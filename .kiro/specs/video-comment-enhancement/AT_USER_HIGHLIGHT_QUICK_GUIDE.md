# @用户高亮显示 - 快速指南

## 功能说明

@用户文本现在会在输入框中以**蓝色高亮**显示，让用户能够清楚地看到 @提及的内容。

## 高亮效果

### 颜色
- **蓝色** (#1890FF)
- **字重**: 中等 (FontWeight.w500)

### 支持的格式
- `@用户名 ` - 中文用户名
- `@username ` - 英文用户名
- `@user123 ` - 混合用户名

## 使用示例

### 示例 1
```
输入：@张三 你好
显示：[蓝色]@张三[/蓝色] 你好
```

### 示例 2
```
输入：@张三 和 @李四 一起
显示：[蓝色]@张三[/蓝色] 和 [蓝色]@李四[/蓝色] 一起
```

### 示例 3
```
输入：@用户 [happy] 你好
显示：[蓝色]@用户[/蓝色] [表情图片] 你好
```

## 工作原理

1. **识别**: 使用正则表达式识别 `@用户名 ` 格式
2. **分段**: 将文本分为 @提及部分和普通部分
3. **渲染**: 对 @提及部分应用蓝色高亮样式

## 修改高亮颜色

如果想修改高亮颜色，编辑 `lib/common/widgets/rich_text/controller.dart`：

```dart
final mentionStyle = (baseStyle ?? const TextStyle()).copyWith(
  color: const Color(0xFF1890FF), // 修改这里
  fontWeight: FontWeight.w500,
);
```

### 常用颜色代码
- 蓝色: `0xFF1890FF`
- 绿色: `0xFF52C41A`
- 红色: `0xFFF5222D`
- 紫色: `0xFF722ED1`
- 橙色: `0xFFFA8C16`

## 测试方法

1. 打开评论对话框
2. 点击 @提及按钮
3. 选择用户
4. 观察输入框中的 @提及文本是否显示为蓝色

## 常见问题

### Q: @提及文本没有高亮显示
**A**: 
- 确保输入格式正确：`@用户名 `（注意末尾的空格）
- 检查是否重新编译了代码

### Q: 高亮颜色太浅/太深
**A**: 修改颜色代码中的 RGB 值，或调整透明度

### Q: 能否添加背景色？
**A**: 可以，在样式中添加 `backgroundColor` 参数
