## 技术实现

### 核心算法
**视频进度识别正则表达式**:
```regex
(?:^|\s)(\d{1,2}:\d{2}(?::\d{2})?)(?:\s|$)
```

**高亮处理流程**:
1. 提取文本中的视频进度
2. 提取文本中的 @提及
3. 合并两种高亮信息
4. 按位置排序
5. 分段渲染，应用相应样式

### 关键类
- `_VideoProgressSpan` - 视频进度信息存储
- `_HighlightSpan` - 高亮文本信息存储
- `RichTextEditingController` - 富文本控制器
