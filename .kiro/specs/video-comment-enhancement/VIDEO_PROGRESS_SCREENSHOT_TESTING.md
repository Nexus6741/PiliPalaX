# 视频进度和截图功能 - 测试指南

## 快速测试

### 测试 1：视频进度功能
```
1. 打开视频
2. 播放视频到任意位置（如 1分30秒）
3. 打开评论对话框
4. 点击"更多"按钮
5. 选择"视频进度"
6. 检查评论框中是否显示 "01:30"
7. 验证时间是否与当前播放位置一致
```

**预期结果**：
- 评论框中显示当前播放进度
- 时间格式正确（MM:SS 或 HH:MM:SS）
- 显示"已插入视频进度: XX:XX"提示

### 测试 2：视频截图功能
```
1. 打开视频
2. 播放视频到想要截图的位置
3. 打开评论对话框
4. 点击"更多"按钮
5. 选择"视频截图"
6. 等待截图完成
7. 检查图片列表中是否显示新截图
```

**预期结果**：
- 显示"正在截图..."加载提示
- 截图完成后显示"截图成功，已添加到图片列表"
- 图片列表中显示新截图

### 测试 3：多个进度插入
```
1. 打开视频
2. 播放到 30 秒，插入进度
3. 继续播放到 1 分 30 秒，插入进度
4. 继续播放到 2 分 30 秒，插入进度
5. 检查评论框内容
```

**预期结果**：
- 评论框显示：`00:30 01:30 02:30`
- 所有时间都正确插入

### 测试 4：截图和进度混合
```
1. 打开视频
2. 插入视频进度
3. 插入视频截图
4. 插入视频进度
5. 检查评论框和图片列表
```

**预期结果**：
- 评论框包含两个时间戳
- 图片列表包含一张截图
- 发送评论时，时间和图片都正确

### 测试 5：发送评论验证
```
1. 插入视频进度：00:30
2. 插入视频截图
3. 输入文本：这是一个很好的片段
4. 点击发送
5. 检查评论区
```

**预期结果**：
- 评论成功发送
- 评论区显示时间戳和文本
- 评论区显示截图

## 关键检查点

- [ ] 视频进度格式正确（MM:SS 或 HH:MM:SS）
- [ ] 视频进度与当前播放位置一致
- [ ] 视频截图成功添加到图片列表
- [ ] 截图内容正确（显示当前视频画面）
- [ ] 多个进度可以正确插入
- [ ] 进度和截图可以混合使用
- [ ] 发送评论时，进度和截图都正确显示
- [ ] 错误情况下显示正确的提示

## 常见问题

### Q: 视频进度显示不正确
**A**:
- 检查视频是否正在播放
- 检查播放位置是否正确
- 尝试重新打开评论对话框

### Q: 截图失败
**A**:
- 检查视频是否已加载
- 检查是否有足够的存储空间
- 检查图片列表是否已满

### Q: 时间格式不对
**A**:
- 检查播放位置是否超过1小时
- 验证时间格式化逻辑
