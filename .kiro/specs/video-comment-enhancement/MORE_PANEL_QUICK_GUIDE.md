# 更多面板快速指南

## 功能概览

工具栏现在包含以下按钮：

```
[😊表情] [🖼️图片] [@提及] [➕更多] [📱转到动态] [取消] [发送]
```

点击"更多"按钮后，会弹出底部面板显示：

```
┌─────────────────────────────────┐
│  📄插入内容  ⏰视频进度  📷视频截图  │
└─────────────────────────────────┘
```

## 快速使用

### 插入视频进度
1. 点击工具栏的"更多"按钮（➕图标）
2. 点击"视频进度"选项
3. 当前播放时间自动插入到输入框

### 视频截图
1. 点击工具栏的"更多"按钮（➕图标）
2. 点击"视频截图"选项
3. 当前视频画面自动截图并添加到图片列表

### 插入内容（开发中）
1. 点击工具栏的"更多"按钮（➕图标）
2. 点击"插入内容"选项
3. 搜索并插入视频/文章链接

### 转到动态（开发中）
1. 点击工具栏的"转到动态"按钮（📱图标）
2. 将评论转发到动态

## 面板切换

| 当前状态 | 点击按钮 | 结果 |
|---------|---------|------|
| 输入状态 | 更多按钮 | 显示更多面板 |

| 表情面板 | 更多按钮 | 切换到更多面板 |
| @提及面板 | 更多按钮 | 切换到更多面板 |

## 常见问题

### Q: 为什么点击"更多"按钮没有反应？
**A**: 检查是否有其他面板正在显示，尝试先关闭其他面板。

### Q: 更多面板显示不完整？
**A**: 检查设备屏幕尺寸，面板会自动适配键盘高度。

### Q: 如何关闭更多面板？
**A**: 再次点击"更多"按钮，或点击其他面板按钮（如表情、@提及）。

### Q: 插入内容功能什么时候可用？

## 技术细节

### 面板类型
- `input` - 输入状态（显示键盘）
- `emote` - 表情面板
- `mention` - @提及面板
- `more` - 更多面板

### 面板高度
- 使用 `emoteHeight` 变量
- 与键盘高度保持一致
- 最小高度 200px

### 网格布局
- 4列布局
- 主轴间距 12px
- 交叉轴间距 12px
- 宽高比 0.8
