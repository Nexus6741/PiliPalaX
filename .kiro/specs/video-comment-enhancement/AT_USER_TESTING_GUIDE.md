# @用户功能测试指南

## 快速测试步骤

### 测试 1：基础搜索功能
```
1. 打开视频评论对话框
2. 点击 @提及按钮（@图标）
3. 应该看到 MentionPanel 显示已关注用户列表
4. 在搜索框中输入用户名
5. 应该看到搜索结果更新
```

**预期结果**：
- MentionPanel 显示用户列表
- 搜索框实时更新搜索结果
- 显示用户头像、昵称、粉丝数

### 测试 2：选择用户并插入 @提及
```
1. 打开 @提及面板
2. 搜索一个用户
3. 点击用户
4. 检查输入框
```

**预期结果**：
- 输入框中插入 `@用户名 ` 格式的文本
- MentionPanel 自动关闭
- 光标位置在 @提及文本之后

### 测试 3：多个 @提及
```
1. 输入文本：`你好`
2. 点击 @提及按钮，选择用户 A
3. 输入文本：`和`
4. 点击 @提及按钮，选择用户 B
5. 输入文本：`再见`
6. 检查输入框显示
```

**预期结果**：
- 输入框显示：`你好@用户A 和@用户B 再见`
- 所有文本和 @提及都正确显示

### 测试 4：发送评论验证
```
1. 输入：`@用户名 你好`
2. 点击发送
3. 检查评论区
```

**预期结果**：
- 评论成功发送
- 评论区显示 `@用户名 你好`
- @提及的用户能看到通知

### 测试 5：用户分组
```
1. 打开 @提及面板
2. 不输入任何内容
3. 观察用户列表
```

**预期结果**：
- 已关注用户显示在前面
- 其他用户显示在后面
- 用户按粉丝数排序

### 测试 6：认证状态显示
```
1. 打开 @提及面板
2. 搜索一个认证用户
3. 观察用户信息
```

**预期结果**：
- 认证用户显示认证标签（个人认证/机构认证）
- 未认证用户不显示标签

## 关键检查点

- [ ] @提及按钮可以打开 MentionPanel
- [ ] 搜索框可以实时搜索用户
- [ ] 用户列表显示头像、昵称、粉丝数
- [ ] 点击用户后插入 `@用户名 ` 格式的文本
- [ ] MentionPanel 自动关闭
- [ ] 支持多个 @提及
- [ ] 发送的评论中 @提及格式正确
- [ ] 用户分组正确（已关注/其他）
- [ ] 认证状态正确显示

## 常见问题

### Q: 搜索不到用户
**A**: 
- 检查网络连接
- 确保输入的用户名正确
- 尝试搜索已关注的用户

### Q: @提及文本没有插入
**A**:
- 检查输入框是否有焦点
- 确保选择了用户
- 检查光标位置

### Q: 发送评论失败
**A**:
- 检查网络连接
- 确保已登录
- 检查评论内容是否违规

## 调试信息

如果遇到问题，可以检查以下信息：

1. **网络请求**：检查 API 是否正确调用
2. **用户数据**：检查搜索结果是否正确解析
3. **文本插入**：检查 @提及文本是否正确插入
4. **发送内容**：检查发送的评论内容是否正确

## 修复建议

如果功能不正常，可以尝试：

1. **清除缓存**
   ```bash
   flutter clean
   flutter pub get
   flutter run
   ```

2. **检查 API 连接**
   - 确保网络正常
   - 检查 API 端点是否正确

3. **检查用户认证**
   - 确保已登录
   - 检查 SESSDATA cookie 是否有效

4. **查看日志**
   - 运行时查看控制台输出
   - 检查是否有错误信息
