# 如何启用影视标签

## 问题

首次运行应用时，影视标签可能不会显示在主页标签栏中。这是因为应用使用了本地存储的标签配置。

## 解决方案

有两种方法可以启用影视标签：

### 方法 1: 清除应用数据（推荐）

1. 完全卸载应用
2. 重新安装应用
3. 启动应用后，影视标签将自动显示

### 方法 2: 通过设置启用

1. 打开应用
2. 进入 **设置** → **外观设置** → **首页标签页**
3. 在标签列表中找到 **影视** 选项
4. 勾选 **影视** 复选框
5. 点击右上角的 **保存** 按钮
6. 重启应用，影视标签将显示在主页

### 方法 3: 手动清除本地存储（开发者）

如果你是开发者，可以手动清除本地存储：

```dart
// 在应用启动时执行一次
Box settingStorage = GStorage.setting;
settingStorage.delete(SettingBoxKey.tabbarSort);
```

或者在调试时：

```bash
# Android
adb shell pm clear com.your.package.name

# iOS
# 在模拟器中删除应用并重新安装
```

## 技术说明

### 默认配置

影视标签已添加到默认配置中：

```dart
defaultValue: ['live', 'rcmd', 'hot', 'rank', 'bangumi', 'cinema']
```

### 标签顺序

默认标签顺序为：
1. 直播 (live)
2. 推荐 (rcmd)
3. 热门 (hot)
4. 分区 (rank)
5. 番剧 (bangumi)
6. 影视 (cinema) ← 新增

### 配置文件位置

标签配置存储在以下位置：
- **代码**: `lib/pages/home/controller.dart`
- **设置页面**: `lib/pages/setting/pages/home_tabbar_set.dart`
- **本地存储**: Hive Box - `SettingBoxKey.tabbarSort`

## 验证

启用影视标签后，你应该能够：

1. ✅ 在主页底部看到"影视"标签
2. ✅ 点击标签后看到影视内容页面
3. ✅ 看到"最近追剧"区域（如果已登录）

## 常见问题

**Q: 为什么我更新代码后影视标签还是不显示？**

A: 因为应用使用了本地存储的配置。你需要清除应用数据或通过设置手动启用。

**Q: 我可以调整标签顺序吗？**

A: 可以！在 **设置** → **外观设置** → **首页标签页** 中，长按标签可以拖动排序。

**Q: 我可以隐藏某些标签吗？**

A: 可以！在标签设置页面中，取消勾选不需要的标签即可。
