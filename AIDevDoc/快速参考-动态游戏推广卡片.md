# 快速参考 - 动态游戏推广卡片

## 功能说明

在动态卡片下方显示游戏推广链接卡片，包含游戏图标、名称、描述和进入按钮。

## 实现位置

### 数据模型
**文件**：`lib/models/dynamics/result.dart`
- `AddCommon` - 游戏推广卡片数据
- `AddButton` - 按钮数据
- `JumpStyle` - 跳转样式

### UI 实现
**文件**：`lib/pages/dynamics/widgets/additional_panel.dart`
- `addWidget()` 函数
- `case 'ADDITIONAL_TYPE_COMMON'`

## 布局结构

```
┌─────────────────────────────────────┐
│ [45x45] 游戏标题          [进入按钮] │
│  图标   类型/分类                   │
│         额外信息                    │
└─────────────────────────────────────┘
```

## 关键代码

### 数据结构
```dart
class AddCommon {
  AddButton? button;      // 按钮
  String? cover;          // 封面图
  String? desc1;          // 描述1
  String? desc2;          // 描述2
  String? jumpUrl;        // 跳转链接
  String? title;          // 标题
}
```

### UI 实现
```dart
Material(
  color: bgColor,
  borderRadius: BorderRadius.circular(6),
  child: InkWell(
    onTap: () => Get.toNamed('/webview', ...),
    child: Padding(
      padding: EdgeInsets.symmetric(horizontal: 12, vertical: 8),
      child: Row(
        children: [
          NetworkImgLayer(width: 45, height: 45, ...),
          SizedBox(width: 10),
          Expanded(
            child: Column(
              children: [
                Text(title),
                Text(desc1, style: grayStyle),
                Text(desc2, style: grayStyle),
              ],
            ),
          ),
          FilledButton.tonal(child: Text('进入')),
        ],
      ),
    ),
  ),
)
```

## 样式参数

### 尺寸
- 封面图：45x45
- 圆角：6px
- 内边距：12x8

### 颜色
- 背景：`dividerColor.withValues(alpha: 0.08)` 或 `surface`
- 描述文本：`colorScheme.outline`
- 按钮：`FilledButton.tonal`

### 字体
- 标题：默认
- 描述：13px

## 交互逻辑

### 卡片点击
- 跳转到 `/webview`
- 传递 `jumpUrl` 和 `title`

### 按钮点击
- 跳转到 `/webview`
- 传递 `button.jumpUrl`
