# 头像框显示修复完成

## 修复时间
2024-12-22

## 问题描述

1. 用户空间的头像框（pendant）显示不全
2. 评论区的用户头像没有显示头像框

## 修复方案

### 1. 用户空间头像框修复

**问题原因：**
- 头像框位置固定为 `top: -30`，不够准确
- Stack 没有设置 `clipBehavior: Clip.none`，导致超出部分被裁剪

**修复方法：**
参考 PiliPlus 的实现，使用动态计算的位置：

```dart
Stack(
  alignment: Alignment.bottomCenter,
  clipBehavior: Clip.none,  // 关键：允许子组件超出边界
  children: [
    // 头像
    Container(...),
    
    // 头像框 - 动态计算位置
    if (card.pendant?.image?.isNotEmpty == true)
      Positioned(
        top: -0.375 * (80 - 4),  // -(80 * 1.75 - 80) / 2
        child: IgnorePointer(
          child: CachedNetworkImage(
            width: 80 * 1.75,  // 头像框是头像的 1.75 倍
            height: 80 * 1.75,
            imageUrl: card.pendant!.image!,
          ),
        ),
      ),
  ],
)
```

**计算公式：**
- 头像框大小 = 头像大小 × 1.75
- 头像框位置 = -0.375 × (头像大小 - 边框宽度)
- 对于 80px 的头像：`top: -0.375 * (80 - 4) = -28.5`

### 2. 评论区头像框添加

**实现方法：**
在评论项的 `lfAvtar` 方法中添加头像框显示：

```dart
Widget lfAvtar(BuildContext context, String heroTag) {
  return Stack(
    clipBehavior: Clip.none,  // 允许头像框超出边界
    children: [
      // 头像
      Hero(
        tag: heroTag,
        child: NetworkImgLayer(
          src: replyItem!.member!.avatar,
          width: 34,
          height: 34,
          type: 'avatar',
        ),
      ),
      
      // 头像框
      if (replyItem!.member!.pendant?.image?.isNotEmpty == true)
        Positioned(
          top: -0.375 * 34,  // 对于 34px 的头像
          left: -0.375 * 34,
          child: IgnorePointer(
            child: NetworkImgLayer(
              src: replyItem!.member!.pendant!.image,
              width: 34 * 1.75,
              height: 34 * 1.75,
            ),
          ),
        ),
      
      // VIP 标识
      // 认证标识
      // ...
    ],
  );
}
```

**数据来源：**
评论模型 `ReplyItemModel` 中的 `member.pendant` 字段已经包含头像框信息：
```dart
class Member {
  String? avatar;
  int? level;
  Pendant? pendant;  // 头像框数据
  Map? officialVerify;
  Map? vip;
}

class Pendant {
  String? image;  // 头像框图片 URL
  int? pid;
  String? name;
}
```

## 技术要点

### 1. Stack 的 clipBehavior
```dart
Stack(
  clipBehavior: Clip.none,  // 允许子组件超出边界
  children: [...]
)
```
默认情况下，Stack 会裁剪超出边界的子组件。设置为 `Clip.none` 可以让头像框完整显示。

### 2. 头像框尺寸比例
根据 B 站的设计规范，头像框是头像的 **1.75 倍**大小。

### 3. 头像框位置计算
```dart
// 头像框应该居中在头像上
// 头像框大小 = size * 1.75
// 需要向上和向左偏移 = (size * 1.75 - size) / 2 = size * 0.375
top: -0.375 * size
left: -0.375 * size  // 评论区需要，用户空间因为居中对齐不需要
```

### 4. IgnorePointer
```dart
IgnorePointer(
  child: CachedNetworkImage(...)
)
```
头像框不应该响应点击事件，使用 `IgnorePointer` 让点击事件穿透到下层的头像。
