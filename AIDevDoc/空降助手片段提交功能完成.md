# 空降助手片段提交功能完成

## 修复内容

### 问题描述
1. 用户点击片段提交按钮时，提示错误 "No userID provided"，导致无法提交片段到 SponsorBlock 服务器
2. 提交面板打开时视频继续播放，影响用户精确设置时间
3. 每次打开面板都重新获取当前时间，无法保持上次设置的时间

### 根本原因
1. 提交片段时需要用户 ID (blockUserID)，但系统没有在提交前检查和生成该 ID
2. 缺少视频播放状态管理
3. 缺少时间状态持久化

### 解决方案

#### 1. 添加用户 ID 检查和生成逻辑
在 `lib/pages/video/widgets/submit_segment_panel.dart` 的 `_submitSegment()` 方法中：

```dart
// Check and generate user ID
final setting = GStorage.setting;
String blockUserID = setting.get('blockUserID', defaultValue: '');
if (blockUserID.isEmpty) {
  blockUserID = const Uuid().v4().replaceAll('-', '');
  await setting.put('blockUserID', blockUserID);
  print('🔍 [SubmitSegmentPanel] 生成新的 userID: $blockUserID');
} else {
  print('🔍 [SubmitSegmentPanel] 使用已有 userID: $blockUserID');
}
```

#### 2. 添加视频播放状态管理
```dart
bool wasPlaying = false;

@override
void initState() {
  super.initState();
  
  // 记录当前播放状态
  wasPlaying = widget.videoDetailCtr.plPlayerController?.playing.value ?? false;
  
  // 暂停视频
  if (wasPlaying) {
    widget.videoDetailCtr.plPlayerController?.pause();
  }
}

@override
void dispose() {
  // 恢复播放状态
  if (wasPlaying) {
    widget.videoDetailCtr.plPlayerController?.play();
  }
  super.dispose();
}
```

#### 3. 添加时间状态持久化
在 `VideoDetailController` 中添加状态变量：
```dart
// 片段提交面板状态
bool isFirstOpenSubmitPanel = true;
int? savedStartTime;
int? savedEndTime;
```

在 `openSubmitPanel` 方法中：
```dart
// 如果是首次打开，使用当前位置；否则使用保存的时间
final startTime = isFirstOpenSubmitPanel ? currentPos : (savedStartTime ?? currentPos);
final endTime = isFirstOpenSubmitPanel ? (currentPos + 10000) : (savedEndTime ?? (currentPos + 10000));

showModalBottomSheet(...).then((_) {
  // 面板关闭后，标记为非首次打开
  if (isFirstOpenSubmitPanel) {
    isFirstOpenSubmitPanel = false;
    savedStartTime = startTime;
    savedEndTime = endTime;
  }
});
```

在用户手动设置时间时更新保存的值：
```dart
void _setStartTime() {
  // ... 设置时间逻辑
  widget.videoDetailCtr.savedStartTime = startTime;
  widget.videoDetailCtr.savedEndTime = endTime;
}

void _setEndTime() {
  // ... 设置时间逻辑
  widget.videoDetailCtr.savedEndTime = endTime;
}
```

#### 4. 添加必要的导入
```dart
import 'package:uuid/uuid.dart';
import 'package:PiliPalaX/utils/storage.dart';
```

## 功能特性

### 视频播放控制
- 打开提交面板时自动暂停视频
- 关闭面板时恢复播放（如果之前是播放状态）
- 不影响用户手动暂停的状态

### 时间状态管理
- **首次打开**：自动获取当前播放位置作为开始时间，结束时间默认为开始时间+10秒
- **后续打开**：保持上次设置的时间，不会重新获取
- **手动设置**：用户点击"设为开始"/"设为结束"按钮手动更新时间
- **提交成功后**：重置状态，下次打开重新开始

### 用户 ID 管理
- 首次提交时自动生成 UUID（去除连字符）
- 后续提交复用已生成的 ID
- ID 持久化存储在 GStorage.setting 中

### 片段提交流程
1. 用户在播放视频时点击"片段提交"按钮
2. 视频自动暂停
3. 打开提交面板：
   - 首次打开：显示当前播放位置作为开始时间
   - 后续打开：显示上次保存的时间
4. 用户可以：
   - 播放到需要的位置，点击"设为开始"设置开始时间
   - 继续播放到片段结束位置，点击"设为结束"设置结束时间
   - 选择片段类型（赞助、片头、片尾等）
5. 点击"提交片段"按钮
6. 系统检查/生成用户 ID
7. 调用 SponsorBlock API 提交片段
8. 显示提交结果并刷新片段列表
9. 关闭面板，视频恢复播放

### 数据验证
- 结束时间必须大于开始时间
- 自动将毫秒转换为秒（API 要求）
- 包含视频总时长信息

## 注意事项

1. **播放状态管理**：只在视频正在播放时才会暂停和恢复，不会影响用户手动暂停的状态
2. **时间持久化**：时间状态在当前视频会话中保持，切换视频后会重置
3. **用户 ID 唯一性**：每个设备生成唯一的 UUID，用于标识提交者
4. **数据持久化**：用户 ID 存储在本地，卸载应用后会丢失
5. **时间单位**：内部使用毫秒，API 使用秒，需要转换
6. **网络请求**：提交需要网络连接，失败时会显示错误信息
7. **审核机制**：提交的片段可能被 SponsorBlock 的自动审核机制拒绝
