# 合作视频功能实现完成

## 功能概述

完整实现了哔哩哔哩合作视频功能，包括：
1. 合作视频 UP 主列表显示
2. 每个 UP 主的头像、昵称、职位、VIP 状态、认证标识
3. 批量查询关注状态
4. 快速关注/取消关注功能
5. 点击跳转到 UP 主主页

## 实现细节

### 1. 数据模型层

#### 新增文件：`lib/models/video_detail_res_staff.dart`
- `Staff` 类：合作视频 UP 主信息
  - `mid`: UP 主 ID
  - `name`: UP 主昵称
  - `face`: 头像 URL
  - `title`: 职位/角色（如"UP主"、"音乐"、"剪辑"等）
  - `vip`: VIP 信息
  - `official`: 认证信息

- `Vip` 类：VIP 信息
  - `type`: VIP 类型（2=大会员）
  - `status`: VIP 状态
  - `nicknameColor`: 昵称颜色

- `Official` 类：认证信息
  - `type`: 认证类型（0=个人认证，1=机构认证）
  - `title`: 认证标题
  - `desc`: 认证描述

#### 修改文件：`lib/models/video_detail_res.dart`
- 在 `VideoDetailData` 类中添加 `staff` 字段
- 支持从 JSON 解析 staff 数组
- 支持序列化为 JSON

### 2. HTTP 接口层

#### 修改文件：`lib/http/api.dart`
- 新增 API 端点：`relations = '/x/relation/relations'`
  - 用于批量查询多个 UP 主的关注状态

#### 修改文件：`lib/http/video.dart`
- 新增方法：`relations({required String fids})`
  - 参数：fids - 多个 mid 用逗号分隔
  - 返回：Map<String, dynamic> - 每个 mid 的关注状态

### 3. 控制器层

#### 修改文件：`lib/pages/video/introduction/detail/controller.dart`

**新增字段：**
```dart
// 合作视频UP主关注状态
RxMap staffRelations = {}.obs;
```

**修改方法：**

1. `queryUserStat()` - 获取 UP 主信息
   - 检测是否为合作视频
   - 如果是合作视频，调用 `queryStaffRelations()`
   - 如果是普通视频，查询单个 UP 主粉丝数

2. `queryStaffRelations()` - 查询合作 UP 主关注状态
   - 提取所有 staff 的 mid
   - 批量查询关注状态
   - 更新 `staffRelations` 响应式变量

3. `queryFollowStatus()` - 查询关注状态
   - 如果是合作视频，跳过单个 UP 主关注状态查询

4. `actionRelationMod()` - 关注/取关操作
   - 如果是合作视频，提示用户点击 UP 主头像进入主页关注

**新增方法：**

5. `actionStaffRelationMod(int mid)` - 关注/取关合作 UP 主
   - 检查登录状态
   - 检查当前关注状态
   - 调用 API 进行关注/取关操作
   - 更新 `staffRelations` 状态
   - 显示操作结果提示

### 4. UI 组件层

#### 新增文件：`lib/pages/video/introduction/widgets/staff_item.dart`

**StaffItem 组件：**
- 显示单个合作 UP 主的信息
- 支持点击跳转到 UP 主主页
- 支持快速关注/取消关注

**UI 布局：**
```
┌─────────────────────────────────┐
│  ┌────┐                         │
│  │头像│  UP主名称（VIP颜色）     │
│  │ +  │  职位/角色               │
│  └────┘                         │
└─────────────────────────────────┘
```

**特性：**
1. 头像右下角显示认证标识
   - 个人认证：黄色闪电图标
   - 机构认证：蓝色闪电图标

2. 头像右上角显示关注按钮（仅未关注时）
   - 圆形按钮，带 + 图标
   - 点击快速关注

3. VIP 用户名称显示为粉色

4. 职位/角色显示为灰色小字

#### 修改文件：`lib/pages/video/introduction/detail/view.dart`

**新增方法：**

1. `_buildOwnerSection()` - 构建 UP 主区域
   - 检测是否为合作视频
   - 合作视频：调用 `_buildStaffList()`
   - 普通视频：调用 `_buildSingleOwner()`

2. `_buildSingleOwner()` - 构建单个 UP 主
   - 保持原有的单 UP 主显示逻辑
   - 显示头像、昵称、粉丝数、关注按钮

3. `_buildStaffList()` - 构建合作 UP 主列表
   - 横向滚动列表
   - 使用 `StaffItem` 组件显示每个 UP 主
   - 响应式更新关注状态
   - 支持点击跳转和快速关注

**UI 效果：**
```
普通视频：
┌────────────────────────────────────┐
│ [头像] UP主名称        [关注按钮]  │
│        123万粉丝                   │
└────────────────────────────────────┘

合作视频（横向滚动）：
┌────────────────────────────────────┐
│ [UP1] [UP2] [UP3] [UP4] ...        │
│  名称  名称  名称  名称             │
│  职位  职位  职位  职位             │
└────────────────────────────────────┘
```

## 使用示例

### 查看合作视频
1. 打开任意合作视频
2. 在视频简介区域可以看到横向滚动的 UP 主列表
3. 每个 UP 主显示头像、昵称、职位

### 关注合作 UP 主
1. 点击 UP 主头像右上角的 + 按钮
2. 系统提示"关注成功"
3. + 按钮消失，表示已关注

### 取消关注
1. 点击已关注的 UP 主头像
2. 进入 UP 主主页
3. 在主页进行取消关注操作

### 查看 UP 主主页
1. 点击任意 UP 主的头像或名称
2. 跳转到该 UP 主的主页
3. 可以查看更多信息和视频
