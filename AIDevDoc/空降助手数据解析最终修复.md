## 根本原因

SponsorBlock API 返回的数据类型不一致：
- 某些字段可能是 `int`、`double`、`String` 或 `null`
- 直接类型转换会失败
- 需要更健壮的解析逻辑

## 最终解决方案

### 修改文件
`lib/models_new/sponsor_block/segment_item.dart`

### 核心改进

#### 1. 健壮的 segment 数组解析
```dart
List<int> segment = [];
if (json['segment'] is List) {
  segment = (json['segment'] as List).map((e) {
    if (e is int) return e;              // 直接返回 int
    if (e is double) return e.toInt();   // double 转 int
    if (e is String) return int.tryParse(e) ?? 0;  // String 转 int
    return (e as num).toInt();           // 其他 num 类型
  }).toList();
}
```

**处理情况**：
- `[1000, 5000]` → int 数组 ✅
- `[1000.0, 5000.0]` → double 数组 ✅
- `["1000", "5000"]` → string 数组 ✅
- `[1000, "5000", 3000.0]` → 混合类型 ✅

#### 2. 通用整数字段解析函数
```dart
int? parseIntField(dynamic value) {
  if (value == null) return null;
  if (value is int) return value;
  if (value is double) return value.toInt();
  if (value is String) return int.tryParse(value);
  if (value is num) return value.toInt();
  return null;
}
```

**处理情况**：
- `null` → `null` ✅
- `123` → `123` ✅
- `123.0` → `123` ✅
- `"123"` → `123` ✅
- `"abc"` → `null` ✅（解析失败返回 null）

#### 3. 安全的字符串字段解析
```dart
uuid: json['UUID']?.toString() ?? '',
category: json['category']?.toString() ?? 'sponsor',
description: json['description']?.toString(),
```

**特点**：
- 使用 `?.toString()` 安全转换
- 提供默认值
- 避免 null 异常

#### 4. 错误日志
```dart
try {
  // 解析逻辑
} catch (e) {
  print('❌ SegmentItemModel.fromJson 解析失败: $e');
  print('   JSON 数据: $json');
  rethrow;
}
```

**作用**：
- 捕获解析错误
- 打印完整的 JSON 数据
- 帮助调试 API 返回格式

## 完整代码

```dart
factory SegmentItemModel.fromJson(Map<String, dynamic> json) {
  try {
    // 解析 segment 数组
    List<int> segment = [];
    if (json['segment'] is List) {
      segment = (json['segment'] as List).map((e) {
        if (e is int) return e;
        if (e is double) return e.toInt();
        if (e is String) return int.tryParse(e) ?? 0;
        return (e as num).toInt();
      }).toList();
    }

    // 安全解析整数字段
    int? parseIntField(dynamic value) {
      if (value == null) return null;
      if (value is int) return value;
      if (value is double) return value.toInt();
      if (value is String) return int.tryParse(value);
      if (value is num) return value.toInt();
      return null;
    }

    return SegmentItemModel(
      uuid: json['UUID']?.toString() ?? '',
      segment: segment,
      category: json['category']?.toString() ?? 'sponsor',
      videoDuration: parseIntField(json['videoDuration']),
      actionType: parseIntField(json['actionType']),
      locked: parseIntField(json['locked']),
      votes: parseIntField(json['votes']),
      description: json['description']?.toString(),
    );
  } catch (e) {
    print('❌ SegmentItemModel.fromJson 解析失败: $e');
    print('   JSON 数据: $json');
    rethrow;
  }
}
```

## 技术要点

### 类型安全
- 不假设任何字段的类型
- 每个字段都有多种类型的处理逻辑
- 提供合理的默认值

### 错误处理
- 使用 try-catch 捕获异常
- 打印详细的错误信息
- 重新抛出异常以便上层处理

### 向后兼容
- 支持旧版本 API 格式
- 支持新版本 API 格式
- 支持不同服务器的实现差异

## 总结

通过三层防护：
1. **类型检查**：`if (e is int)`
2. **安全转换**：`int.tryParse(e)`
3. **默认值**：`?? 0`

确保无论 API 返回什么格式，都能正确解析或优雅降级。
