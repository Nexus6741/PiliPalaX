# 4K 视频播放卡顿优化方案

## 当前状态分析

你的项目使用的 media_kit **已经是 Texture 渲染方案**，不是 PlatformView，所以渲染方式本身不是问题。

## 4K 卡顿的可能原因

### 1. 硬件解码配置问题
```dart
// 当前配置 (lib/pages/video/controller.dart)
enableHA.value = setting.get(SettingBoxKey.enableHA, defaultValue: true);
hwdec.value = setting.get(SettingBoxKey.hardwareDecoding, defaultValue: 'auto');
```

**优化建议**：
- 确保硬件解码已启用
- 尝试不同的 hwdec 值：`'auto'`, `'auto-safe'`, `'mediacodec'` (Android)
- 检查设备是否支持 4K 硬解

### 2. 解码格式选择问题
```dart
// 当前逻辑会优先选择 AV1 编码
cacheDecode = setting.get(SettingBoxKey.defaultDecode, 
    defaultValue: VideoDecodeFormats.values.last.code);
```

**问题**：AV1 编码虽然压缩率高，但解码性能要求更高
**优化建议**：
- 4K 视频优先使用 H.264 (AVC) 或 H.265 (HEVC)
- 避免使用 AV1，除非设备有专门的 AV1 硬解支持

### 3. 缓冲区配置不足
**优化建议**：
```dart
// 在 playerInit 中添加缓冲配置
await plPlayerController!.setDataSource(
  DataSource(
    // ... 现有配置
    extras: {
      // 增加缓冲区大小
      'demuxer-max-bytes': '150M',  // 默认可能较小
      'demuxer-max-back-bytes': '75M',
      // 预读取配置
      'cache': 'yes',
      'cache-secs': '10',  // 预缓冲秒数
    },
  ),
  // ...
);
```

### 4. 画质自动降级策略
**建议添加**：
```dart
// 检测设备性能，4K 视频时自动降级
Future<void> optimizeVideoQuality() async {
  // 获取视频分辨率
  if (firstVideo.width != null && firstVideo.width! >= 3840) {
    // 4K 视频
    final deviceInfo = await DeviceInfoPlugin().androidInfo;
    
    // 低端设备自动降级到 1080P
    if (deviceInfo.version.sdkInt < 28 || 
        !deviceInfo.isPhysicalDevice) {
      // 选择 1080P 画质
      currentVideoQa = VideoQuality.fhd1080;
      SmartDialog.showToast('检测到 4K 视频，已自动降级到 1080P 以保证流畅播放');
    }
  }
}
```

### 5. 渲染优化
**当前配置**：
```dart
Texture(
  textureId: id,
  filterQuality: videoViewParameters.filterQuality,
)
```

**优化建议**：
```dart
Texture(
  textureId: id,
  filterQuality: FilterQuality.low,  // 4K 时使用低质量过滤，减少 GPU 负担
)
```

### 6. 内存和线程优化
**添加 mpv 配置**：
```dart
extras: {
  // 视频输出优化
  'vo': 'gpu',  // 使用 GPU 渲染
  'hwdec': 'auto-safe',  // 安全的硬件解码
  'hwdec-codecs': 'h264,hevc,vp9',  // 指定硬解编码格式
  
  // 线程优化
  'vd-lavc-threads': '4',  // 解码线程数
  
  // 内存优化
  'demuxer-max-bytes': '200M',
  'demuxer-readahead-secs': '10',
  
  // 跳帧策略（卡顿时自动跳帧）
  'video-sync': 'audio',
  'framedrop': 'vo',  // 允许丢帧
}
```

## 具体优化代码

### 1. 修改 controller.dart 的 playerInit 方法

```dart
Future playerInit({
  video,
  audio,
  seekToTime,
  duration,
  bool autoplay = true,
}) async {
  plPlayerController ??= PlPlayerController.getInstance();
  headerControl ??= HeaderControl(
    controller: plPlayerController,
    videoDetailCtr: this,
    heroTag: heroTag,
  );
  
  // 检测是否为 4K 视频
  bool is4K = firstVideo.width != null && firstVideo.width! >= 3840;
  
  // 4K 视频优化配置
  Map<String, String> extras = {};
  if (is4K) {
    extras = {
      'hwdec': 'auto-safe',
      'vo': 'gpu',
      'vd-lavc-threads': '4',
      'demuxer-max-bytes': '200M',
      'demuxer-readahead-secs': '10',
      'video-sync': 'audio',
      'framedrop': 'vo',
      'cache': 'yes',
      'cache-secs': '15',
    };
  }
  
  await plPlayerController!.setDataSource(
    DataSource(
      videoSource: video ?? videoUrl,
      audioSource: audio ?? audioUrl,
      type: DataSourceType.network,
      httpHeaders: {
        'user-agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36',
        'referer': HttpString.baseUrl
      },
      extras: extras,  // 添加优化配置
    ),
    enableHA: enableHA.value,
    hwdec: is4K ? 'auto-safe' : hwdec.value,  // 4K 强制使用 auto-safe
    seekTo: seekToTime ?? defaultST,
    duration: duration ?? (data.timeLength == null ? null : Duration(milliseconds: data.timeLength!)),
    direction: firstVideo.width != null && firstVideo.height != null
        ? ((firstVideo.width! - firstVideo.height!) > 0 ? 'horizontal' : 'vertical')
        : null,
    bvid: bvid,
    cid: cid.value,
    epid: epid,
    seasonId: seasonId,
    enableHeart: enableHeart,
    autoplay: autoplay,
  );
  
  plPlayerController!.headerControl = headerControl;
}
```

### 2. 优化解码格式选择逻辑

在 `queryVideoUrl()` 方法中，添加 4K 视频的特殊处理：

```dart
// 在选择解码格式时
if (firstVideo.width != null && firstVideo.width! >= 3840) {
  // 4K 视频优先使用 HEVC (H.265)，其次 AVC (H.264)
  // 避免使用 AV1
  final List<String> preferred4KCodecs = ['hev', 'avc'];
  
  for (var codec in preferred4KCodecs) {
    try {
      firstVideo = videosList.firstWhere(
        (e) => e.codecs!.startsWith(codec),
      );
      currentDecodeFormats = VideoDecodeFormatsCode.fromString(firstVideo.codecs!)!;
      break;
    } catch (e) {
      continue;
    }
  }
}
```

### 3. 添加性能监控和自动降级

```dart
// 在 VideoDetailController 中添加
void monitorPerformance() {
  if (plPlayerController == null) return;
  
  // 监听缓冲事件
  plPlayerController!.isBuffering.listen((isBuffering) {
    if (isBuffering) {
      _bufferingCount++;
      
      // 频繁缓冲时自动降级画质
      if (_bufferingCount > 5 && currentVideoQa.code > VideoQuality.fhd1080.code) {
        SmartDialog.showToast('检测到频繁卡顿，正在降低画质...');
        currentVideoQa = VideoQuality.fhd1080;
        updatePlayer();
      }
    }
  });
}

int _bufferingCount = 0;
```

## 测试建议

1. **测试不同硬解模式**：
   - `auto` - 自动选择
   - `auto-safe` - 安全模式（推荐）
   - `mediacodec` - Android MediaCodec（Android 专用）
   - `no` - 纯软解（对比测试）

2. **测试不同编码格式**：
   - H.264 (AVC) - 兼容性最好
   - H.265 (HEVC) - 压缩率高，4K 推荐
   - AV1 - 最新但性能要求高

3. **监控指标**：
   - 帧率 (FPS)
   - 缓冲频率
   - CPU/GPU 使用率
   - 内存占用

## 总结

你的项目**不是 PlatformView 的问题**，而是：
1. ✅ 已使用 Texture 渲染（性能最优）
2. ⚠️ 可能是硬解配置、编码格式选择、缓冲策略需要优化
3. ⚠️ 4K 视频需要特殊的性能优化策略

建议按照上述方案逐步测试优化。
