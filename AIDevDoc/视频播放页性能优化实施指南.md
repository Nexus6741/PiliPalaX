### 优化 4: 优化 AnimatedContainer

找到所有 AnimatedContainer（约 10 处），将：

```dart
AnimatedContainer(
  duration: const Duration(milliseconds: 350),
  curve: Curves.fastOutSlowIn,
  ...
)
```

替换为：

```dart
AnimatedContainer(
  duration: const Duration(milliseconds: 250),
  curve: Curves.fastOutSlowIn,
  clipBehavior: Clip.none,
  ...
)
```

**使用查找替换**:
- 查找: `duration: const Duration(milliseconds: 350),`
- 替换为: `duration: const Duration(milliseconds: 250),`

然后在每个 AnimatedContainer 的参数中添加 `clipBehavior: Clip.none,`
