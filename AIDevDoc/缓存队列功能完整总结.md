### 任务2：缓存队列实时显示修复 ✅
**问题**：点击缓存后看不到任务，需要重启应用才能看到

**根本原因**：
- `startDownload()` 使用 `removeAt(0)` 从队列移除正在下载的视频
- 导致UI无法显示正在下载的项

**解决方案**：
- 改为保持视频在队列中
- 使用 `_curCid` 标记当前正在下载的视频
- 只在完成、失败或删除时才从队列移除
- 修改了 `_completeDownload()`, `_onDone()`, `cancelDownload()` 等方法

**修改文件**：
- `lib/services/download_service.dart`

### 任务6：进度持久化问题修复 ✅
**问题**：切换视频或退出页面后进度条归零

**根本原因**：
- `_onReceive()` 只在 `progress == 0 && total != 0` 时保存进度
- 下载过程中和暂停时没有持久化进度信息

**解决方案**：
1. **智能保存策略**：
   - 进度变化超过 5MB 时立即保存
   - 使用定时器每 5 秒保存一次
   - 避免频繁磁盘写入

2. **暂停时立即保存**：
   - `cancelDownload()` - 暂停下载
   - `prioritizeDownload()` - 切换视频
   - `skipCurrentDownload()` - 跳过下载
   - `_onDone()` - 下载完成/失败

3. **清理定时器**：
   - 所有状态转换时清理定时器
   - 避免内存泄漏

**技术细节**：
```dart
Timer? _progressSaveTimer;
int _lastSavedProgress = 0;

void _onReceive(int progress, int total) {
  // 更新总大小
  if (total != 0 && entry.totalBytes.value != total) {
    entry.totalBytes.value = total;
    _updateBiliDownloadEntryJson(entry);
  }
  
  // 更新已下载大小
  entry.downloadedBytes.value = progress;
  
  // 智能保存：大进度变化或定时保存
  final progressDiff = (progress - _lastSavedProgress).abs();
  if (progressDiff > 5 * 1024 * 1024) {
    _lastSavedProgress = progress;
    _updateBiliDownloadEntryJson(entry);
  } else {
    _progressSaveTimer?.cancel();
    _progressSaveTimer = Timer(const Duration(seconds: 5), () {
      _lastSavedProgress = progress;
      _updateBiliDownloadEntryJson(entry);
    });
  }
}
```

## 技术架构

### 数据流
```
用户操作 → DownloadService
         ↓
    waitDownloadQueue (RxList)
         ↓
    _curCid + curDownload (当前下载)
         ↓
    DownloadManager (实际下载)
         ↓
    _onReceive (进度回调)
         ↓
    定期保存到 JSON
         ↓
    UI 实时更新 (Obx)
```

### 状态同步
```
内存状态 (RxInt)
    ↕️ 实时同步
UI 显示 (Obx)

内存状态
    ↕️ 定期保存
磁盘存储 (JSON)
```

### 并发控制
- 使用 `Lock` 确保状态转换的原子性
- 单个下载管理器实例
- 队列自动处理

1. **进度精度**：应用崩溃可能丢失最后5秒进度（可接受）
2. **单线程下载**：一次只能下载一个视频
3. **队列顺序**：按添加顺序下载（除非手动优先）
