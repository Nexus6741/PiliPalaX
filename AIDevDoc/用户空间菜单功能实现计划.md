# 用户空间菜单功能实现计划

## 概述
在用户空间右上角菜单中添加以下功能（仅在查看自己的空间时显示）：
- 登录设备
- 登录记录
- 硬币记录
- 经验记录
- 空间设置

## 参考实现
完全按照 PiliPlus 的实现来做，包括功能细节和 UI 布局。

## 实施步骤

### 阶段一：创建基础页面和控制器

#### 1. 登录设备页面
**文件**：
- `lib/pages/login_devices/view.dart`
- `lib/pages/login_devices/controller.dart`
- `lib/models/login_devices/login_devices_data.dart`
- `lib/models/login_devices/login_device.dart`

**功能**：
- 显示当前登录的所有设备列表
- 显示设备名称、最后登录时间、来源
- 标记当前设备

**API**：
- 需要在 `lib/http/login.dart` 中添加 `loginDevices()` 方法

#### 2. 日志表格通用页面
**文件**：
- `lib/pages/log_table/view.dart`
- `lib/pages/log_table/controller.dart`

**功能**：
- 通用的表格展示页面
- 支持登录记录、硬币记录、经验记录等多种日志类型
- 表格布局，带表头

#### 3. 登录记录
**文件**：
- `lib/pages/login_log/controller.dart`
- `lib/models/login_log/login_log_data.dart`
- `lib/models/login_log/login_log_item.dart`

**功能**：
- 显示登录时间、IP、地理位置
- 使用通用日志表格页面

**API**：
- 需要在 `lib/http/user.dart` 中添加 `loginLog()` 方法

#### 4. 硬币记录
**文件**：
- `lib/pages/coin_log/controller.dart`
- `lib/models/coin_log/coin_log_data.dart`
- `lib/models/coin_log/coin_log_item.dart`

**功能**：
- 显示硬币变化记录
- 使用通用日志表格页面

**API**：
- 需要在 `lib/http/user.dart` 中添加 `coinLog()` 方法

#### 5. 经验记录
**文件**：
- `lib/pages/exp_log/controller.dart`
- `lib/models/exp_log/exp_log_data.dart`
- `lib/models/exp_log/exp_log_item.dart`

**功能**：
- 显示经验值变化记录
- 使用通用日志表格页面

**API**：
- 需要在 `lib/http/user.dart` 中添加 `expLog()` 方法

#### 6. 空间设置
**文件**：
- `lib/pages/space_setting/view.dart`
- `lib/pages/space_setting/controller.dart`
- `lib/models/space_setting/space_setting_data.dart`
- `lib/models/space_setting/privacy.dart`
- `lib/models/space_setting/space_setting_model.dart`

**功能**：
- 显示空间隐私设置
- 分组显示多个开关选项
- 支持修改并保存设置

**API**：
- 需要在 `lib/http/user.dart` 中添加 `spaceSetting()` 和 `spaceSettingMod()` 方法

### 阶段二：更新路由和菜单

#### 1. 添加路由
在 `lib/router/app_pages.dart` 中添加：
- `/loginDevices` - 登录设备页面
- `/logTable` - 日志表格页面
- `/spaceSetting` - 空间设置页面

#### 2. 更新用户空间菜单
在 `lib/pages/member/view.dart` 的 `_buildActions` 方法中：
- 添加判断：仅在查看自己的空间时显示这些菜单项
- 添加菜单项：登录设备、登录记录、硬币记录、经验记录、空间设置

### 阶段三：API 实现

#### 1. 登录相关 API
在 `lib/http/login.dart` 中添加：
```dart
static Future loginDevices() async
```

#### 2. 用户相关 API
在 `lib/http/user.dart` 中添加：
```dart
static Future loginLog() async
static Future coinLog() async
static Future expLog() async
static Future spaceSetting() async
static Future spaceSettingMod(Map<String, int> settings) async
```

## UI 设计要点

### 登录设备页面
- 使用 ListTile 显示每个设备
- 标题：设备名称
- 副标题：最后登录时间 + 来源
- 尾部：当前设备标记 "(本机)"

### 日志表格页面
- 表格布局，带分隔线
- 表头固定，内容可滚动
- 支持文本选择
- 每列宽度可配置（flex）

### 空间设置页面
- 分组显示设置项
- 每组之间有分隔条
- 使用 Switch 开关
- 页面关闭时自动保存修改

## 注意事项

1. 所有页面都需要支持加载状态、错误状态、空数据状态
2. 使用 GetX 进行状态管理
3. 遵循项目现有的代码风格和架构
4. API 调用需要处理错误情况
5. 空间设置的修改需要在页面关闭时自动保存

## 实施顺序

1. 先实现通用的日志表格页面（因为多个功能会用到）
2. 实现登录设备页面（相对简单）
3. 实现三个日志记录页面（登录、硬币、经验）
4. 实现空间设置页面（最复杂）
5. 更新路由和菜单
6. 测试所有功能
