# 用户空间数据异常调试

## 问题描述
用户打开空间页面后显示"数据异常"，表示 `card` 或 `images` 为空。

## 根本原因
**API接口使用错误**：原本使用的是 Web API (`/x/space/wbi/acc/info`)，该API返回的是扁平的用户基本信息，不包含 `card` 和 `images` 嵌套结构。

**实际返回的字段**（Web API）：
```
[mid, name, sex, face, sign, rank, level, jointime, moral, silence, coins, 
fans_badge, official, vip, pendant, nameplate, top_photo, live_room, ...]
```

**期望的字段**（App API）：
```json
{
  "card": { "mid": "...", "name": "...", "face": "...", ... },
  "images": { "imgUrl": "...", "night_imgurl": "..." },
  "archive": { ... },
  "tab2": [ ... ],
  ...
}
```

## 已完成的修复

### 1. 切换到正确的API
**文件**: `lib/http/api.dart`

**修改前**:
```dart
// Web API - 返回扁平的用户信息
static const String memberSpace = '/x/space/wbi/acc/info';
```

**修改后**:
```dart
// App API - 返回包含card、images等完整数据
static const String memberSpace = '${HttpString.appBaseUrl}/x/v2/space';
```

### 2. 添加完整的App API参数
**文件**: `lib/http/member.dart`

**修改前**（缺少必需参数，导致-400错误）:
```dart
Map<String, dynamic> params = {
  'vmid': mid,
  'from_view_aid': fromViewAid,
};

var res = await Request().get(
  Api.memberSpace,
  data: params,
);
```

**修改后**（添加完整的App API参数）:
```dart
Map<String, dynamic> params = {
  'build': 2001100,
  'c_locale': 'zh_CN',
  'channel': 'yingyongbao',
  'mobi_app': 'android_hd',
  'platform': 'android',
  's_locale': 'zh_CN',
  'statistics': Constants.statistics,
  'vmid': mid,
};

if (fromViewAid != null) {
  params['from_view_aid'] = fromViewAid;
}

var res = await Request().get(
  Api.memberSpace,
  data: params,
  extra: {
    'headers': {
      'bili-http-engine': 'cronet',
      'user-agent': Constants.userAgent,
    },
  },
);
```

**添加导入**:
```dart
import '../common/constants.dart';
```

### 3. 修复 SpaceImages 字段名
**文件**: `lib/models/member/space_data.dart`

**问题**: `nightImgurl` 字段名不匹配
- JSON字段名: `night_imgurl` (下划线)
- Dart属性名: `nightImgurl` (驼峰)

**修复**: 更新 `SpaceImages.fromJson()` 使用正确的JSON字段名：
```dart
SpaceImages.fromJson(Map<String, dynamic>? json) {
  if (json == null) return;
  imgUrl = json['imgUrl'] as String?;
  nightImgurl = json['night_imgurl'] as String?;  // 使用下划线
}
```

## API对比

### Web API (`/x/space/wbi/acc/info`)
- **用途**: 获取用户基本信息
- **需要**: WBI签名
- **返回**: 扁平结构的用户信息
- **适用**: 简单的用户信息展示

### App API (`/x/v2/space`)
- **用途**: 获取用户空间完整数据
- **需要**: 仅需 vmid 参数
- **返回**: 嵌套结构，包含 card、images、archive、tab2 等
- **适用**: 完整的用户空间页面

## 测试步骤

1. **运行应用并打开用户空间**
   ```bash
   flutter run
   ```

2. **查看控制台日志**

   ```

   Response code: 0
   Raw data keys: [card, images, archive, tab2, ...]
   Card exists: true
   Card keys: [mid, name, face, ...]
   Images exists: true

   Card parsed: true
   Images parsed: true
   ==============================================
   ```

3. **验证功能**
   - 用户信息卡片正常显示
   - 背景图正常显示
   - Tab栏正常显示
   - 各个Tab内容正常加载
