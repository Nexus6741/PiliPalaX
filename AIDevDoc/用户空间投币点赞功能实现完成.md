# 用户空间投币和点赞视频功能实现完成

## 实现时间
2025-12-22

## 功能概述
为用户空间主页的"最近投币的视频"和"最近点赞的视频"添加"查看更多"功能，点击后跳转到专门的列表页面。

## 实现内容

### 1. API 层
**文件**: `lib/http/api.dart`
- 添加了两个新的 API 路径：
  - `spaceCoinArc`: `/x/v2/space/coinarc` - 用户投币视频列表
  - `spaceLikeArc`: `/x/v2/space/likearc` - 用户点赞视频列表

**文件**: `lib/http/member.dart`
- 添加了两个新的 API 方法：
  - `spaceCoinArc()`: 获取用户投币视频列表
  - `spaceLikeArc()`: 获取用户点赞视频列表
- 使用 App API，支持分页加载
- 自动添加 access_key 和 App 签名

### 2. 控制器层
**文件**: `lib/pages/member_coin/controller.dart`
- 实现了 `MemberCoinController`
- 功能：
  - 分页加载投币视频列表
  - 下拉刷新
  - 上拉加载更多
  - 加载状态管理

**文件**: `lib/pages/member_like/controller.dart`
- 实现了 `MemberLikeController`
- 功能：
  - 分页加载点赞视频列表
  - 下拉刷新
  - 上拉加载更多
  - 加载状态管理

### 3. 视图层
**文件**: `lib/pages/member_coin/view.dart`
- 实现了投币视频列表页面
- 使用网格布局展示视频卡片
- 支持下拉刷新和上拉加载更多
- 显示加载状态和错误提示

**文件**: `lib/pages/member_like/view.dart`
- 实现了点赞视频列表页面
- 使用网格布局展示视频卡片
- 支持下拉刷新和上拉加载更多
- 显示加载状态和错误提示

### 4. 路由配置
**文件**: `lib/router/app_pages.dart`
- 路由已存在：
  - `/memberCoin`: 投币视频列表页
  - `/memberLike`: 点赞视频列表页

### 5. 主页跳转
**文件**: `lib/pages/member_home/view.dart`
- 更新了 `_onMoreTap()` 方法
- 点击"查看更多"按钮时：
  - 投币视频：跳转到 `/memberCoin`
  - 点赞视频：跳转到 `/memberLike`
- 传递参数：
  - `mid`: 用户 ID
  - `name`: 用户名称

## 技术细节

### API 参数
```dart
{
  'build': 8430300,
  'version': '8.43.0',
  'c_locale': 'zh_CN',
  'channel': 'master',
  'mobi_app': 'android',
  'platform': 'android',
  's_locale': 'zh_CN',
  'vmid': mid,
  'pn': page,
  'ps': pageSize,
  'ts': timestamp,
  'access_key': accessKey, // 如果已登录
  'sign': appSign, // App 签名
}
```

### 数据模型
使用现有的 `SpaceArchiveItem` 模型，包含：
- `bvid`: 视频 BV 号
- `pic`/`cover`: 封面图片
- `title`: 视频标题
- `pubdate`: 发布时间
- `play`: 播放量
- `duration`: 视频时长
- `cid`: 视频 CID
- `param`: aid 的字符串形式

### 视频卡片
复用现有的 `VideoCardVMemberHome` 组件，支持：
- Hero 动画
- 视频信息展示
- 点击跳转到视频详情页
