# 专栏功能完整修复总结

## 修复的问题

### 1. ✅ 专栏内容无法加载
**问题**：搜索后打开专栏只显示标题，内容和评论都无法加载

**原因**：使用HTML爬取方式不稳定，容易被反爬虫拦截

**解决方案**：改用B站官方API `/x/article/view`

### 2. ✅ 浏览历史记录未上传
**问题**：浏览专栏后，历史记录页面看不到浏览记录

**原因**：
- 使用了错误的历史记录暂停状态检查键
- 缺少正确的Content-Type设置

**解决方案**：
- 使用`LocalCacheKey.historyPause`检查暂停状态
- 添加`Options(contentType: Headers.formUrlEncodedContentType)`

### 3. ✅ JSON格式专栏显示异常
**问题**：新版专栏（type=3）显示原始JSON字符串，无法阅读

**原因**：未处理JSON格式的专栏内容

**解决方案**：添加JSON到HTML的转换功能

```dart
// 添加历史记录上报方法
static Future historyReport({
  required int aid,
  int? type,  // 3=视频, 4=番剧, 5=专栏
}) async {
  var res = await Request().post(
    Api.historyReport,
    data: {
      'aid': aid,
      if (type != null) 'type': type,
      'csrf': await Request.getCsrf(),
    },
    options: Options(contentType: Headers.formUrlEncodedContentType),
  );
  return res;
}
```

## 技术细节

### API使用

#### 专栏内容API
```
GET https://api.bilibili.com/x/article/view?id={cvId}

响应：
{
  "code": 0,
  "data": {
    "id": 123456,
    "title": "标题",
    "content": "内容（HTML或JSON字符串）",
    "type": 0,  // 0=HTML, 3=JSON
    "author": {...},
    "stats": {...}
  }
}
```

#### 历史记录上报API
```
POST https://api.bilibili.com/x/v2/history/report
Content-Type: application/x-www-form-urlencoded

参数：
- aid: 专栏ID
- type: 5（专栏类型）
- csrf: CSRF Token
```

### JSON格式转换

新版专栏使用JSON格式存储内容：
```json
{
  "ops": [
    {
      "insert": "文本内容",
      "attributes": {
        "bold": true,
        "header": 2
      }
    }
  ]
}
```

转换为HTML：
```html
<h2><strong>文本内容</strong></h2>
```
