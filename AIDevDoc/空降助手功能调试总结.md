## 功能架构说明

### 核心文件
1. **数据模型层**
   - `lib/models/common/sponsor_block/segment_type.dart` - 片段类型定义
   - `lib/models/common/sponsor_block/skip_type.dart` - 跳过方式定义
   - `lib/models/common/sponsor_block/segment_model.dart` - 片段数据模型
   - `lib/models_new/sponsor_block/segment_item.dart` - API 返回数据模型

2. **网络请求层**
   - `lib/http/sponsor_block.dart` - SponsorBlock API 封装
   - `lib/http/sponsor_block_api.dart` - API 端点定义

3. **控制器层**
   - `lib/pages/video/controller.dart` - 视频播放控制器
     - `querySponsorBlock()` - 查询片段入口
     - `_querySponsorBlockSegments()` - 查询 SponsorBlock 数据
     - `_queryPgcSkipSegments()` - 查询番剧片头片尾
     - `_handleSegmentData()` - 处理片段数据
     - `_initSkipListener()` - 初始化播放位置监听
     - `_skipSegment()` - 执行跳过操作
     - `showSegmentDetail()` - 显示片段详情

4. **UI 层**
   - `lib/pages/video/widgets/header_control.dart` - 播放器控制栏
     - `submitSegmentButton()` - 提交片段按钮
     - `segmentInfoButton()` - 片段信息按钮
   - `lib/pages/sponsor_block/view.dart` - 设置页面

5. **配置层**
   - `lib/utils/storage.dart` - 存储键定义
   - `lib/pages/setting/extra_setting.dart` - 设置入口
   - `lib/router/app_pages.dart` - 路由配置

### 工作流程

```
1. 用户播放视频
   ↓
2. VideoDetailController.playerInit()
   ↓
3. 检查 enableBlock && autoplay
   ↓
4. 调用 querySponsorBlock()
   ↓
5. 根据视频类型选择数据源：
   - 普通视频 → _querySponsorBlockSegments() → SponsorBlock API
   - 番剧视频 → _queryPgcSkipSegments() → PGC API
   ↓
6. _handleSegmentData() 处理数据
   - 过滤片段（类型、长度）
   - 设置跳过方式
   - 添加到 segmentList
   ↓
7. _initSkipListener() 监听播放位置
   ↓
8. 检测到片段 → 根据 skipType 执行操作：
   - alwaysSkip → 自动跳过
   - skipOnce → 跳过一次
   - skipManually → 显示手动跳过按钮
   - showOnly → 仅显示不跳过
```

### 按钮显示逻辑

#### 提交片段按钮
- **显示条件**：`enableSponsorBlock == true`
- **位置**：全屏模式控制栏
- **功能**：打开片段提交面板（开发中）

#### 片段信息按钮
- **显示条件**：`segmentList.isNotEmpty`
- **位置**：全屏模式控制栏
- **功能**：显示当前视频的所有片段信息

## 用户调试步骤

### 第一步：启用功能
1. 打开应用
2. 进入 **设置 → 其他 → 空降助手**
3. 启用以下选项：
   - **启用 SponsorBlock**：开启（用于普通视频）
   - 或 **番剧自动跳过片头片尾**：开启（在播放设置中）

### 第二步：配置跳过方式
在空降助手设置页面：
1. 为每种片段类型选择跳过方式：
   - **自动跳过**：检测到立即跳过
   - **跳过一次**：每个片段只跳过一次
   - **手动跳过**：显示按钮，用户点击跳过
   - **仅显示**：不跳过，仅标记
   - **禁用**：不处理该类型片段

2. 推荐设置：
   - sponsor（赞助商）→ 自动跳过
   - intro（片头）→ 手动跳过
   - outro（片尾）→ 手动跳过
   - interaction（互动提醒）→ 自动跳过
   - selfpromo（自我推广）→ 手动跳过

### 第三步：测试功能
1. 播放一个视频（建议选择热门视频，更可能有数据）
2. 查看控制台日志输出
3. 进入全屏模式
4. 检查控制栏是否显示按钮

## 可能的问题和解决方案

### 问题 1：按钮不显示
**原因**：
- 提交按钮：`enableSponsorBlock` 未启用
- 信息按钮：`segmentList` 为空（视频无数据或被过滤）
- 未进入全屏模式

**解决方案**：
1. 检查设置是否启用
2. 换一个有数据的视频测试
3. 进入全屏模式查看

### 问题 2：不自动跳过
**原因**：
- 片段的 `skipType` 不是 `alwaysSkip` 或 `skipOnce`
- 播放位置监听未启动
- 片段时间不准确

**解决方案**：
1. 检查设置中该类型片段的跳过方式
2. 查看日志确认 `_initSkipListener()` 是否被调用
3. 手动点击信息按钮查看片段时间

### 问题 3：API 请求失败
**原因**：
- 网络问题
- SponsorBlock 服务器地址错误
- 视频 ID 格式错误

**解决方案**：
1. 检查网络连接
2. 在设置中检查服务器地址（默认应该正确）
3. 查看日志中的 bvid 和 cid 是否正确
