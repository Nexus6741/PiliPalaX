# 番剧分组合并修复完成

## 问题描述
下载同一番剧的多集后，它们没有合并在一起显示，而是分别显示为独立的项。

## 问题原因
番剧下载时没有传递 `seasonId` 和 `epInfo` 参数，导致：
1. `seasonId` 为 `null`
2. `pageId` 计算为 `avid.toString()`（因为 `seasonId ?? avid.toString()`）
3. 每集的 `avid` 不同，导致无法按 `seasonId` 分组

## 解决方案

### 1. 修改下载服务
**文件**: `lib/services/download_service.dart`

#### 添加参数
```dart
void downloadVideo({
  // ... 原有参数
  // 番剧相关参数
  String? seasonId,
  EpInfo? epInfo,
})
```

#### 使用参数
```dart
final entry = DownloadEntryInfo(
  // ... 其他字段
  seasonId: seasonId,
  ep: epInfo,
  // ...
);
```

### 2. 修改番剧控制器
**文件**: `lib/pages/video/introduction/bangumi/controller.dart`

#### 添加导入
```dart
import 'package:PiliPalaX/models/download/download_entry_info.dart';
```

#### 构建 EpInfo
```dart
void _startDownload(
  DownloadService downloadService,
  EpisodeItem currentEpisode,
  VideoQuality quality,
) {
  // 构建EpInfo
  final epInfo = EpInfo(
    avId: currentEpisode.aid!,
    page: 1,
    danmaku: 0,
    cover: currentEpisode.cover ?? '',
    episodeId: currentEpisode.id ?? 0,
    index: currentEpisode.title ?? '',
    indexTitle: currentEpisode.longTitle ?? '',
    showTitle: currentEpisode.longTitle,
    from: 'bangumi',
    seasonType: bangumiDetail.value.type ?? 1,
    width: 0,
    height: 0,
    rotate: 0,
    link: currentEpisode.link ?? '',
    bvid: currentEpisode.bvid ?? '',
    sortIndex: currentEpisode.id ?? 0,
  );

  downloadService.downloadVideo(
    // ... 其他参数
    seasonId: seasonId?.toString(),
    epInfo: epInfo,
  );
}
```

## 数据流

### 修复前
```
番剧第1集 (aid=123) → pageId = "123" → 独立显示
番剧第2集 (aid=456) → pageId = "456" → 独立显示
番剧第3集 (aid=789) → pageId = "789" → 独立显示
```

### 修复后
```
番剧 (seasonId=12345)
  ├─ 第1集 (aid=123, cid=111)
  ├─ 第2集 (aid=456, cid=222)
  └─ 第3集 (aid=789, cid=333)

pageId = seasonId = "12345" → 合并显示
```

## pageId 计算逻辑

```dart
String get pageId => seasonId ?? avid.toString();
```

- **番剧**：使用 `seasonId`（所有集相同）
- **普通视频**：使用 `avid`（分P相同）

## EpInfo 字段映射

| EpInfo 字段 | EpisodeItem 字段   | 说明              |
| ----------- | ------------------ | ----------------- |
| avId        | aid                | AV号              |
| episodeId   | id                 | 剧集ID            |
| index       | title              | 集数标题（如"1"） |
| indexTitle  | longTitle          | 长标题            |
| showTitle   | longTitle          | 显示标题          |
| cover       | cover              | 封面              |
| bvid        | bvid               | BV号              |
| link        | link               | 链接              |
| sortIndex   | id                 | 排序索引          |
| seasonType  | bangumiDetail.type | 番剧类型          |

## 测试场景

### 场景1：下载同一番剧的多集
1. 打开一个番剧（如《某番剧》，seasonId=12345）
2. 下载第1集（1080P）
3. 下载第2集（1080P）
4. 下载第3集（1080P）
5. 打开下载页面
6. **预期**：显示一个卡片"《某番剧》(3集)"
7. 点击展开
8. **预期**：显示"第1集"、"第2集"、"第3集"

### 场景2：下载同一集的多个画质
1. 打开番剧第1集
2. 下载1080P
3. 下载720P
4. 下载480P
5. 打开下载页面
6. **预期**：显示一个卡片"《某番剧》(1集)"
7. 点击展开
8. **预期**：显示"第1集 (3个画质)"
9. 点击第1集展开
10. **预期**：显示"1080P"、"720P"、"480P"

### 场景3：混合下载
1. 下载第1集的1080P和720P
2. 下载第2集的1080P
3. 下载第3集的1080P、720P、480P
4. 打开下载页面
5. **预期**：显示一个卡片"《某番剧》(3集)"
6. 点击展开
7. **预期**：
   - 第1集 (2个画质)
   - 第2集 (1080P)
   - 第3集 (3个画质)

## 与普通视频的对比

| 特性          | 普通视频          | 番剧             |
| ------------- | ----------------- | ---------------- |
| pageId        | avid              | seasonId         |
| 分组依据      | 同一视频的不同分P | 同一番剧的不同集 |
| ep 字段       | null              | EpInfo           |
| seasonId 字段 | null              | seasonId         |
| 选集标题      | "PX 标题"         | "第X集"          |
