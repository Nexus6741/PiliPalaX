# 空降助手启用开关添加完成

## 问题发现
通过调试日志发现问题根源：
```
🔍 enableBlock: true (enableSponsorBlock: false, enablePgcSkip: true)
🔍 [submitSegmentButton] enableSponsorBlock: false
🔍 [segmentInfoButton] segmentList.length: 0
```

**核心问题**：`enableSponsorBlock` 为 `false`，导致：
1. 提交片段按钮不显示（需要 `enableSponsorBlock: true`）
2. 不查询 SponsorBlock 数据（只查询番剧片头片尾）
3. `segmentList` 为空，信息按钮也不显示

## 根本原因
空降助手设置页面（`lib/pages/sponsor_block/view.dart`）缺少主开关！

原来的设置页面只有：
- 服务器状态
- 最小片段长度
- Toast 提示
- 追踪统计
- 用户信息
- 各类型片段的跳过方式

**缺少**：启用/禁用 SponsorBlock 的主开关

## 解决方案

### 修改文件
`lib/pages/sponsor_block/view.dart` 第 128-145 行

### 添加内容
在设置页面顶部添加主开关：

```dart
SliverToBoxAdapter(
  child: SwitchListTile(
    title: const Text('启用 SponsorBlock', style: titleStyle),
    subtitle: Text('自动跳过视频中的赞助商片段', style: subTitleStyle),
    value: GStorage.setting.get(SettingBoxKey.enableSponsorBlock, defaultValue: false),
    onChanged: (value) {
      setState(() {
        GStorage.setting.put(SettingBoxKey.enableSponsorBlock, value);
      });
    },
  ),
),
sliverDivider,
```

### 位置
放在最顶部，在"服务器状态"之前，这样用户一进入设置页面就能看到主开关。

## 与番剧跳过的关系

### 两个独立的功能
1. **SponsorBlock**（新增开关）
   - 用于普通视频
   - 跳过赞助商、互动提醒等
   - 需要手动启用

2. **番剧片头片尾跳过**（已有开关）
   - 用于番剧视频
   - 跳过片头片尾
   - 在"播放设置"中

### enableBlock 的逻辑
```dart
bool get enableBlock => enableSponsorBlock || enablePgcSkip;
```

只要有一个启用，`enableBlock` 就为 `true`，但：
- 普通视频只使用 SponsorBlock 数据
- 番剧视频只使用 PGC 片头片尾数据

## 常见问题

### Q1: 为什么之前没有这个开关？
A: 之前的实现遗漏了主开关，导致功能无法启用。

### Q2: 启用后还是不工作怎么办？
A: 检查：
1. 是否在全屏模式
2. 视频是否有 SponsorBlock 数据（尝试其他视频）
3. 片段类型是否设置为"禁用"

### Q3: 番剧跳过需要启用这个开关吗？
A: 不需要。番剧跳过使用独立的开关（在播放设置中）。

### Q4: 两个功能可以同时启用吗？
A: 可以。普通视频用 SponsorBlock，番剧用片头片尾跳过。
