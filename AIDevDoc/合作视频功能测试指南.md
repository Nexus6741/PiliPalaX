# 合作视频功能测试指南

1. 确保项目已编译成功
2. 确保已登录 B 站账号（关注功能需要登录）
3. 准备测试用的合作视频 BV 号

## 测试用合作视频示例

以下是一些可以用于测试的合作视频（请根据实际情况选择）：

- 搜索关键词："合作视频"、"联动"、"多人合作"
- 在 B 站首页查找带有"合作"标签的视频
- 查看知名 UP 主的合作视频

## 常见问题排查

### 问题1：UP 主列表不显示
**可能原因：**
- API 返回数据为空
- staff 字段解析失败
- UI 渲染逻辑错误

**排查步骤：**
1. 检查 API 返回数据
2. 检查 staff 字段是否正确解析
3. 检查 UI 渲染条件

### 问题2：关注状态不正确
**可能原因：**
- relations API 调用失败
- mid 参数错误
- 关注状态解析错误

**排查步骤：**
1. 检查 relations API 调用
2. 检查 mid 参数是否正确
3. 检查关注状态解析逻辑

### 问题3：+ 按钮不显示
**可能原因：**
- 关注状态查询失败
- UI 渲染条件错误
- 已关注该 UP 主

**排查步骤：**
1. 检查关注状态查询结果
2. 检查 UI 渲染条件
3. 确认是否已关注

### 问题4：点击无反应
**可能原因：**
- 点击事件未绑定
- 回调函数错误
- 网络请求失败

**排查步骤：**
1. 检查点击事件绑定
2. 检查回调函数逻辑
3. 检查网络请求状态
