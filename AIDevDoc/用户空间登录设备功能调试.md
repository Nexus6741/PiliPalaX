# 用户空间登录设备功能调试

## 调试时间
2024-12-22

## 问题描述

登录设备页面返回 -400 "请求错误"，其他页面（登录记录、硬币记录、经验记录、空间设置）都正常工作。

### 错误日志
```
Response code: -400
Response message: 请求错误
Response data keys: null
```

## API 信息

### 当前使用的 API
```
URL: https://passport.bilibili.com/x/safecenter/user_login_devices
Method: GET (已尝试改为 POST)
Parameters: csrf
```

### API 文档查找结果

在 `bilibili-API-collect` 文档中搜索，**没有找到** `user_login_devices` 这个 API 的文档。

找到的相关 API：
1. **登录记录查询** - `https://api.bilibili.com/x/safecenter/login_notice`
   - 需要参数：mid, buvid（可选）
   - 返回单次登录的详细信息

2. **最近一周登录情况** - `https://api.bilibili.com/x/member/web/login/log`
   - 参数：jsonp（可选）
   - 返回最近一周的登录记录列表

## 尝试的修复方案

### 方案 1：使用 GET 请求 + data 参数 ❌
```dart
var res = await Request().get(
  Api.loginDevices,
  data: {
    'csrf': csrf,
  },
);
```
**结果：** -400 请求错误

### 方案 2：使用 POST 请求 + queryParameters 🔄
```dart
var res = await Request().post(
  Api.loginDevices,
  queryParameters: {
    'csrf': csrf,
  },
);
```
**结果：** 待测试

## 可能的原因

1. **API 不存在或已废弃**
   - 文档中没有这个 API 的记录
   - 可能是 B 站内部 API，不对外开放

2. **需要特殊的认证方式**
   - 可能需要特定的 headers
   - 可能需要 App 端的签名

3. **参数不正确**
   - 可能需要其他必要参数
   - 可能参数格式不对

## 替代方案

如果 `user_login_devices` API 确实不可用，可以考虑：

### 方案 A：使用登录记录 API
使用 `https://api.bilibili.com/x/member/web/login/log` 替代，显示最近一周的登录记录。

**优点：**
- API 有文档支持
- 已经在项目中实现（登录记录页面）

**缺点：**
- 只显示登录记录，不是设备列表
- 功能略有不同

### 方案 B：隐藏登录设备功能
如果这个功能不是必需的，可以暂时隐藏这个菜单项。
