# 移除并发下载功能完成

## 问题背景

用户反馈在使用并发下载功能时遇到应用崩溃问题，经过分析发现并发下载功能的复杂状态管理可能是导致崩溃的根本原因。为了提高应用稳定性，决定移除并发下载功能，恢复为原来的单个下载队列模式。

## 修改内容

### 1. DownloadService 重构

#### 移除并发下载相关代码
- **移除**：`_activeDownloads` Map 和 `_DownloadTask` 类
- **移除**：`maxConcurrentDownloads` 属性和相关设置
- **移除**：`activeDownloadEntries` getter
- **移除**：`cancelSpecificDownload` 方法
- **恢复**：单个 `videoManager` 和 `audioManager`

#### 简化下载管理逻辑
```dart
// 单个下载管理
DownloadManager? videoManager;
DownloadManager? audioManager;

int? _curCid;
int? get curCid => _curCid;
final curDownload = Rxn<DownloadEntryInfo>();
```

#### 恢复原始的 startDownload 方法
- **修改前**：支持传入特定 entry，管理多个并发下载
- **修改后**：无参数方法，从队列中取出第一个进行下载

```dart
Future<void> startDownload() {
  return _lock.synchronized(() async {
    if (waitDownloadQueue.isEmpty) {
      return;
    }
    if (curDownload.value != null) {
      return;
    }

    final entry = waitDownloadQueue.removeAt(0);
    _curCid = entry.cid;
    curDownload.value = entry;

    try {
      await _startDownload(entry);
    } catch (e) {
      // 错误处理和下一个下载启动
    }
  });
}
```

#### 简化回调方法
- **_onReceive**：直接操作 `curDownload.value`，无需 cid 参数
- **_onDone**：简化为单个下载的完成处理
- **_onAudioDone**：移除复杂的并发状态判断

```dart
void _onReceive(int progress, int total) {
  final entry = curDownload.value;
  if (entry != null) {
    if (progress == 0 && total != 0) {
      entry.totalBytes.value = total;
      _updateBiliDownloadEntryJson(entry);
    }
    entry.downloadedBytes.value = progress;
    entry.status.value = DownloadStatus.downloading;
  }
}
```

#### 恢复原始的取消下载方法
```dart
Future<void> cancelDownload({
  required bool isDelete,
  bool downloadNext = true,
}) async {
  if (!isDelete && videoManager?.status == DownloadStatus.downloading) {
    curDownload.value?.status.value = DownloadStatus.pause;
  }
  await videoManager?.cancel(isDelete: isDelete);
  await audioManager?.cancel(isDelete: isDelete);
  if (!isDelete) {
    final entry = curDownload.value;
    if (entry != null) {
      await _updateBiliDownloadEntryJson(entry);
      entry.status.value = DownloadStatus.pause;
      waitDownloadQueue.insert(0, entry);
    }
  }
  _curCid = null;
  curDownload.value = null;
  videoManager = null;
  audioManager = null;
  if (downloadNext) {
    startDownload();
  }
}
```

```dart
// 暂停/继续按钮
onPressed: () async {
  try {
    if (status == DownloadStatus.downloading ||
        status == DownloadStatus.audioDownloading ||
        status == DownloadStatus.getDanmaku ||
        status == DownloadStatus.getPlayUrl) {
      // 暂停下载
      await _downloadService.cancelDownload(
        isDelete: false,

        status == DownloadStatus.wait) {
      // 继续下载
      await _downloadService.startDownload();

  }
```

## 优势分析

### 1. 稳定性提升
- **状态管理简化**：单个下载状态更容易管理
- **并发问题消除**：避免多线程和并发访问问题
- **崩溃风险降低**：减少复杂的异步操作交互

### 2. 代码维护性
- **代码简化**：移除大量并发管理代码
- **逻辑清晰**：下载流程更加直观
- **调试容易**：问题定位和修复更简单

### 3. 用户体验
- **界面简洁**：下载页面更加清爽
- **操作直观**：用户操作逻辑更简单
- **性能优化**：减少资源占用和UI更新频率

## 使用指南

### 下载多个视频
1. 在视频页面点击下载按钮
2. 视频会自动加入下载队列
3. 系统会按顺序一个接一个下载

### 管理下载队列
1. 在下载页面查看等待队列
2. 可以删除等待中的视频
3. 当前下载完成后自动开始下一个

### 控制下载
1. **暂停**：暂停当前下载，视频回到队列首位
2. **继续**：继续当前暂停的下载
3. **删除**：删除当前下载，开始下一个
