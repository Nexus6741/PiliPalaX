# 鸿蒙外部浏览器打开链接修复完成

## 问题描述
在应用内打开链接时，如果选择在外部浏览器打开会提示：
> 请在 launch 函数的 headers 参数中添加 harmony_browser_page 和对应的值，并在鸿蒙工程中增加对应的页面和配置路由

## 解决方案

### 1. 创建 LaunchInAppPage 页面
创建了 `ohos/entry/src/main/ets/pages/LaunchInAppPage.ets` 页面，用于在应用内打开网页链接。

页面功能：
- 使用 WebView 组件显示网页内容
- 提供返回按钮
- 监听 closeWebView 事件以支持关闭

### 2. 注册页面路由
在 `ohos/entry/src/main/resources/base/profile/main_pages.json` 中添加页面声明：
```json
{
  "src": [
    "pages/Index",
    "pages/LaunchInAppPage"
  ]
}
```

### 3. 修改所有 launchUrl 调用
为所有使用 `launchUrl` 的地方添加 `webViewConfiguration` 参数，包含 `harmony_browser_page` header：

```dart
launchUrl(
  Uri.parse(url),
  mode: LaunchMode.externalApplication,
  webViewConfiguration: WebViewConfiguration(
    headers: {'harmony_browser_page': 'pages/LaunchInAppPage'},
  ),
);
```

修改的文件：
- `lib/pages/webview/view.dart` - WebView 页面的外部浏览器打开按钮
- `lib/utils/utils.dart` - 应用更新下载和 GitHub 链接
- `lib/pages/video/introduction/detail/controller.dart` - 视频详情页的"其它app打开"
- `lib/pages/video/introduction/bangumi/controller.dart` - 番剧详情页的"其它app打开"
- `lib/pages/setting/pages/logs.dart` - 日志页面的反馈链接
- `lib/pages/about/index.dart` - 关于页面的所有外部链接（GitHub、网盘、QQ群、Telegram等）

## 技术细节

### url_launcher_ohos 插件工作原理
根据 `ohos/entry/oh_modules/url_launcher_ohos/src/main/ets/components/plugin/UrlLauncher.ets` 源码：

1. `openUrlInWebView` 方法会检查 headers 中是否包含 `harmony_browser_page` 参数
2. 如果没有该参数，会显示提示信息
3. 如果有该参数，使用 `router.pushUrl` 跳转到指定页面，并传递 url 和 options 参数
4. 如果页面不存在或未在 main_pages.json 中声明，会显示错误提示

### LaunchInAppPage 实现要点
- 使用 `router.getParams()` 获取传递的 url 参数
- 使用 `emitter.on("closeWebView")` 监听关闭事件
- 在 `aboutToDisappear` 中取消事件监听，避免内存泄漏
