## 实施内容

### 1. 创建 MemberOpusController
**文件**: `lib/pages/member_opus/controller.dart`

**功能**：
- 管理图文列表的加载状态
- 支持分页加载（使用offset游标）
- 支持下拉刷新和上拉加载更多
- 错误处理和状态管理

**关键特性**：
```dart
class MemberOpusController extends GetxController {
  final int mid;              // 用户ID
  int page = 1;               // 当前页码
  String offset = '';         // 游标偏移量
  RxBool isLoading = true.obs;
  RxBool isLoadingMore = false.obs;
  RxBool hasMore = true.obs;
  RxList opusList = [].obs;   // 图文列表
  RxString errorMsg = ''.obs;
}
```

**API调用**：
```dart
var res = await MemberHttp.memberOpus(
  hostMid: mid,
  page: page,
  offset: offset,
);
```

### 2. 创建 MemberOpusPage 视图
**文件**: `lib/pages/member_opus/view.dart`

**UI特性**：
- 使用 `DynamicPanel` 组件显示图文内容
- 支持下拉刷新（RefreshIndicator）
- 支持上拉加载更多（ScrollController监听）
- 加载状态指示器
- 错误处理和空状态显示
- 状态保持（AutomaticKeepAliveClientMixin）

**布局结构**：
```
RefreshIndicator

      ├─ DynamicPanel (图文1)

```

### 3. 添加 memberOpus API 方法
**文件**: `lib/http/member.dart`

**API信息**：
- **端点**: `/x/polymer/web-dynamic/v1/opus/feed/space`
- **方法**: GET
- **签名**: 需要WbiSign签名

**参数**：
```dart
{
  'host_mid': hostMid,    // 用户ID
  'page': page,           // 页码
  'offset': offset,       // 游标偏移量
  'type': type,           // 类型（默认'all'）
  'web_location': 333.1387,
  'w_rid': xxx,           // WBI签名
  'wts': xxx,             // WBI时间戳
}
```

**响应数据**：
```json
{
  "code": 0,
  "message": "0",
  "data": {
    "items": [...],      // 图文列表
    "offset": "xxx",     // 下一页偏移量
    "has_more": true     // 是否有更多
  }
}
```

## 技术要点

### 1. 复用动态组件
图文内容使用现有的 `DynamicPanel` 组件显示，因为图文本质上是一种特殊的动态类型。这样可以：
- 复用已有的UI组件
- 保持界面一致性
- 减少开发工作量

### 2. 游标分页
使用offset游标而不是传统的页码分页：
```dart
// 第一页
offset = '';

// 后续页
offset = response['offset'];  // 从上一次响应中获取
```

### 3. WBI签名
图文API需要WBI签名：
```dart
Map params = await WbiSign().makSign(data);
// 添加 w_rid 和 wts 到请求参数
```

### 4. 状态保持
使用 `AutomaticKeepAliveClientMixin` 保持页面状态：
```dart
class _MemberOpusPageState extends State<MemberOpusPage>
    with AutomaticKeepAliveClientMixin {
  @override
  bool get wantKeepAlive => true;
}
```

### 5. 滚动监听
监听滚动位置，接近底部时自动加载更多：
```dart
void _onScroll() {
  if (_scrollController.position.pixels >=
      _scrollController.position.maxScrollExtent - 200) {
    _controller.onLoadMore();
  }
}
```

## 与PiliPlus的对比

### 相同点
1. ✅ 使用相同的API端点
2. ✅ 使用WBI签名
3. ✅ 使用offset游标分页
4. ✅ 支持下拉刷新和上拉加载更多

### 差异点
1. **UI组件** - PiliPlus使用瀑布流布局，我们使用列表布局
2. **筛选功能** - PiliPlus支持类型筛选（全部图文、视频图文等），我们暂未实现
3. **骨架屏** - PiliPlus有专门的骨架屏，我们使用CircularProgressIndicator

### 简化原因
1. **复用现有组件** - 使用DynamicPanel可以快速实现
2. **保持一致性** - 与动态页面的UI保持一致
3. **减少开发时间** - 优先实现核心功能
