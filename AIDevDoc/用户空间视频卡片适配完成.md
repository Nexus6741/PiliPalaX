# 用户空间视频卡片适配完成

## 问题描述

用户空间主页Tab使用 `VideoCardH` 组件显示视频时报错：
```
type 'Null' is not a subtype of type 'String'
```

**原因分析**：
- `VideoCardH` 组件要求 `videoItem` 必须有特定的字段结构：
  - `aid`: int (非空)
  - `bvid`: String (非空)
  - `pic`: String (非空)
  - `owner.name`: String
  - `stat.view`: int
  - `stat.danmu`: int
- 但 `SpaceArchiveItem` 模型的字段可能为 null，且缺少 `owner` 和 `stat` 对象

## 解决方案

创建适配器类 `SpaceArchiveItemAdapter`，将 `SpaceArchiveItem` 转换为 `VideoCardH` 可用的格式。

### 1. 创建适配器类

在 `lib/models/member/space_data.dart` 中添加：

```dart
// VideoCardH 适配器 - 将 SpaceArchiveItem 转换为 VideoCardH 可用的格式
class SpaceArchiveItemAdapter {
  final SpaceArchiveItem item;

  SpaceArchiveItemAdapter(this.item);

  // VideoCardH 需要的字段
  int get aid => item.aid ?? 0;
  String get bvid => item.bvid ?? '';
  String get pic => item.pic ?? '';
  String get title => item.title ?? '';
  int? get pubdate => item.pubdate;
  int get duration => item.duration ?? 0;
  int? get cid => item.cid;
  String get type => 'video';

  // VideoCardH 需要的 owner 对象
  _Owner get owner => _Owner();

  // VideoCardH 需要的 stat 对象
  _Stat get stat => _Stat(item.play ?? 0);
}

// 空的 owner 对象（用户空间视频不显示 owner）
class _Owner {
  String get name => '';
}

// 简单的 stat 对象
class _Stat {
  final int view;
  _Stat(this.view);
  int get danmu => 0; // 用户空间 API 不返回弹幕数
}
```

### 2. 更新视图使用适配器

在 `lib/pages/member_home/view.dart` 中，将所有 `VideoCardH` 的 `videoItem` 参数包装为适配器：

```dart
// 视频投稿
VideoCardH(
  videoItem: SpaceArchiveItemAdapter(
    spaceData.archive!.item![index],
  ),
  showOwner: false,
)

// 最近投币的视频
VideoCardH(
  videoItem: SpaceArchiveItemAdapter(
    spaceData.coinArchive!.item![index],
  ),
  showOwner: false,
)

// 最近点赞的视频
VideoCardH(
  videoItem: SpaceArchiveItemAdapter(
    spaceData.likeArchive!.item![index],
  ),
  showOwner: false,
)
```

## 技术要点

### 适配器模式优势
1. **类型安全**：确保所有必需字段都有非空值
2. **解耦**：不修改原有的 `SpaceArchiveItem` 和 `VideoCardH` 代码
3. **灵活性**：可以轻松添加默认值或转换逻辑
4. **可维护性**：集中管理数据转换逻辑

### 字段映射
- `aid`, `bvid`, `pic`, `title`, `duration`: 直接映射，null 时提供默认值
- `owner`: 创建空对象（因为 `showOwner: false`）
- `stat.view`: 从 `item.play` 映射
- `stat.danmu`: 固定为 0（用户空间 API 不返回弹幕数）

## 修改文件

1. `lib/models/member/space_data.dart` - 添加适配器类
2. `lib/pages/member_home/view.dart` - 使用适配器包装视频数据
