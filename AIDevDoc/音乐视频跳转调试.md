## 可能的问题

### 1. bvid或cid为空
如果看到：
```
❌ 参数无效，取消跳转
```
说明videoItem的bvid或cid字段为null或0。

**解决方案**: 检查API返回的数据是否包含这些字段。

### 2. 路由跳转失败
如果日志显示"✅ Get.toNamed 调用完成"但页面白屏，可能是：
- 路由配置问题
- 视频控制器初始化失败
- arguments格式不正确

### 3. videoItem字段缺失
视频控制器期望videoItem有以下字段：
- `pic`: 封面图片URL
- `dimension`: 视频尺寸（可选）
- `rcmdReason`: 推荐理由（可选）

BgmRecommend模型有：
- `cover`: 封面图片URL
- `title`: 标题
- `bvid`, `cid`, `aid`: 视频ID
- `upNickName`: UP主昵称
- `play`, `danmu`: 播放量、弹幕数

**可能的问题**: BgmRecommend使用`cover`字段，而视频控制器期望`pic`字段。

## 下一步调试

根据日志输出判断：

### 情况1: 参数无效
检查API返回的数据结构，确认bvid和cid字段存在。

### 情况2: 跳转成功但白屏
需要在视频控制器中添加日志，查看：
1. Get.parameters是否正确接收到bvid和cid
2. Get.arguments是否正确接收到videoItem
3. videoItem的字段是否符合预期

### 情况3: videoItem字段不匹配
需要创建一个适配器，将BgmRecommend转换为视频控制器期望的格式：

```dart
Map<String, dynamic> _convertToVideoItem(BgmRecommend item) {
  return {
    'pic': item.cover,
    'title': item.title,
    'bvid': item.bvid,
    'cid': item.cid,
    'aid': item.aid,
    'owner': {
      'name': item.upNickName,
      'mid': item.mid,
    },
    'stat': {
      'view': item.play,
      'danmu': item.danmu,
    },
    'duration': item.duration,
  };
}
```
