# 视频缓存画质选项和标题显示修复完成

## 问题描述

用户反馈了两个关于视频缓存功能的问题：

1. **画质选项固定问题**：缓存视频时画质选项总是固定的4个选项，但每个视频的可用画质应该是不同的
2. **低画质视频标题显示问题**：缓存低画质视频时，在下载列表中显示的不是视频标题，而是其他信息

## 修复方案

### 1. 画质选项动态获取

**修改文件**：`lib/pages/video/introduction/detail/controller.dart`

**修复内容**：
- 添加了 `actionDownloadVideo()` 方法（之前缺失）
- 在显示画质选择对话框前，先调用 `VideoHttp.videoUrl()` 获取视频的真实可用画质列表
- 使用 `PlayUrlModel.supportFormats` 动态生成画质选项
- 每个画质选项显示真实的描述信息（如 `format.newDesc` 或 `quality.description`）

**关键代码**：
```dart
// 获取视频真实可用的画质列表
final res = await VideoHttp.videoUrl(
  bvid: bvid,
  cid: currentPage.cid!,
);

final PlayUrlModel playUrlData = res['data'];
final List<FormatItem>? supportFormats = playUrlData.supportFormats;

// 动态生成画质选项
children: supportFormats.map((format) {
  final quality = VideoQualityCode.fromCode(format.quality!);
  if (quality == null) return const SizedBox.shrink();
  
  return ListTile(
    title: Text(format.newDesc ?? quality.description),
    onTap: () {
      Get.back();
      _startDownload(downloadService, currentPage!, quality);
    },
  );
}).toList(),
```

### 2. 视频标题显示修复

**修改文件**：`lib/models/download/download_entry_info.dart`

**问题原因**：
- `showTitle` getter 优先显示 `pageData.part` 而不是 `title`
- 对于低画质视频，`part` 字段可能包含技术信息而不是用户友好的标题

**修复内容**：
- 修改 `showTitle` 逻辑，优先显示主标题 `title`
- 只有在主标题为空时才使用 `part` 作为备选
- 添加了更好的默认值处理

**修复前**：
```dart
String get showTitle {
  if (pageData != null) {
    final pd = pageData!;
    return pd.part?.isNotEmpty == true ? pd.part! : title;  // 优先显示part
  }
  // ...
}
```

**修复后**：
```dart
String get showTitle {
  // 优先显示主标题，只有在主标题为空时才使用part
  if (title.isNotEmpty) {
    return title;
  }
  
  if (pageData != null) {
    final pd = pageData!;
    return pd.part?.isNotEmpty == true ? pd.part! : 'Unknown Video';
  }
  // ...
}
```

## 修复效果

### 1. 画质选项动态化
- ✅ 每个视频显示其真实可用的画质选项

### 2. 标题显示统一化

- ✅ 提供了更好的默认值处理
