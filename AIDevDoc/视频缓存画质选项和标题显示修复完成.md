# 视频缓存画质选项和标题显示修复完成

## 问题描述

用户反馈两个问题：
1. **同一个视频不能下载多个画质** - 如果已经下载了1080p画质，就不能再下载720p或4K等其他画质
2. **缓存卡片缺少画质信息** - 用户无法知道下载的视频是什么画质

## 问题分析

### 根本原因
1. **重复检查逻辑问题**：下载服务只检查 `cid`，没有考虑画质差异
2. **目录结构问题**：不同画质的视频存储在相同目录，会产生冲突
3. **UI显示缺失**：界面没有显示画质信息

### 原有逻辑
```dart
// 只检查 cid，不考虑画质
if (downloadList.indexWhere((e) => e.cid == cid) != -1) {
  SmartDialog.showToast('该视频已在下载列表中');
  return;
}
```

## 修复内容

### 1. 修改重复检查逻辑

#### 下载服务修改
```dart
// 修改前：只检查 cid
if (downloadList.indexWhere((e) => e.cid == cid) != -1) {
  SmartDialog.showToast('该视频已在下载列表中');
  return;
}

// 修改后：同时检查 cid 和画质
if (downloadList.indexWhere((e) => e.cid == cid && e.preferedVideoQuality == videoQuality.code) != -1) {
  SmartDialog.showToast('该画质视频已在下载列表中');
  return;
}
```

#### 相等性判断修改
```dart
// DownloadEntryInfo 类
@override
bool operator ==(Object other) {
  if (identical(this, other)) {
    return true;
  }
  if (other is DownloadEntryInfo) {
    // 修改前：只比较 cid
    // return cid == other.cid;
    
    // 修改后：同时比较 cid 和画质
    return cid == other.cid && preferedVideoQuality == other.preferedVideoQuality;
  }
  return false;
}

@override
int get hashCode => Object.hash(cid, preferedVideoQuality);
```

### 2. 修改存储目录结构

#### 目录命名规则
```dart
// 修改前：不区分画质
pageDirName = 'c_${page.cid}';           // 普通视频
pageDirName = ep.episodeId.toString();   // 番剧视频

// 修改后：包含画质信息
pageDirName = 'c_${page.cid}_${entry.preferedVideoQuality}';     // 普通视频
pageDirName = '${ep.episodeId}_${entry.preferedVideoQuality}';   // 番剧视频
```

## 使用指南

### 下载多个画质
1. 在视频播放页面选择画质（如1080p）
2. 点击下载按钮，视频加入下载队列
3. 再次选择不同画质（如720p）
4. 点击下载按钮，新画质也会加入队列
5. 两个画质的视频会分别下载和存储

### 识别画质信息
1. **正在下载**：画质标签显示在状态信息前面
2. **等待队列**：画质标签显示在"等待中"前面
3. **已下载**：画质标签显示在UP主信息前面
4. **合集视频**：显示包含的所有画质类型

### 画质标签说明
- **1080P+**：1080p高清
- **720P**：720p标清
- **480P**：480p流畅
- **4K**：4K超清
- **8K**：8K超高清

## 技术要点

### 1. 唯一性标识
- **修改前**：只使用 `cid` 作为唯一标识
- **修改后**：使用 `cid + preferedVideoQuality` 组合标识

### 2. 目录结构
- **普通视频**：`avid/c_cid_quality/`
- **番剧视频**：`seasonId/episodeId_quality/`
- **画质目录**：`quality/index.json + video.m4s + audio.m4s`

### 3. UI组件
- **画质容器**：使用 `primaryContainer` 背景色
- **文字颜色**：使用 `onPrimaryContainer` 确保对比度
- **圆角设计**：统一使用4px圆角
- **字体大小**：根据显示区域调整（10-11px）
