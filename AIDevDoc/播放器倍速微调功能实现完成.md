# 播放器倍速微调功能实现完成

## 功能概述
在播放器底部控制栏的倍速区域左右两边添加了 `-` 和 `+` 按钮，支持以 0.1 的幅度精细调节视频播放速度。

## 实现位置
- **文件**: `lib/plugin/pl_player/view.dart`
- **区域**: `BottomControlType.speed` 控件

## 功能特性

### 1. 界面布局
- **左侧**: `-` 减速按钮（宽度 32px）
- **中间**: 原有的倍速显示和菜单选择（宽度 42px）
- **右侧**: `+` 加速按钮（宽度 32px）

### 2. 调节规则
- **调节幅度**: 每次点击增加或减少 0.1 倍速
- **速度范围**: 0.5x ~ 3.0x（使用 `clamp` 限制）
- **精度控制**: 保留一位小数，避免浮点数精度问题

### 3. 交互体验
- 使用 `InkWell` 提供点击水波纹效果
- 按钮透明背景，与播放器控制栏风格一致
- 支持无障碍功能（semanticsLabel）

## 代码实现

### 减速按钮
```dart
SizedBox(
  width: 32,
  height: 30,
  child: Material(
    color: Colors.transparent,
    child: InkWell(
      onTap: () {
        double currentSpeed = _.playbackSpeed;
        double newSpeed = (currentSpeed - 0.1).clamp(0.5, 3.0);
        newSpeed = double.parse(newSpeed.toStringAsFixed(1));
        _.setPlaybackSpeed(newSpeed);
      },
      child: Container(
        alignment: Alignment.center,
        child: const Text("-", ...),
      ),
    ),
  ),
),
```

### 加速按钮
```dart
SizedBox(
  width: 32,
  height: 30,
  child: Material(
    color: Colors.transparent,
    child: InkWell(
      onTap: () {
        double currentSpeed = _.playbackSpeed;
        double newSpeed = (currentSpeed + 0.1).clamp(0.5, 3.0);
        newSpeed = double.parse(newSpeed.toStringAsFixed(1));
        _.setPlaybackSpeed(newSpeed);
      },
      child: Container(
        alignment: Alignment.center,
        child: const Text("+", ...),
      ),
    ),
  ),
),
```

## 使用说明

### 基本操作
1. 播放视频时，在底部控制栏找到倍速区域
2. 点击 `-` 按钮降低播放速度（每次 -0.1）
3. 点击 `+` 按钮提高播放速度（每次 +0.1）
4. 点击中间的倍速显示可打开菜单快速选择预设倍速

### 示例场景
- **从 1.0x 调整到 1.3x**: 点击 `+` 按钮 3 次
- **从 2.0x 调整到 1.5x**: 点击 `-` 按钮 5 次
- **达到最小值 0.5x**: 继续点击 `-` 不会低于 0.5x
- **达到最大值 3.0x**: 继续点击 `+` 不会高于 3.0x

## 技术细节

### 1. 浮点数精度处理
使用 `toStringAsFixed(1)` 和 `double.parse()` 确保倍速值精确到一位小数，避免出现 1.2999999 这样的浮点数误差。

### 2. 边界限制
使用 `clamp(0.5, 3.0)` 方法确保倍速值始终在合理范围内，与系统预设倍速范围保持一致。

### 3. 状态同步
调用 `_.setPlaybackSpeed(newSpeed)` 方法，确保：
- 视频播放器实际倍速更新
- UI 显示的倍速值同步更新
- 倍速设置可能被保存（取决于原有逻辑）

## 兼容性
- 与原有的倍速菜单选择功能完全兼容
- 不影响长按倍速功能
- 不影响默认倍速设置
- 支持直播和点播视频
