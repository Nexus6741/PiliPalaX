# 历史记录Tab分类功能测试指南

## 测试环境准备
1. 确保已登录账号
2. 确保账号有历史记录数据（包含视频、直播、专栏等不同类型）

## 功能测试清单

### 1. Tab显示测试
- [ ] 打开历史记录页面
- [ ] 检查是否显示Tab栏（全部、视频、直播、专栏）
- [ ] 检查Tab标签文字是否正确
- [ ] 检查默认选中"全部"Tab

### 2. Tab切换测试
- [ ] 点击"视频"Tab，检查是否显示视频类型的历史记录
- [ ] 点击"直播"Tab，检查是否显示直播类型的历史记录
- [ ] 点击"专栏"Tab，检查是否显示专栏类型的历史记录
- [ ] 点击"全部"Tab，检查是否显示所有类型的历史记录
- [ ] 滑动切换Tab，检查是否正常工作

### 3. 数据加载测试
- [ ] 在"全部"Tab下拉刷新，检查数据是否更新
- [ ] 在"全部"Tab上拉加载更多，检查是否加载下一页
- [ ] 切换到"视频"Tab，检查是否自动加载数据
- [ ] 在"视频"Tab下拉刷新，检查数据是否更新
- [ ] 在"视频"Tab上拉加载更多，检查是否加载下一页

### 4. 状态保持测试
- [ ] 在"全部"Tab滚动到中间位置
- [ ] 切换到"视频"Tab
- [ ] 再切换回"全部"Tab，检查滚动位置是否保持
- [ ] 在"视频"Tab滚动到底部
- [ ] 切换到"直播"Tab再切回，检查"视频"Tab滚动位置是否保持

### 5. 多选功能测试
- [ ] 在"全部"Tab点击菜单 -> 多选删除
- [ ] 检查AppBar是否切换为多选模式
- [ ] 选择几个历史记录
- [ ] 检查顶部是否显示"已选择X项"
- [ ] 点击"全选"，检查是否全部选中
- [ ] 点击"删除"，检查是否删除成功
- [ ] 点击"取消"，检查是否退出多选模式

### 6. 多选Tab切换测试
- [ ] 在"全部"Tab进入多选模式
- [ ] 尝试滑动切换Tab，检查是否被禁用
- [ ] 点击"视频"Tab标签
- [ ] 检查"全部"Tab的多选模式是否自动取消
- [ ] 检查"视频"Tab是否正常显示（非多选模式）

### 7. 删除功能测试
- [ ] 在"全部"Tab长按某个历史记录删除
- [ ] 检查该记录是否从列表中移除
- [ ] 切换到对应类型的Tab（如"视频"）
- [ ] 检查该记录是否也被移除
- [ ] 在"视频"Tab删除一个记录
- [ ] 切换到"全部"Tab，检查该记录是否也被移除

### 8. 菜单功能测试
- [ ] 在"全部"Tab点击菜单 -> 暂停观看记录
- [ ] 检查是否显示确认对话框
- [ ] 确认暂停，检查是否成功
- [ ] 切换到"视频"Tab，检查菜单是否显示"恢复观看记录"
- [ ] 点击菜单 -> 清空观看记录
- [ ] 检查是否显示确认对话框
- [ ] 确认清空，检查所有Tab的数据是否清空
- [ ] 点击菜单 -> 删除已看记录
- [ ] 检查是否删除进度为-1的记录

### 9. 搜索功能测试
- [ ] 点击搜索图标
- [ ] 检查是否跳转到搜索页面
- [ ] 搜索功能是否正常工作

### 10. 返回键测试
- [ ] 在非多选模式下按返回键，检查是否正常退出
- [ ] 进入多选模式
- [ ] 按返回键，检查是否退出多选模式（而不是退出页面）
- [ ] 再次按返回键，检查是否退出页面

### 11. 边界情况测试
- [ ] 在没有历史记录的Tab（如"专栏"），检查是否显示空状态
- [ ] 在网络断开的情况下切换Tab，检查错误提示
- [ ] 快速切换Tab，检查是否有数据混乱
- [ ] 在加载中切换Tab，检查是否正常处理
