# 图片预览功能全面升级完成

## 实现概述

将项目中所有长按直接保存图片的功能统一升级为长按弹出图片预览弹窗，然后手动选择保存，与 PiliPlus 保持一致的交互体验。

## 核心改动

### 1. 创建通用图片预览组件

**文件**: `lib/common/widgets/image_preview_dialog.dart`

创建了一个通用的图片预览对话框组件，提供以下功能：
- 全屏黑色背景的图片预览
- 双击缩放（1x ↔ 2x）
- 手势缩放（最大 5x）和拖拽
- 底部操作栏，包含：
  - 标题显示
  - 复制链接按钮
  - 保存图片按钮（右下角）
  - 关闭按钮
- 加载进度显示

**便捷方法**:
```dart
showImagePreviewDialog({
  required String imageUrl,
  String? title,
  String? imgType,
});
```

## 功能特性

### 图片预览界面

1. **手势操作**
   - 双击：在 1x 和 2x 之间切换缩放
   - 捏合：自由缩放（1x - 5x）
   - 拖拽：移动查看图片细节

2. **底部操作栏**
   - 左侧显示标题（如果有）
   - 右侧操作按钮：
     - 🔗 复制链接：复制图片 URL 到粘贴板
     - ⬇️ 保存图片：保存到手机相册（右下角位置，与 PiliPlus 一致）
     - ✕ 关闭：关闭预览

3. **加载状态**
   - 显示加载进度条
   - 白色进度指示器

### 保存功能

- 自动处理权限请求
- 显示下载和保存进度提示
- 保存到 `Pictures/PiliPalaX` 目录
- 文件名格式：`{imgType}_{时间戳}.jpg`

## 交互流程

### 旧版本（直接保存）
```
长按封面 → 直接下载保存 → 显示保存结果
```

### 新版本（预览后保存）
```
长按封面 → 弹出预览弹窗 → 查看/缩放图片 → 点击保存按钮 → 下载保存 → 显示保存结果
```

## 技术实现

### 依赖库
- `extended_image`: 图片手势操作和缩放
- `get`: 路由导航
- `flutter_smart_dialog`: 提示信息

### 关键代码

**添加长按预览**:
```dart
onLongPress: () {
  showImagePreviewDialog(
    imageUrl: imageUrl,
    title: title,
    imgType: 'cover',
  );
}
```

**双击缩放动画**:
```dart
ExtendedImage.network(
  imageUrl,
  mode: ExtendedImageMode.gesture,
  onDoubleTap: (state) {
    // 处理双击缩放逻辑
  },
  initGestureConfigHandler: (state) {
    return GestureConfig(
      initialScale: 1.0,
      maxScale: 5.0,
      animationMaxScale: 6.0,
    );
  },
)
```

## 兼容性处理

### 保留自定义回调
对于 `VideoCardV` 和 `VideoCardH`，保留了 `longPress` 参数：
```dart
onLongPress: () {
  if (longPress != null) {
    longPress!();  // 使用自定义回调
  } else {
    showImagePreviewDialog(...);  // 默认行为
  }
}
```

### 条件预览
对于图文卡片，只在有图片时才启用长按预览：
```dart
onLongPress: hasPic
    ? () {
        showImagePreviewDialog(...);
      }
    : null,
```
