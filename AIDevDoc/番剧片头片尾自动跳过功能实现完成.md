# 番剧片头片尾自动跳过功能实现完成

## 功能概述

参考 PiliPlus 项目的实现，为 PiliPalaX 添加了自动跳过番剧片头片尾的功能。该功能支持：

1. **番剧片头片尾自动跳过**：播放番剧时自动识别并跳过片头（OP）和片尾（ED）
2. **多种跳过模式**：支持总是跳过、跳过一次、手动跳过、仅显示、禁用等模式
3. **SponsorBlock 支持**：预留了 SponsorBlock API 接口，可用于普通视频的片段跳过（需要服务器支持）

## 修复的编译错误

1. **sponsor_block_api.dart**：移除了 `abstract final class` 语法（需要 Dart 3.0+），改为普通 `class`
2. **segment_item.dart**：将 switch 表达式改为传统的 if-else 语句，避免语法兼容性问题

## 实现细节

### 1. 数据模型

创建了以下模型文件：

#### `lib/models/common/sponsor_block/segment_type.dart`
定义了片段类型枚举，包括：
- `intro` - 片头/开场动画
- `outro` - 片尾/结束画面
- `sponsor` - 赞助广告
- `selfpromo` - 自我推广
- `interaction` - 订阅提醒
- `preview` - 预览
- `music_offtopic` - 非音乐部分
- `poi_highlight` - 精彩时刻
- `filler` - 闲聊
- `exclusive_access` - 品牌合作

#### `lib/models/common/sponsor_block/skip_type.dart`
定义了跳过类型枚举：
- `alwaysSkip` - 总是跳过
- `skipOnce` - 跳过一次
- `skipManually` - 手动跳过
- `showOnly` - 仅显示
- `disable` - 禁用

#### `lib/models/common/sponsor_block/segment_model.dart`
片段模型，包含：
- UUID - 片段唯一标识
- segmentType - 片段类型
- segmentStart - 开始时间（毫秒）
- segmentEnd - 结束时间（毫秒）
- skipType - 跳过类型
- hasSkipped - 是否已跳过标记

#### `lib/models_new/sponsor_block/segment_item.dart`
API 返回的片段数据模型，支持：
- 从 SponsorBlock API 解析数据
- 从番剧 API 的 `clip_info_list` 解析片头片尾数据

### 2. HTTP 接口

#### `lib/http/sponsor_block.dart`
实现了 SponsorBlock API 接口：
- `getSkipSegments()` - 获取跳过片段
- `voteOnSponsorTime()` - 投票
- `viewedVideoSponsorTime()` - 标记已观看
- `uptimeStatus()` - 检查服务器状态
- `userInfo()` - 获取用户信息

### 3. 核心逻辑

#### 视频控制器 (`lib/pages/video/controller.dart`)

添加了以下功能：

1. **片段查询**
   - `querySponsorBlock()` - 主查询方法
   - `_queryPgcSkipSegments()` - 查询番剧片头片尾
   - `_querySponsorBlockSegments()` - 查询 SponsorBlock 片段

2. **片段处理**
   - `_handleSegmentData()` - 处理片段数据
   - 根据片段类型和设置决定跳过方式
   - 检查片段长度，太短的片段只显示不跳过

3. **跳过执行**
   - `_initSkipListener()` - 初始化播放位置监听
   - `_skipSegment()` - 执行跳过操作
   - `_showSkipButton()` - 显示手动跳过按钮

4. **生命周期管理**
   - 在 `playerInit()` 中调用 `querySponsorBlock()`
   - 在 `onClose()` 中取消监听

### 4. 配置选项

#### 存储配置 (`lib/utils/storage.dart`)

添加了以下配置键：
- `enableSponsorBlock` - 启用 SponsorBlock
- `enablePgcSkip` - 启用番剧跳过
- `pgcSkipType` - 番剧跳过类型
- `blockServer` - SponsorBlock 服务器地址
- `blockUserID` - SponsorBlock 用户 ID
- `blockSettings` - 片段跳过设置
- `blockLimit` - 最小跳过时长（秒）
- `blockToast` - 显示跳过提示
- `blockTrack` - 追踪跳过记录

#### 播放设置页面 (`lib/pages/setting/play_setting.dart`)

添加了以下设置项：
1. **番剧自动跳过片头片尾** - 开关
2. **番剧跳过方式** - 选择跳过模式（总是跳过/跳过一次/手动跳过/仅显示/禁用）

### 5. 数据结构扩展

#### `lib/models/video/play/url.dart`

在 `Dash` 类中添加了 `clipInfoList` 字段，用于存储番剧 API 返回的片头片尾信息：

```dart
List<Map<String, dynamic>>? clipInfoList;
```

## 工作流程

1. **视频加载**
   - 用户打开番剧视频
   - `playerInit()` 初始化播放器
   - 调用 `querySponsorBlock()` 查询片段信息

2. **片段查询**
   - 如果是番剧，从 `data.dash.clipInfoList` 获取片头片尾信息
   - 如果启用 SponsorBlock，从 API 获取片段信息
   - 解析数据并创建 `SegmentModel` 列表

3. **片段处理**
   - 根据设置确定每个片段的跳过方式
   - 检查片段长度，太短的片段只显示
   - 如果当前播放位置在片段内，立即跳过

4. **播放监听**
   - 监听播放位置变化
   - 当接近片段开始位置时（提前1秒）
   - 根据跳过类型执行相应操作

5. **跳过执行**
   - **总是跳过**：自动跳过
   - **跳过一次**：第一次自动跳过，之后不跳过
   - **手动跳过**：显示跳过按钮，用户点击后跳过
   - **仅显示**：不执行任何操作
   - **禁用**：不处理该片段

## 使用方法

### 用户操作

1. 打开 **设置 > 播放器设置**
2. 找到 **番剧自动跳过片头片尾** 开关，开启功能
3. 点击 **番剧跳过方式** 选择跳过模式：
   - **总是跳过**：每次都自动跳过
   - **跳过一次**：只在第一次播放时跳过
   - **手动跳过**：显示跳过按钮，手动点击跳过
   - **仅显示**：只显示片段位置，不跳过
   - **禁用**：完全禁用跳过功能

### 播放体验

- 播放番剧时，系统会自动识别片头片尾
- 根据设置的跳过方式自动处理
- 跳过时会显示提示信息（可在设置中关闭）
- 手动跳过模式下，会在左下角显示跳过按钮（toast 样式，不遮挡视频内容）

## 注意事项

1. **番剧 API 依赖**
   - 功能依赖番剧 API 返回的 `clip_info_list` 字段
   - 如果 API 不返回该字段，功能将不生效

2. **SponsorBlock 服务器**
   - 当前使用的服务器地址为 `https://api.biliplus.com`
   - 可在设置中修改服务器地址
   - 需要服务器支持 BilibiliSponsorBlock API

3. **性能考虑**
   - 监听播放位置变化，性能开销较小
   - 只在接近片段时才执行检查
   - 不影响正常播放体验
