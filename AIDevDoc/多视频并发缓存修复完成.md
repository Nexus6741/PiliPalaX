# 多视频并发缓存功能修复完成

## 问题描述

用户反馈在同时缓存两个视频时遇到以下问题：
1. 只显示一个视频正在缓存，而不是显示所有正在缓存的视频
2. 没有进度显示，一直显示"等待中"
3. 无法暂停或取消缓存

## 修复内容

### 1. UI显示修复 (lib/pages/download/view.dart)

#### 多视频显示
- **问题**：UI只显示一个正在下载的视频
- **修复**：改为显示所有正在下载和等待的视频
- **实现**：
  ```dart
  // 获取所有正在下载和等待的视频
  final allDownloadingEntries = <DownloadEntryInfo>[];
  
  // 添加正在下载的视频
  allDownloadingEntries.addAll(_downloadService.activeDownloadEntries);
  
  // 添加等待队列中的视频
  allDownloadingEntries.addAll(_downloadService.waitDownloadQueue);
  ```

#### 列表显示优化
- 将单个下载项改为列表显示
- 使用 `SliverList` 替代单个 `SliverToBoxAdapter`
- 支持显示多个并发下载项

### 2. 下载服务修复 (lib/services/download_service.dart)

#### 并发下载管理
- **问题**：`curDownload` 只跟踪一个下载，导致状态更新混乱
- **修复**：
  - 添加 `_updateEntryStatus()` 方法，针对特定下载更新状态
  - 修改 `_startDownload()` 使用新的状态更新方法
  - 确保每个下载任务独立管理状态

#### 进度显示修复
- **问题**：进度回调只更新当前下载
- **修复**：`_onReceive()` 方法现在根据 `cid` 更新对应的下载任务
- **实现**：
  ```dart
  void _onReceive(int cid, int progress, int total) {
    final task = _activeDownloads[cid];
    if (task != null) {
      final entry = task.entry;
      if (progress == 0 && total != 0) {
        entry.totalBytes.value = total;
        _updateBiliDownloadEntryJson(entry);
      }
      entry.downloadedBytes.value = progress;
      entry.status.value = DownloadStatus.downloading;
    }
  }
  ```

#### 暂停/取消功能修复
- **问题**：暂停按钮调用的是全局取消方法
- **修复**：
  - 改进 `cancelSpecificDownload()` 方法
  - 暂停时将任务重新加入等待队列
  - 删除时从所有队列中移除
  - 支持继续下载功能

### 3. UI控制按钮优化

#### 智能按钮状态
- **暂停/继续按钮**：根据下载状态显示不同图标
  - 正在下载时显示暂停图标
  - 暂停/等待时显示播放图标
- **删除按钮**：添加独立的删除按钮

#### 按钮功能实现
```dart
// 暂停/继续按钮
IconButton(
  icon: Icon(
    status == DownloadStatus.downloading ||
            status == DownloadStatus.audioDownloading ||
            status == DownloadStatus.getDanmaku ||
            status == DownloadStatus.getPlayUrl
        ? Icons.pause
        : Icons.play_arrow,
  ),
  onPressed: () {
    if (status == DownloadStatus.downloading ||
        status == DownloadStatus.audioDownloading ||
        status == DownloadStatus.getDanmaku ||
        status == DownloadStatus.getPlayUrl) {
      // 暂停下载
      _downloadService.cancelSpecificDownload(
        entry.cid,
        isDelete: false,
      );
    } else if (status == DownloadStatus.pause ||
        status == DownloadStatus.wait) {
      // 继续下载
      _downloadService.startDownload(entry);
    }
  },
),
```

### 4. 代码结构优化

#### 私有类型处理
- **问题**：暴露了私有类型 `_DownloadTask`
- **修复**：添加公共getter `activeDownloadEntries`
- **实现**：
  ```dart
  // 获取正在下载的条目列表（用于UI显示）
  List<DownloadEntryInfo> get activeDownloadEntries => 
      _activeDownloads.values.map((task) => task.entry).toList();
  ```
