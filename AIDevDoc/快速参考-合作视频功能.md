```dart
// 查询合作 UP 主关注状态
Future<void> queryStaffRelations() async {
  final fids = videoDetail.value.staff!.map((item) => item.mid).join(',');
  var result = await VideoHttp.relations(fids: fids);
  if (result['status']) {
    staffRelations.value = {
      'status': true,
      if (result['data'] != null) ...result['data'],
    };
  }
}

// 关注/取关合作 UP 主
Future actionStaffRelationMod(int mid) async {
  final isFollowed = staffRelations['$mid'] != null;
  var result = await VideoHttp.relationMod(
    mid: mid,
    act: isFollowed ? 2 : 1,
    reSrc: 11,
  );
  if (result['status']) {
    if (isFollowed) {
      staffRelations.remove('$mid');
    } else {
      staffRelations['$mid'] = true;
    }
    staffRelations.refresh();
  }
}
```

### 4. UI 组件
```dart
// 合作 UP 主列表
Widget _buildStaffList(BuildContext context, ThemeData t) {
  return SingleChildScrollView(
    scrollDirection: Axis.horizontal,
    child: Obx(
      () => Row(
        children: staffList.map((staff) {
          final bool isFollowed =
              videoIntroController.staffRelations['status'] == true &&
              videoIntroController.staffRelations['${staff.mid}'] != null;
          
          return Padding(
            padding: const EdgeInsets.only(right: 25),
            child: StaffItem(
              staff: staff,
              isFollowed: isFollowed,
              onTap: () => Get.toNamed('/member?mid=${staff.mid}'),
              onFollow: () => videoIntroController.actionStaffRelationMod(staff.mid!),
            ),
          );
        }).toList(),
      ),
    ),
  );
}
```

## 常见问题

### Q1: UP 主列表不显示？
**A:** 检查 `videoDetail.staff` 是否有数据，确认 API 返回正确。

### Q2: 关注状态不正确？
**A:** 检查 `relations` API 调用是否成功，确认 `staffRelations` 更新。

### Q3: + 按钮不显示？
**A:** 检查 `isFollowed` 判断逻辑，确认关注状态查询成功。

### Q4: 点击无反应？
**A:** 检查 `onTap` 和 `onFollow` 回调是否正确绑定。

## API 端点

```
GET /x/relation/relations?fids=123,456,789
```

**返回示例：**
```json
{
  "code": 0,
  "message": "0",
  "data": {
    "123": {
      "mid": 123,
      "attribute": 2,
      "mtime": 1234567890
    },
    "456": {
      "mid": 456,
      "attribute": 0,
      "mtime": 0
    }
  }
}
```

**attribute 说明：**
- 0: 未关注
- 2: 已关注
- 6: 已互关
