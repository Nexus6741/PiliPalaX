# 鸿蒙视频防休眠 - 快速参考

## 问题
播放视频时设备自动休眠

## 解决方案
创建了 `wakelock_ohos` 插件 + `WakelockManager` 工具类

## 文件位置

### 核心文件
- **插件**: `packages/wakelock_ohos/`
- **工具类**: `lib/utils/wakelock_manager.dart`
- **集成点**: `lib/plugin/pl_player/controller.dart`

### 配置文件
- **权限**: `ohos/entry/src/main/module.json5`
- **依赖**: `pubspec.yaml`

## 使用方法

### 自动使用（已集成）
播放器会自动管理：
- ✅ 播放时启用防休眠
- ✅ 暂停时禁用防休眠
- ✅ 退出时释放锁

### 手动使用
```dart
import 'package:PiliPalaX/utils/wakelock_manager.dart';

// 启用
await WakelockManager.instance.enable();

// 禁用
await WakelockManager.instance.disable();

// 查询状态
bool enabled = await WakelockManager.instance.isEnabled();
```

## 技术细节

### 鸿蒙 API
- 使用 `@ohos.runningLock`
- 类型: `PROXIMITY_SCREEN_CONTROL`
- 权限: `ohos.permission.RUNNING_LOCK`

### 架构
```
播放器 → WakelockManager → WakelockOhos/WakelockPlus
```

## 故障排查

### 问题：防休眠不生效
1. 检查权限是否配置
2. 查看日志输出
3. 确认插件是否正确加载

### 问题：编译错误
1. 运行 `flutter pub get`
2. 清理构建缓存
3. 重新编译
