# 专栏历史记录修复测试指南

## 修复内容
修复了专栏浏览后无法上传到历史记录的问题。

## 关键修复点

### 1. 使用正确的历史记录暂停状态检查
**修复前：**
```dart
bool historyPause = setting.get(SettingBoxKey.enableSaveLastData, defaultValue: false);
```

**修复后：**
```dart
Box localCache = GStorage.localCache;
bool historyPause = localCache.get(LocalCacheKey.historyPause, defaultValue: false);
```

### 2. 添加正确的Content-Type
**修复前：**
```dart
await Request().post(
  Api.historyReport,
  data: {
    'aid': aid,
    if (type != null) 'type': type,
    'csrf': await Request.getCsrf(),
  },
);
```

**修复后：**
```dart
var res = await Request().post(
  Api.historyReport,
  data: {
    'aid': aid,
    if (type != null) 'type': type,
    'csrf': await Request.getCsrf(),
  },
  options: Options(contentType: Headers.formUrlEncodedContentType),
);
```

## 测试步骤

### 前置条件
1. 确保已登录账号
2. 确保历史记录功能未暂停（在设置中检查）

### 测试流程

#### 1. 测试专栏浏览历史记录
1. 打开应用，进入搜索页面
2. 搜索专栏关键词（如"教程"、"攻略"等）
3. 点击搜索结果中的专栏条目
4. 等待专栏内容加载完成
5. 查看控制台日志，应该看到：
   ```
   专栏历史记录已上报: aid=xxxxx
   historyReport response: {code: 0, message: 0, ttl: 1}
   ```
6. 返回主页，进入"历史记录"页面
7. 验证刚才浏览的专栏是否出现在历史记录中

#### 2. 测试历史记录暂停功能
1. 进入"历史记录"页面
2. 点击右上角菜单，选择"暂停观看历史"
3. 浏览一篇新的专栏
4. 查看控制台日志，应该看到：
   ```
   跳过历史记录上报: 登录=true, 暂停=true
   ```
5. 返回历史记录页面，验证新浏览的专栏没有被记录
6. 恢复观看历史功能

#### 3. 测试未登录状态
1. 退出登录
2. 浏览专栏
3. 查看控制台日志，应该看到：
   ```
   跳过历史记录上报: 登录=false, 暂停=false
   ```
4. 验证历史记录未被上传

## 预期结果

### 成功标志
- ✅ 登录状态下浏览专栏，历史记录正常上传
- ✅ 历史记录页面能看到浏览过的专栏
- ✅ 暂停历史记录功能生效，不上传记录
- ✅ 未登录状态不上传历史记录
- ✅ 控制台日志显示正确的状态信息

### API响应
成功的API响应应该是：
```json
{
  "code": 0,
  "message": "0",
  "ttl": 1
}
```

## 调试信息

### 查看日志
在控制台中查找以下关键日志：
- `专栏历史记录已上报: aid=xxxxx` - 表示成功调用上报
- `historyReport response: {...}` - 显示API响应
- `跳过历史记录上报: ...` - 显示跳过原因
- `_reportHistory error: ...` - 显示错误信息

### 常见问题

**问题1：历史记录没有上传**
- 检查是否已登录
- 检查历史记录是否被暂停
- 查看控制台日志确认原因

**问题2：API返回错误**
- 检查CSRF Token是否有效
- 检查网络连接
- 查看API响应中的错误信息

**问题3：专栏ID不正确**
- 确认从API获取的专栏ID是数字格式
- 检查`oid.value`的值是否正确

## 技术细节

### API参数
- `aid`: 专栏ID（数字，如123456）
- `type`: 内容类型（5表示专栏）
- `csrf`: CSRF Token（从cookie获取）

### 历史记录类型
- `type: 3` - 视频
- `type: 4` - 番剧
- `type: 5` - 专栏
