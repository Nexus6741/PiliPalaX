# 用户空间功能完善实施方案

## 一、功能对比分析

### 当前项目 (PiliPalaX) 用户空间功能
- 基础信息展示：头像、昵称、签名、等级、VIP状态
- 3个Tab：动态、投稿、合集/列表
- 基础操作：关注/取关、搜索、分享、拉黑、复制UID

### PiliPlus 用户空间功能（目标）
#### 1. 更丰富的Tab页面
- **主页 (home)**：展示用户的各类内容概览
  - 视频投稿（最多显示4-8个）
  - 收藏夹（显示第一个）
  - 最近投币的视频（2-4个）
  - 最近点赞的视频（2-4个）
  - 图文（显示第一个）
  - 音频（1-3个）
  - 漫画（1-3个）
  - 追番（3-6个）
  
- **动态 (dynamic)**：用户动态列表
- **投稿 (contribute)**：包含多个子分类
  - 视频 (video)
  - 图文 (opus)
  - 音频 (audio)
  - 漫画 (comic)
  
- **追番 (bangumi)**：追番/追剧列表
- **收藏 (favorite)**：收藏夹列表
- **课程 (cheese)**：付费课程
- **商品 (shop)**：商品橱窗

#### 2. 更完善的用户信息卡片
- 顶部背景图（支持日间/夜间模式）
- 头像（支持挂件、直播状态、认证标识）
- 用户名（VIP颜色显示）
- 等级标识（包括特殊等级6_s）
- VIP标签（独立的标签样式）
- 勋章展示
- 认证信息（个人/机构认证，带图标）
- 个性签名（支持选择复制）
- 共同关注展示（显示共同关注的UP主）
- UID和空间标签
- 封禁状态提示
- 粉丝/关注/获赞数据（可点击跳转）
- 私信按钮
- 关注按钮（多种状态：关注、已关注、已互关、特别关注、悄悄关注、移除黑名单）
- 推广信息展示（支持日间/夜间模式）

#### 3. 更多的菜单功能
**自己的空间：**
- 搜索
- 充电排行榜
- 大会员经验
- 登录设备
- 登录记录
- 硬币记录
- 经验记录
- 空间设置
- 分享我的主页
- 复制UID

**他人空间：**
- 搜索
- 加入/移除黑名单
- 移除粉丝
- 分享UP主
- 充电排行榜
- 举报
- 复制UID

#### 4. 新增的页面和功能
- 登录设备管理页面 (`login_devices`)
- 登录记录页面 (`login_log`)
- 硬币记录页面 (`coin_log`)
- 经验记录页面 (`exp_log`)
- 空间设置页面 (`space_setting`)
- 编辑资料页面 (`edit_profile`)
- 充电排行榜页面 (`member_upower_rank`)
- 最近投币视频页面 (`member_coin_arc`)
- 最近点赞视频页面 (`member_like_arc`)
- 图文页面 (`member_opus`)
- 音频页面 (`member_audio`)
- 漫画页面 (`member_comic`)
- 课程页面 (`member_cheese`)
- 商品页面 (`member_shop`)
- 共同关注页面 (`follow_type/followed`)

## 三、技术要点

### 1. 使用 ExtendedNestedScrollView
```dart
ExtendedNestedScrollView(
  onlyOneScrollInBody: true,
  pinnedHeaderSliverHeightBuilder: () => kToolbarHeight + padding.top,
  headerSliverBuilder: (context, innerBoxIsScrolled) => [...],
  body: TabBarView(...),
)
```

### 2. 使用 DynamicSliverAppBarMedium
自定义的可折叠AppBar，支持灵活的内容展示

### 3. LoadingState 状态管理
```dart
sealed class LoadingState<T> {
  Loading(),
  Success<T>(response: T),
  Error(errMsg: String),
}
```

### 4. 动态Tab配置
根据API返回的tab2配置动态生成Tab页面

### 5. 响应式布局
支持横屏和竖屏不同的布局方式
