# 空降助手番剧支持修复

## 问题描述

在集成空降助手功能时，发现 `SegmentItemModel` 类缺少 `fromPgcJson` 方法，导致番剧片头片尾数据无法正确解析。

### 错误信息
```
The method 'fromPgcJson' isn't defined for the type 'SegmentItemModel'.
```

### 错误位置
`lib/models/video/play/url.dart` 第 75 行：
```dart
clipInfoList = clipInfoListJson
    .map((e) => SegmentItemModel.fromPgcJson(e, timeLength))
    .toList();
```

## 问题原因

番剧的片头片尾数据格式与 SponsorBlock API 返回的数据格式不同：

### SponsorBlock 数据格式
```json
{
  "UUID": "abc123",
  "segment": [10000, 90000],
  "category": "intro",
  "videoDuration": 1200000
}
```

### 番剧片头片尾数据格式
```json
{
  "clipType": "CLIP_TYPE_OP",
  "start": 10.5,
  "end": 90.2
}
```

主要区别：
1. 番剧使用 `clipType` 而不是 `category`
2. 番剧使用 `start` 和 `end`（秒）而不是 `segment`（毫秒数组）
3. 番剧没有 `UUID`

## 解决方案

在 `SegmentItemModel` 类中添加 `fromPgcJson` 工厂方法，专门处理番剧数据格式。

### 实现代码

```dart
/// 从番剧片头片尾数据创建
factory SegmentItemModel.fromPgcJson(
  Map<String, dynamic> json,
  int? videoDuration,
) {
  String category;
  switch (json['clipType']) {
    case 'CLIP_TYPE_OP':
      category = 'intro';  // 片头
      break;
    case 'CLIP_TYPE_ED':
      category = 'outro';  // 片尾
      break;
    default:
      category = 'sponsor';
  }

  return SegmentItemModel(
    uuid: '',  // 番剧片段没有 UUID
    segment: [
      ((json['start'] as num) * 1000).round(),  // 秒转毫秒
      ((json['end'] as num) * 1000).round(),
    ],
    category: category,
    videoDuration: videoDuration,
  );
}
```

### 关键点

1. **clipType 映射**
   - `CLIP_TYPE_OP` → `intro`（片头）
   - `CLIP_TYPE_ED` → `outro`（片尾）
   - 其他 → `sponsor`（默认）

2. **时间单位转换**
   - 番剧 API 返回的是秒（浮点数）
   - 需要转换为毫秒（整数）
   - 使用 `((json['start'] as num) * 1000).round()`

3. **UUID 处理**
   - 番剧片段没有 UUID
   - 设置为空字符串 `''`
   - 不影响功能，因为番剧跳过不需要统计

## 功能说明

### 番剧片头片尾跳过

番剧的片头片尾信息来自 B站官方 API，不需要社区维护：

1. **数据来源**
   - 官方 API 提供
   - 数据准确可靠
   - 自动更新

2. **支持的类型**
   - 片头（OP）
   - 片尾（ED）

3. **跳过模式**
   - 使用 `pgcSkipType` 设置
   - 可选：总是跳过、跳过一次、手动跳过等
   - 独立于 SponsorBlock 设置

### 与 SponsorBlock 的区别

| 特性     | SponsorBlock | 番剧片头片尾     |
| -------- | ------------ | ---------------- |
| 数据来源 | 社区维护     | 官方 API         |
| 片段类型 | 10种         | 2种（片头/片尾） |
| UUID     | 有           | 无               |
| 统计追踪 | 支持         | 不支持           |
| 投票功能 | 支持         | 不支持           |
| 提交片段 | 支持         | 不支持           |

## 配置说明

### 启用番剧跳过

在设置中配置：
```dart
// 是否启用番剧跳过
enablePgcSkip = true

// 番剧跳过类型
pgcSkipType = SkipType.alwaysSkip  // 总是跳过
```

### 配置键

```dart
static const String enablePgcSkip = 'enablePgcSkip';
static const String pgcSkipType = 'pgcSkipType';
```

## 工作流程

```
播放番剧
  ↓
检查 enablePgcSkip
  ↓
从 PlayUrlModel 获取 clipInfoList
  ↓
使用 fromPgcJson 解析数据
  ↓
转换为 SegmentModel
  ↓
应用 pgcSkipType 设置
  ↓
自动跳过片头/片尾
```

## 注意事项

1. **时间精度**
   - 番剧 API 返回的时间是秒（浮点数）
   - 转换为毫秒时使用 `round()` 四舍五入
   - 保证时间精度

2. **空 UUID**
   - 番剧片段的 UUID 为空字符串
   - 不影响跳过功能
   - 不支持统计追踪

3. **独立设置**
   - 番剧跳过使用独立的设置
   - 不受 SponsorBlock 设置影响
   - 可以单独启用/禁用

## 总结

通过添加 `fromPgcJson` 方法，成功实现了番剧片头片尾的自动跳过功能：

- ✅ 正确解析番剧数据格式
- ✅ 支持片头和片尾跳过
- ✅ 独立的配置选项
- ✅ 与 SponsorBlock 功能兼容
- ✅ 不影响普通视频播放

用户现在可以在观看番剧时自动跳过片头片尾，享受更流畅的观看体验。
