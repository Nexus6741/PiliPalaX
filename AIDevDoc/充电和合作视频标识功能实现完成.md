# 充电和合作视频标识功能实现完成

## 功能概述

在视频卡片的封面右上角显示充电视频和合作视频的标识，与 PiliPlus 保持一致。

## 实现内容

### 1. 数据模型更新

#### RecVideoItemModel (`lib/models/model_rec_video_item.dart`)
- 添加 `isCooperation` 字段：合作视频标识
- 添加 `isCharging` 字段：充电视频标识
- 从 `json['rights']['is_cooperation']` 解析合作视频标识
- 从 `json['charging_pay']['level']` 解析充电视频标识

#### HotVideoItemModel (`lib/models/model_hot_video_item.dart`)
- 添加 `isCooperation` 字段：合作视频标识
- 添加 `isCharging` 字段：充电视频标识
- 解析逻辑与 RecVideoItemModel 一致

#### SearchVideoItemModel (`lib/models/search/result.dart`)
- 添加 `isUnionVideo` 字段：搜索接口使用的合作视频标识
- 从 `json['is_union_video']` 解析

#### SpaceArchiveItem (`lib/models/space_archive/space_archive_item.dart`)
- 已有 `isCooperation` 字段：从 `json['is_cooperation']` 解析
- 已有 `ugcPay` 字段：从 `json['ugc_pay']` 解析，用于判断充电视频

### 2. 视频卡片组件更新

#### VideoCardV (`lib/common/widgets/video_card_v.dart`)
在封面右上角添加标识显示逻辑：
- 充电视频：显示"充电专属"，红色标识（error 类型）
- 合作视频：显示"合作"，蓝色标识（primary 类型）
- 充电视频优先级高于合作视频

#### VideoCardH (`lib/common/widgets/video_card_h.dart`)
在封面右上角添加标识显示逻辑：
- 支持 `isCharging` 和 `isCooperation` 字段
- 兼容搜索接口的 `isUnionVideo` 字段
- 标识样式与 VideoCardV 一致

#### VideoCardHMember (`lib/pages/member_archive/widgets/video_card_h_member.dart`)
用户空间投稿视频卡片：
- 通过 `ugcPay > 0` 判断充电视频
- 通过 `isCooperation == true` 判断合作视频
- 标识显示在封面右上角

#### VideoCardVMemberHome (`lib/pages/member_home/widgets/video_card_v_member_home.dart`)
用户空间主页视频卡片：
- 判断逻辑与 VideoCardHMember 一致
- 标识显示在封面右上角

## 标识样式

### 充电专属
- 文本：`充电专属`
- 类型：`error`（红色背景）
- 位置：封面右上角（top: 6, right: 6/7）

### 合作视频
- 文本：`合作`
- 类型：`primary`（蓝色背景）
- 位置：封面右上角（top: 6, right: 6/7）

## 优先级规则

当视频同时具有充电和合作属性时，优先显示充电标识。

## 字段映射

不同接口返回的字段名称不同，需要兼容处理：

| 接口类型 | 充电视频字段         | 合作视频字段            |
| -------- | -------------------- | ----------------------- |
| 推荐视频 | `charging_pay.level` | `rights.is_cooperation` |
| 热门视频 | `charging_pay.level` | `rights.is_cooperation` |
| 搜索视频 | -                    | `is_union_video`        |
| 用户空间 | `ugc_pay`            | `is_cooperation`        |

## 实现细节

### 标识显示逻辑

```dart
Builder(builder: (context) {
  String? badge;
  String badgeType = 'primary';
  
  // 判断是否为充电视频
  if (videoItem.isCharging == true) {
    badge = '充电专属';
    badgeType = 'error';
  }
  // 判断是否为合作视频（优先级低于充电视频）
  else if (videoItem.isCooperation == 1) {
    badge = '合作';
    badgeType = 'primary';
  }
  
  if (badge != null) {
    return PBadge(
      text: badge,
      top: 6.0,
      right: 6.0,
      type: badgeType,
    );
  }
  return const SizedBox();
})
```

### 数据解析逻辑

```dart
// 推荐视频和热门视频
isCooperation = json['rights']?['is_cooperation'];
isCharging = json['charging_pay']?['level'] != null;

// 搜索视频
isUnionVideo = json['is_union_video'];

// 用户空间
ugcPay = (json['ugc_pay'] as num?)?.toInt();
isCooperation = json['is_cooperation'] as bool?;
```
