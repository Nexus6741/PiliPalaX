# 直播间历史弹幕表情修复完成

## 问题描述
进入直播间后，交流区会默认显示进入直播间之前的一些历史弹幕，但这些历史弹幕中的表情没有正常显示，只显示文本形式（如 `[happy]`），而进入直播间后新发的弹幕表情能正常渲染。

## 问题原因
在 `lib/models/live/live_danmaku/danmaku_msg.dart` 文件中，`DanmakuMsg.fromPrefetch` 工厂方法只解析了基本的弹幕信息（昵称、UID、文本），但没有解析表情相关的字段：
- `emots`: 官方默认表情映射
- `uemote`: 第三方大表情

而实时弹幕在 `controller.dart` 的 `_handleDanmuMsg` 方法中会正确解析这些表情信息。

## 修复方案
修改 `DanmakuMsg.fromPrefetch` 方法，添加表情信息的解析逻辑：

1. **解析官方表情** (`emots`)：
   - 检查 JSON 中是否存在 `emots` 字段
   - 将其转换为 `Map<String, BaseEmote>` 格式
   - 每个表情键值对通过 `BaseEmote.fromJson` 解析

2. **解析第三方表情** (`uemote`)：
   - 检查 JSON 中是否存在 `uemote` 字段
   - 通过 `BaseEmote.fromJson` 解析为 `BaseEmote` 对象

## 修改文件
- `lib/models/live/live_danmaku/danmaku_msg.dart`

## 修改内容
```dart
factory DanmakuMsg.fromPrefetch(Map<String, dynamic> json) {
  Map<String, BaseEmote>? emoteMap;
  BaseEmote? uemote;

  // 解析表情信息
  if (json['emots'] != null && json['emots'] is Map) {
    try {
      emoteMap = (json['emots'] as Map).map(
        (key, value) => MapEntry(
          key.toString(),
          BaseEmote.fromJson(Map<String, dynamic>.from(value as Map)),
        ),
      );
    } catch (_) {}
  }

  // 解析第三方表情（大表情）
  if (json['uemote'] != null && json['uemote'] is Map) {
    try {
      uemote = BaseEmote.fromJson(
        Map<String, dynamic>.from(json['uemote'] as Map),
      );
    } catch (_) {}
  }

  return DanmakuMsg(
    name: json['nickname'] as String?,
    uid: json['uid'] as int?,
    text: json['text'] as String?,
    emots: emoteMap,
    uemote: uemote,
  );
}
```

## 测试建议
1. 进入一个有历史弹幕的直播间
2. 查看交流区中的历史弹幕
3. 验证表情是否正常显示为图片，而不是文本形式
4. 测试不同类型的表情：
   - 官方默认表情（如 `[doge]`、`[tv_doge]` 等）
   - 第三方大表情（付费表情）
5. 对比新发送的弹幕表情，确保渲染效果一致

## 技术细节
- 历史弹幕通过 `/xlive/web-room/v1/dM/gethistory` API 获取
- 表情渲染逻辑在 `chat_panel.dart` 的 `_buildMsgSpan` 方法中
- 使用正则表达式匹配文本中的表情标记，替换为图片组件
- 支持两种表情类型：
  - `emots`: 文本中的小表情（如 `[doge]`）
  - `uemote`: 单独的大表情（整条弹幕就是一个表情）
