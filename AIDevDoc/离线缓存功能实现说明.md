## 功能特性

### 下载功能
1. **多画质支持**
   - 超清 4K (120)
   - 高清 1080P (80)
   - 高清 720P (64)
   - 清晰 480P (32)

2. **下载管理**
   - 队列下载（一次只下载一个，其他排队等待）
   - 断点续传
   - 暂停/继续
   - 取消下载
   - 删除已下载

3. **内容下载**
   - 视频文件（支持 DASH 和 FLV 格式）
   - 音频文件（DASH 格式）
   - 弹幕文件
   - 封面图片

4. **界面功能**
   - 下载进度显示
   - 下载状态提示
   - 多选批量操作
   - 分组显示（单视频/合集）
   - 长按菜单操作

## 使用方法

### 1. 下载视频
1. 打开视频详情页
2. 点击底部操作栏的"缓存"按钮
3. 选择画质
4. 视频将自动添加到下载队列

### 2. 查看下载
1. 从主页面进入"离线缓存"页面（路由：`/download`）
2. 查看正在下载和已下载的视频

### 3. 管理下载
- **单个操作**：长按视频卡片，选择删除或更新弹幕
- **批量操作**：点击右上角多选按钮，选择多个视频后批量删除或更新弹幕

## 技术细节

### 文件存储结构
```
downloads/
├── {avid}/                    # 普通视频目录
│   └── c_{cid}/              # 分P目录
│       ├── entry.json        # 条目信息
│       ├── cover.jpg         # 封面
│       ├── danmaku.pb        # 弹幕文件
│       └── {quality}/        # 画质目录
│           ├── index.json    # 媒体信息
│           ├── video.m4s     # 视频文件（DASH）
│           ├── audio.m4s     # 音频文件（DASH）
│           └── video.flv     # 视频文件（FLV）
└── s_{seasonId}/             # 番剧目录
    └── {episodeId}/          # 剧集目录
        └── ...               # 同上
```

### 下载状态
- `downloading` - 正在下载
- `audioDownloading` - 正在下载音频
- `getDanmaku` - 获取弹幕
- `getPlayUrl` - 获取播放地址
- `completed` - 下载完成
- `failDownload` - 下载失败
- `failDownloadAudio` - 音频下载失败
- `failDanmaku` - 获取弹幕失败
- `failPlayUrl` - 获取播放地址失败
- `pause` - 暂停中
- `wait` - 等待中

## 注意事项

1. **依赖包**
   - 需要确保 `path_provider` 包已添加到 `pubspec.yaml`
   - 需要确保 `synchronized` 包已添加到 `pubspec.yaml`

2. **权限**
   - Android 需要存储权限
   - iOS 需要文件访问权限

3. **性能**
   - 下载时会占用网络带宽
   - 大文件下载会占用存储空间
   - 建议添加存储空间检查

4. **错误处理**
   - 网络错误会自动重试
   - 文件写入错误会提示用户
   - 下载失败的文件会被清理
