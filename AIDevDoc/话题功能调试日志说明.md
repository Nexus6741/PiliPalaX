## 需要关注的关键信息

### 1. CSRF Token

```
🔍 [likeTopic] csrf: xxxxxxxxxx
```

- 如果为空或很短，说明 CSRF token 获取失败
- 正常的 CSRF token 应该是 32 位的字符串

### 2. API Endpoint

```
🔍 [likeTopic] API endpoint: /x/topic/like
```

- 应该是相对路径，不应该包含完整 URL
- 如果包含 `https://app.bilibili.com`，说明配置错误

### 3. up_mid

```
🔍 [likeTopic] up_mid: 38248199
```

- 应该是当前登录用户的 mid
- 如果是 0，说明用户信息获取失败

### 4. Response Code

```
🔍 [likeTopic] Response code: -111
```

- 0: 成功
- -111: CSRF 校验失败
- -101: 账号未登录
- 其他: 查看 Response 中的 message

### 5. Response 完整内容

```
🔍 [likeTopic] Response: {code: -111, message: csrf 校验失败, ttl: 1}
```

- 包含完整的错误信息
- 可以根据 message 判断具体问题

## 常见问题诊断

### 问题 1：-111 CSRF 校验失败

**可能原因**：
1. CSRF token 为空或无效
2. API 端点使用了错误的域名
3. Cookie 域名不匹配

**检查步骤**：
1. 查看日志中的 `csrf` 值是否正常
2. 查看 `API endpoint` 是否是相对路径
3. 检查是否已登录

### 问题 2：up_mid 为 0

**可能原因**：
1. 用户信息未正确获取
2. GStorage 中没有 userInfoCache

**检查步骤**：
1. 查看日志中的 `up_mid` 值
2. 确认已登录
3. 检查 GStorage.userInfo.get('userInfoCache')

### 问题 3：API endpoint 包含完整 URL

**可能原因**：
1. Api.likeTopic 等常量定义错误
2. 使用了 `${HttpString.appBaseUrl}` 前缀

**检查步骤**：
1. 查看日志中的 `API endpoint`
2. 检查 `lib/http/api.dart` 中的定义
3. 应该是 `/x/topic/like` 而不是 `https://app.bilibili.com/x/topic/like`
