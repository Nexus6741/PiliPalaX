# 投票附加到动态修复说明

## 问题描述
投票创建成功，但发送出去的动态并没有附带投票功能。

## 问题原因
创建投票后，返回的 `vote_id` 没有被使用。需要将投票作为富文本节点添加到动态的 `contents` 中。

## 富文本节点类型

根据 bilibili API 文档，投票是一种富文本节点类型：

| 类型 | 说明 | type值 | biz_id | 示例 |
|------|------|--------|--------|------|
| RICH_TEXT_NODE_TYPE_TEXT | 文字节点 | 1 | 空 | 普通文本 |
| RICH_TEXT_NODE_TYPE_AT | @用户 | 2 | 用户 mid | @某人 |
| RICH_TEXT_NODE_TYPE_LOTTERY | 互动抽奖 | 3 | 抽奖 id | 抽奖 |
| **RICH_TEXT_NODE_TYPE_VOTE** | **投票** | **4** | **投票 id** | **投票** |
| RICH_TEXT_NODE_TYPE_EMOJI | 表情 | 9 | 空 | 😊 |

## 修复方案

### 1. 在 createDynamic 方法中添加 voteId 参数

**修改文件：** `lib/http/dynamics.dart`

```dart
static Future createDynamic({
  required String content,
  String? title,
  List<String>? images,
  TopicItem? topic,
  int? voteId,  // ✅ 新增投票ID参数
  bool isPrivate = false,
  bool allowReply = true,
  DateTime? scheduledTime,
}) async {
```

### 2. 将投票添加到 contents 中

在构建动态内容时，如果有投票ID，将其作为富文本节点添加：

```dart
// 添加正文内容
if (content.isNotEmpty) {
  contents.add({
    'raw_text': content,
    'type': 1,
    'biz_id': '',
  });
}

// 添加投票（如果有）
if (voteId != null) {
  print('=== 添加投票到内容 ===');
  print('投票ID: $voteId');
  contents.add({
    'raw_text': ' 投票 ',  // 显示文本
    'type': 4,             // 4: 投票类型
    'biz_id': voteId.toString(),  // 投票ID
  });
}
```

### 3. 在 controller 中保存并传递 vote_id

**修改文件：** `lib/pages/dynamics_create/simple_controller.dart`

```dart
// 创建投票（如果有）
int? voteId;
if (selectedVote.value != null) {
  print('=== 开始创建投票 ===');
  final voteResult = await DynamicsHttp.createVote(selectedVote.value!);
  if (voteResult['status'] != true) {
    SmartDialog.showToast('投票创建失败: ${voteResult['msg']}');
    return;
  }
  
  // ✅ 保存投票ID
  voteId = voteResult['data']?['vote_id'];
  print('投票创建成功，vote_id: $voteId');
  
  if (voteId == null) {
    SmartDialog.showToast('投票创建失败：未返回投票ID');
    return;
  }
}

// 发布动态
print('=== 准备发布动态 ===');
print('voteId: $voteId');
final result = await DynamicsHttp.createDynamic(
  content: content,
  title: title,
  images: imageUrls,
  topic: selectedTopic.value,
  voteId: voteId,  // ✅ 传递投票ID
  isPrivate: isPrivate.value,
  allowReply: allowReply.value,
  scheduledTime: scheduledTime.value,
);
```

## 完整流程

1. **用户创建投票**
   - 点击投票按钮
   - 填写投票标题和选项
   - 点击完成

2. **创建投票**
   ```
   POST /x/vote/create
   {
     "vote_info": {
       "title": "投票标题",
       "desc": "",
       "type": 0,
       "choice_cnt": 1,
       "duration": 604800,
       "options": [
         {"opt_desc": "选项1"},
         {"opt_desc": "选项2"}
       ]
     }
   }
   
   响应：
   {
     "code": 0,
     "data": {
       "vote_id": 12345  // ✅ 保存这个ID
     }
   }
   ```

3. **发布动态时附加投票**
   ```
   POST /x/dynamic/feed/create/dyn
   {
     "dyn_req": {
       "content": {
         "contents": [
           {
             "raw_text": "动态内容",
             "type": 1,
             "biz_id": ""
           },
           {
             "raw_text": " 投票 ",
             "type": 4,           // ✅ 投票类型
             "biz_id": "12345"    // ✅ 投票ID
           }
         ]
       },
       "scene": 1,
       ...
     }
   }
   ```

## 测试步骤

1. 打开动态发布页面
2. 点击投票按钮
3. 创建一个投票（至少2个选项）
4. 点击完成
5. 输入动态内容
6. 点击发布
7. 查看控制台日志，确认：
   - 投票创建成功并返回 vote_id
   - vote_id 被正确传递给 createDynamic
   - 投票被添加到 contents 中
8. 查看发布的动态，确认投票显示正常

## 注意事项

1. **投票必须先创建成功**
   - 如果投票创建失败，不会发布动态
   - 如果返回的 vote_id 为 null，也不会发布动态

2. **投票作为富文本节点**
   - type: 4 表示投票类型
   - biz_id: 投票ID（字符串格式）
   - raw_text: 显示文本（可以是任意文本，通常是"投票"或投票标题）

3. **投票在 contents 中的位置**
   - 可以放在任意位置
   - 通常放在文本内容之后

4. **多个投票**
   - 理论上可以添加多个投票节点
   - 但通常一个动态只包含一个投票
