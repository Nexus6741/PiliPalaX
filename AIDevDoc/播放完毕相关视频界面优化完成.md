# 播放完毕相关视频界面优化完成

## 修复内容

### 1. 作者头像点击跳转用户空间
**问题**：播放完毕后全屏状态下显示的相关视频界面中，作者头像点击后无法进入用户空间

**修复位置**：`lib/plugin/pl_player/widgets/completion_overlay.dart`

**修复方案**：
- 在 `_buildUserInfo()` 方法中为头像添加 `GestureDetector`
- 点击头像时跳转到用户空间页面：`/member?mid=${owner.mid}`
- 传递用户头像参数以支持页面预加载

**代码变更**：
```dart
// 头像可点击跳转
GestureDetector(
  onTap: () {
    Get.toNamed(
      '/member?mid=${owner.mid}',
      arguments: {'face': owner.face},
    );
  },
  child: Container(...),
)
```

### 2. 添加退出按钮
**问题**：播放完毕后显示相关视频界面时，用户需要一个明确的方式退出该界面

**修复位置**：`lib/plugin/pl_player/widgets/completion_overlay.dart`

**修复方案**：
- 在右下角添加一个圆形退出按钮
- 使用向右箭头图标（`Icons.arrow_forward`）
- 点击按钮后退出全屏，返回到正常播放界面
- 按钮样式：半透明黑色背景，白色边框，白色箭头图标

**代码实现**：
```dart
// 右下角退出按钮
Positioned(
  right: 20,
  bottom: 20,
  child: Material(
    color: Colors.transparent,
    child: InkWell(
      onTap: () {
        widget.playerController.triggerFullScreen(status: false);
      },
      borderRadius: BorderRadius.circular(24),
      child: Container(
        width: 48,
        height: 48,
        decoration: BoxDecoration(
          color: Colors.black.withOpacity(0.6),
          borderRadius: BorderRadius.circular(24),
          border: Border.all(
            color: Colors.white.withOpacity(0.3), 
            width: 1
          ),
        ),
        child: const Icon(
          Icons.arrow_forward,
          color: Colors.white,
          size: 24,
        ),
      ),
    ),
  ),
)
```

**按钮特点**：
- 位置：右下角，距离边缘 20px
- 尺寸：48x48 圆形按钮（比之前的 56x56 更小）
- 图标：向右箭头，尺寸 24（比之前的 28 更小）
- 样式：半透明黑色背景 + 白色边框 + 白色箭头图标
- 交互：点击后退出全屏模式

### 3. 非全屏状态下重播按钮支持手势穿透
**问题**：非全屏状态下，视频播放完毕后显示的重播按钮会阻止中部上下滑动手势

**修复位置**：`lib/plugin/pl_player/view.dart`

**修复方案**：
- 将原来的 `Container` 改为 `Stack` 结构
- 背景层使用 `IgnorePointer` 让手势穿透
- 重播按钮单独放置，只响应点击事件
- 这样用户可以在重播按钮周围使用上下滑动手势调节亮度/音量

**代码变更**：
```dart
// 修改前：整个 Container 会拦截手势
Container(
  color: Colors.black54,
  child: Center(
    child: IconButton(...),
  ),
)

// 修改后：背景穿透手势，只有按钮响应点击
Stack(
  children: [
    // 背景层 - 忽略指针让手势穿透
    IgnorePointer(
      child: Container(
        color: Colors.black54,
      ),
    ),
    // 重播按钮 - 居中显示
    Center(
      child: IconButton(...),
    ),
  ],
)
```

**效果**：
- 点击重播按钮：正常重播视频
- 在按钮周围上下滑动：可以调节亮度（左侧）、音量（右侧）
- 手势功能与正常播放时一致

## 布局结构

### 全屏状态
```

├── Positioned(顶部 - 用户信息 + 标题)

```

## 技术细节

### CompletionOverlay 显示条件
在 `lib/plugin/pl_player/view.dart` 中：
```dart
Obx(() {
  if (_.playerStatus.status.value == PlayerStatus.completed &&
      !_.isSkipping.value) {
    if (_.isFullScreen.value) {
      return CompletionOverlay(...);
    } else {
      return Stack(...); // 非全屏重播按钮
    }
  }
  return const SizedBox();
})
```

只在以下条件满足时显示：
1. 播放状态为 `completed`（播放完毕）
2. 不在跳转中（`!_.isSkipping.value`）
3. 根据 `isFullScreen.value` 显示不同界面

### 退出全屏的效果
点击退出按钮后：
1. 调用 `playerController.triggerFullScreen(status: false)`
2. 退出全屏模式
3. CompletionOverlay 自动隐藏（因为不再满足 `isFullScreen.value` 条件）
4. 显示非全屏的重播按钮界面

### 手势穿透原理
使用 `IgnorePointer` 包裹背景层：
- `IgnorePointer` 会忽略其子组件的所有指针事件
- 手势事件会穿透到底层的 `InteractiveViewer`
- 播放器的手势处理逻辑正常工作
- 只有明确需要响应的组件（按钮）不使用 `IgnorePointer`

## 注意事项

1. 全屏状态下显示完整的相关视频界面，非全屏状态下只显示重播按钮
2. 相关视频列表是横向滚动的，每个视频卡片宽度为 200
3. 退出按钮使用向右箭头图标，暗示"前进/继续"的操作
4. 非全屏状态下的重播按钮不会阻止手势操作
5. 如果相关视频列表为空，会显示"暂无推荐视频"提示

## 用户体验改进

1. **更美观的退出按钮**：
   - 使用向右箭头代替关闭图标，更符合"继续观看"的语义
   - 缩小按钮尺寸（48x48），减少视觉干扰

2. **非全屏手势支持**：
   - 用户在非全屏状态下也能使用手势调节亮度/音量
   - 不需要先播放视频才能使用手势功能
   - 提升了播放完毕后的交互体验

3. **一致的交互体验**：
   - 全屏和非全屏状态都有明确的操作方式
   - 手势功能在各种状态下保持一致
