# 下载队列持久化问题修复完成

## 问题描述

用户反馈：取消了当前的缓存队列，但是当下次点击下载新视频时，之前被取消的视频又重新出现了。

## 问题分析

### 根本原因
下载服务在初始化时会从本地存储中读取未完成的下载任务，并重新加入到等待队列中。当用户取消下载时，只是从内存中的队列移除了任务，但相关的 JSON 文件仍然保存在本地存储中。

### 问题流程
1. **用户添加下载** → 创建 `entry.json` 文件保存下载信息
2. **用户取消下载** → 只从内存队列中移除，文件仍然存在
3. **应用重启/重新进入下载页** → `_readDownloadList()` 重新读取本地文件
4. **未完成的下载重新出现** → 所有 `!entry.isCompleted` 的下载重新加入队列

### 相关代码分析
```dart
// _readDownloadDirectory 方法会重新加载未完成的下载
if (entry.isCompleted) {
  result.add(entry);
} else {
  entry.status.value = DownloadStatus.wait;
  waitDownloadQueue.add(entry); // 问题所在：重新加入队列
}
```

Future<void> cancelDownload({
  required bool isDelete,
  bool downloadNext = true,
}) async {
  // ... 取消下载管理器
  
  final entry = curDownload.value;
  if (entry != null) {
    if (!isDelete) {
      // 暂停：更新状态并重新加入队列
      await _updateBiliDownloadEntryJson(entry);
      entry.status.value = DownloadStatus.pause;
      waitDownloadQueue.insert(0, entry);
    } else {
      // 删除：删除本地文件
      await _deleteDownloadFiles(entry);
    }
  }

### 2. 新增文件删除方法

#### _deleteDownloadFiles 方法
```dart
/// 删除下载相关的本地文件
Future<void> _deleteDownloadFiles(DownloadEntryInfo entry) async {
  try {
    // 删除整个下载目录
    final entryDir = Directory(entry.entryDirPath);
    if (entryDir.existsSync()) {
      await entryDir.delete(recursive: true);
    }
    
    // 检查父目录是否为空，如果为空也删除
    final pageDir = Directory(entry.pageDirPath);
    if (pageDir.existsSync()) {
      final list = await pageDir.list().toList();
      if (list.isEmpty) {
        await pageDir.delete(recursive: true);
      }
    }
  } catch (e) {
    if (kDebugMode) {
      debugPrint('Failed to delete download files: $e');
    }
  }
}
```

### 3. 新增队列管理方法

#### clearWaitingQueue 方法
```dart
/// 清空等待队列中的所有下载
Future<void> clearWaitingQueue() async {
  final entries = List<DownloadEntryInfo>.from(waitDownloadQueue);
  waitDownloadQueue.clear();
  
  // 删除所有等待中的下载文件
  for (final entry in entries) {
    await _deleteDownloadFiles(entry);
  }
  
  flagNotifier.refresh();
}
```

#### removeFromWaitingQueue 方法
```dart
/// 删除等待队列中的单个下载
Future<void> removeFromWaitingQueue(DownloadEntryInfo entry) async {
  waitDownloadQueue.remove(entry);
  await _deleteDownloadFiles(entry);
  flagNotifier.refresh();
}
```

## 使用指南

### 删除当前下载
1. 在正在下载的视频上点击删除按钮
2. 系统会停止下载并删除所有相关文件
3. 自动开始下一个等待中的下载

### 管理等待队列
1. **查看队列**：在下载页面查看"等待队列"区域
2. **删除单个**：点击等待项右侧的删除按钮
3. **清空队列**：点击"清空队列"按钮，确认后清空所有等待项

### 队列持久化行为
- **暂停下载**：视频会重新回到等待队列，下次启动时恢复
- **删除下载**：视频会彻底删除，下次启动时不会恢复
- **清空队列**：所有等待中的视频都会彻底删除
