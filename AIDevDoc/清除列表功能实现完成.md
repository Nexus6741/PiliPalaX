### 3. 修改清除逻辑
**文件**: `lib/pages/download/view.dart`

- **原方法**: `clearWaitingQueue()` （只清除等待中的）
- **新方法**: `clearAllCachingVideos()` （清除所有正在缓存的）

### 4. 新增服务方法
**文件**: `lib/services/download_service.dart`

添加了新方法 `clearAllCachingVideos()`：
```dart
/// 清除所有正在缓存的视频（包括正在下载的和等待中的）
Future<void> clearAllCachingVideos() async {
  // 先取消当前下载
  if (curDownload.value != null) {
    await cancelDownload(isDelete: true, downloadNext: false);
  }

  // 复制队列列表，避免在迭代时修改
  final entries = List<DownloadEntryInfo>.from(waitDownloadQueue);
  waitDownloadQueue.clear();

  // 删除所有缓存任务的文件
  for (final entry in entries) {
    await _deleteDownloadFiles(entry);
  }

  flagNotifier.refresh();
}
```

## 功能说明

### 清除范围
- **正在下载的视频**: 取消当前下载并删除
- **等待中的视频**: 从队列移除并删除
- **本地文件**: 删除所有相关的下载文件

### 操作流程
1. 用户点击"清除列表"按钮
2. 弹出确认对话框："确定要清除所有正在缓存的视频吗？"
3. 用户确认后：
   - 取消当前正在下载的视频
   - 清空等待队列
   - 删除所有相关的本地文件
   - 刷新UI
4. 显示提示："已清除所有缓存任务"

### 显示条件
- **旧逻辑**: 队列中有2个或更多视频时显示
- **新逻辑**: 队列中有任何视频时显示（包括只有1个正在下载的视频）

## 用户体验改进

1. **更直观的命名**: "清除列表" 比 "清空队列" 更容易理解
2. **更完整的功能**: 不仅清除等待中的，还清除正在下载的
3. **更合理的显示**: 只要有缓存任务就显示按钮，不需要等到有2个以上
4. **更清晰的提示**: 对话框明确说明会清除"所有正在缓存的视频"
