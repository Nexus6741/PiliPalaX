# 快速参考 - 动态话题标签功能

## 功能说明

在动态卡片中识别 `#` 开头的话题标签，在其前面添加小电视话题图标，点击可跳转到对应话题页面。

## 实现位置

### 1. 自定义图标
**文件**：`lib/common/widgets/custom_icon.dart`
- 添加 `topic_tag` 图标（码点：0xe817）
- 使用 `custom_icon.ttf` 字体文件

**字体文件**：`assets/fonts/custom_icon.ttf`
- 从 PiliPlus 复制
- 在 `pubspec.yaml` 中配置

**配置**：`pubspec.yaml`
```yaml
fonts:
  - family: custom_icon
    fonts:
      - asset: assets/fonts/custom_icon.ttf
```

### 2. 动态内容面板
**文件**：`lib/pages/dynamics/widgets/content_panel.dart`
- 处理动态顶部的话题标签（`moduleDynamic.topic`）
- 显示小电视图标 + 话题名称
- 点击跳转到话题页面

### 3. 富文本节点处理
**文件**：`lib/pages/dynamics/widgets/rich_node_panel.dart`
- 处理内容中的话题标签（`RICH_TEXT_NODE_TYPE_TOPIC`）
- 显示小电视图标 + 话题名称
- 智能跳转（有 ID 跳话题页，无 ID 跳搜索页）

## 关键代码

### 显示话题标签
```dart
Text.rich(
  TextSpan(
    children: [
      WidgetSpan(
        alignment: PlaceholderAlignment.middle,
        child: Padding(
          padding: const EdgeInsets.only(right: 4),
          child: Icon(
            size: 18,
            CustomIcons.topic_tag,
            color: theme.colorScheme.primary,
          ),
        ),
      ),
      TextSpan(
        text: topicName,
        style: TextStyle(color: theme.colorScheme.primary),
      ),
    ],
  ),
)
```

### 跳转到话题页
```dart
Get.toNamed(
  '/dynamicsTopic',
  parameters: {
    'id': topicId.toString(),
    'name': topicName,
  },
);
```

## 视觉效果

### 真正的话题（有话题 ID）
- 图标：🔖（小电视话题图标）
- 文本：话题名称（无 `#`）
- 颜色：主题色（蓝色/自定义）
- 大小：18px
- 间距：图标右侧 2-4px

### 普通标签（无话题 ID）
- 图标：无
- 文本：#标签名#（保持原样）
- 颜色：主题色（蓝色/自定义）

## 交互逻辑

### 动态顶部话题
- 始终显示小电视图标
- 点击跳转到话题页面

### 富文本中的话题

1. **真正的话题（有话题 ID）**
   - 显示：🔖 话题名称
   - 点击：跳转到话题页面
   
2. **普通标签（无话题 ID）**
   - 显示：#标签名#
   - 点击：跳转到搜索页面

### 话题名称处理
- 真正的话题：自动去掉前后的 `#`
- 普通标签：保持原始文本（包含 `#`）
