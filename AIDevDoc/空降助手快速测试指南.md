# 空降助手快速测试指南

## 快速启用步骤

### 1. 启用功能（必须）⚠️
```
设置 → 其他 → 空降助手 → 启用 SponsorBlock ✅
```

**重要**：这是主开关，必须打开才能使用 SponsorBlock 功能！

番剧片头片尾跳过（可选）：
```
设置 → 播放器 → 番剧自动跳过片头片尾
```

### 2. 配置跳过方式（推荐）
进入空降助手设置页面，为每种类型选择跳过方式：
- **sponsor（赞助商）** → 自动跳过 ✅
- **intro（片头）** → 手动跳过
- **outro（片尾）** → 手动跳过
- **interaction（互动）** → 自动跳过 ✅
- **selfpromo（自我推广）** → 手动跳过

### 3. 播放视频测试
1. 选择一个热门视频
2. 播放视频
3. 进入全屏模式
4. 查看控制栏是否有按钮：
   - 🛡️ 盾牌图标 = 提交片段按钮
   - ℹ️ 信息图标 = 片段信息按钮

## 快速检查清单

### ✅ 功能正常的标志
- [ ] 控制台输出：`✅ 开始查询 SponsorBlock`
- [ ] 控制台输出：`✅ 成功获取片段，数量: X`
- [ ] 全屏模式下看到按钮
- [ ] 播放时自动跳过广告
- [ ] 显示 Toast 提示："已跳过sponsor"

### ❌ 功能异常的标志
- [ ] 控制台输出：`⚠️ 不满足查询条件，跳过`
  - **原因**：功能未启用或自动播放未开启
  - **解决**：检查设置
  
- [ ] 控制台输出：`❌ API 返回错误: 404`
  - **原因**：该视频没有 SponsorBlock 数据
  - **解决**：换一个视频测试
  
- [ ] 控制台输出：`🔍 查询完成，segmentList.length: 0`
  - **原因**：片段被过滤或类型被禁用
  - **解决**：检查跳过方式设置

## 常见问题速查

| 问题         | 可能原因         | 解决方法       |
| ------------ | ---------------- | -------------- |
| 按钮不显示   | 未启用功能       | 检查设置       |
| 按钮不显示   | 视频无数据       | 换视频测试     |
| 按钮不显示   | 未全屏           | 进入全屏       |
| 不自动跳过   | 跳过方式设置错误 | 改为"自动跳过" |
| 不自动跳过   | 片段时间不准     | 查看片段信息   |
| API 404      | 视频无数据       | 正常，换视频   |
| API 其他错误 | 网络问题         | 检查网络       |

## 测试视频推荐

### 适合测试的视频类型
1. **科技评测视频**：通常有赞助商片段
2. **游戏视频**：可能有互动提醒
3. **热门 UP 主视频**：数据更完整
4. **番剧**：测试片头片尾跳过

### 如何找有数据的视频
1. 选择播放量高的视频
2. 选择时长较长的视频（>10分钟）
3. 选择有赞助商的视频
4. 在 SponsorBlock 官网查询

## 功能说明

### 片段类型
- **sponsor**：赞助商广告
- **intro**：片头
- **outro**：片尾
- **interaction**：互动提醒（点赞关注）
- **selfpromo**：自我推广
- **music_offtopic**：非音乐片段
- **preview**：预告/回顾
- **poi_highlight**：精彩片段
- **filler**：填充内容
- **exclusive_access**：独家内容

### 跳过方式
- **自动跳过**：检测到立即跳过
- **跳过一次**：每个片段只跳过一次
- **手动跳过**：显示按钮，用户点击跳过
- **仅显示**：不跳过，仅标记
- **禁用**：不处理该类型片段

### 按钮功能
- **🛡️ 提交片段**：提交新的片段（开发中）
- **ℹ️ 片段信息**：查看当前视频的所有片段
