# 话题图标字体安装说明

## 已完成的操作

### 1. 复制字体文件
✅ 从 `PiliPlus/assets/fonts/custom_icon.ttf` 复制到 `assets/fonts/custom_icon.ttf`

### 2. 配置 pubspec.yaml
✅ 在 `pubspec.yaml` 中添加了字体配置：
```yaml
fonts:
  - family: custom_icon
    fonts:
      - asset: assets/fonts/custom_icon.ttf
```

### 3. 更新代码
✅ `lib/common/widgets/custom_icon.dart` - 已更新图标定义
✅ `lib/pages/dynamics/widgets/content_panel.dart` - 已使用 topic_tag 图标

## 下一步操作

### 方法 1：热重启（推荐）
1. 在 IDE 中点击"热重启"按钮（🔄）
2. 或者按快捷键：
   - VS Code: `Ctrl+Shift+F5`
   - Android Studio: `Ctrl+\`

### 方法 2：完全重新编译
如果热重启后图标仍然不显示，需要完全重新编译：

```bash
# 清理构建缓存
flutter clean

# 获取依赖
flutter pub get

# 重新运行应用
flutter run
```

## 常见问题

### 问题 1：图标显示为方框 □
**原因**：字体文件未正确加载

**解决方法**：
1. 确认 `assets/fonts/custom_icon.ttf` 文件存在
2. 确认 `pubspec.yaml` 配置正确
3. 运行 `flutter clean` 和 `flutter pub get`
4. 完全重新编译应用

### 问题 2：图标不显示
**原因**：热重载不支持字体更新

**解决方法**：
1. 使用热重启（不是热重载）
2. 或者完全重新编译应用

### 问题 3：编译错误
**原因**：pubspec.yaml 格式错误

**解决方法**：
1. 检查 YAML 缩进（使用空格，不是 Tab）
2. 确保 `fonts:` 配置在正确的位置
3. 运行 `flutter pub get` 验证配置

## 图标码点参考

话题图标（topic_tag）的码点：`0xe817`

其他可用图标：
- coin: `0xe800`
- dm_on: `0xe802`
- dm_off: `0xe801`
- fav: `0xe805`
- share: `0xe80c`
- thumbs_up: `0xe813`
- watch_later: `0xe818`
