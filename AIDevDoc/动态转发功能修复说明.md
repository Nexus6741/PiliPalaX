# 动态转发功能修复说明

## 修复内容

### 1. 添加 aigc 参数
**文件**: `lib/http/dynamics.dart`

在转发动态时，必须在 `option` 中添加 `aigc: 2` 参数：

```dart
// 转发动态时添加 aigc 参数
if (dynIdStr != null) {
  options['aigc'] = 2;
}
```

这是B站API的必需参数，缺少会导致转发失败。

### 2. 支持不输入内容转发
**文件**: `lib/pages/dynamics_repost/view.dart`

#### 修改点：

1. **初始化时允许发布**：
```dart
// 转发动态可以不输入内容，默认允许发布
_canPublish.value = true;
```

2. **移除输入验证**：
```dart
void _onTextChanged() {
  // 转发动态可以不输入内容，所以始终允许发布
  _canPublish.value = true;
}
```

3. **添加默认文本**：
```dart
if (richItems.isEmpty) {
  // 如果没有输入内容，使用默认文本"转发动态"
  richContent = [
    {
      'raw_text': '转发动态',
      'type': 1,
      'biz_id': '',
    }
  ];
}
```

4. **简化AppBar**：
```dart
// 转发按钮始终可用，不需要Obx包装
TextButton(
  onPressed: _onPublish,
  child: Text(
    '转发',
    style: TextStyle(
      color: theme.colorScheme.primary,
    ),
  ),
),
```

## 完整的转发请求格式

根据网页端的请求，正确的格式应该是：

```json
{
  "dyn_req": {
    "content": {
      "contents": [
        {"raw_text": "转发动态", "type": 1, "biz_id": ""}
      ]
    },
    "scene": 4,
    "upload_id": "38248199_1765604907_3587",
    "meta": {
      "app_meta": {
        "from": "create.dynamic.web",
        "mobi_app": "web"
      }
    },
    "option": {
      "aigc": 2
    }
  },
  "web_repost_src": {
    "dyn_id_str": "1145495746703786005"
  }
}
```

## 关键参数说明

1. **scene: 4** - 表示转发场景
2. **option.aigc: 2** - 必需参数，表示AI生成内容标记
3. **web_repost_src.dyn_id_str** - 被转发的动态ID
4. **contents** - 如果用户没有输入，使用默认文本"转发动态"

## 用户体验改进

1. **无需输入即可转发**：用户可以直接点击转发按钮，不需要输入任何内容
2. **默认文本**：不输入内容时自动使用"转发动态"作为默认文本
3. **转发按钮始终可用**：提升操作流畅度
