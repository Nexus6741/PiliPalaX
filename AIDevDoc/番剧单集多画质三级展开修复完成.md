# 番剧单集多画质三级展开修复完成

## 问题描述
番剧的同一集下载多个画质后，没有合并到三级列表中，而是分开显示。普通视频的多画质可以正确展开为三级列表。

## 问题分析

### 根本原因
在 `_buildMultiEntryItem` 方法中，判断是否使用三级结构的逻辑有问题：

```dart
final hasMultipleEpisodes = pageInfo.hasMultipleEpisodes;
// hasMultipleEpisodes 定义为: (episodes?.length ?? 0) > 1

// 展开逻辑
children: hasMultipleEpisodes
    ? pageInfo.episodes!.map((episode) => _buildEpisodeItem(...))
    : pageInfo.entries.map((entry) => _buildExpandedEntryItem(...))
```

问题在于：
- `hasMultipleEpisodes` 只检查是否有多个选集（episodes.length > 1）
- 当只有1个选集但有多个画质时，`episodes.length == 1`，所以 `hasMultipleEpisodes = false`
- 导致直接显示 `pageInfo.entries`，跳过了三级结构

### 应该的逻辑
应该使用三级结构的情况：
1. 多个选集（episodes.length > 1）
2. 单个选集但有多个画质（episodes.length == 1 && episodes[0].entries.length > 1）

## 修复方案

### 修改文件
`lib/pages/download/view.dart`

### 修改内容
在 `_buildMultiEntryItem` 方法中，添加新的判断逻辑：

```dart
// 检查是否应该使用三级结构：多集 或 单集多画质
final useThreeLevelStructure = pageInfo.episodes != null && 
    (pageInfo.episodes!.length > 1 || 
     (pageInfo.episodes!.length == 1 && pageInfo.episodes!.first.entries.length > 1));
```

然后在展开逻辑和画质标签显示中使用这个新变量：

```dart
// 显示包含的画质信息（仅当不使用三级结构时）
if (!useThreeLevelStructure)
  ...pageInfo.entries.map((e) => e.qualityPithyDescription)...

// 展开的子项列表
children: useThreeLevelStructure
    ? pageInfo.episodes!.map((episode) => _buildEpisodeItem(...))
    : pageInfo.entries.map((entry) => _buildExpandedEntryItem(...))
```

## 修复效果

### 修复前
- 番剧同一集的不同画质分开显示为多个卡片
- 无法通过三级列表查看同一集的不同画质

### 修复后
- 番剧同一集的不同画质合并显示
- 点击展开后显示选集（二级）
- 再点击选集展开显示画质列表（三级）
- 与普通视频的多画质展开行为一致
