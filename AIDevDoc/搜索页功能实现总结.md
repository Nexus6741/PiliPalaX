## API 接口

### 1. 热搜榜单
```
GET /x/v2/search/trending/ranking
参数：limit (默认30)
返回：list (热搜列表) + top_list (置顶列表)
```

### 2. 搜索发现
```
GET /x/v2/search/recommend
参数：mobi_app=android, platform=android
返回：list (推荐列表)
```

## 数据模型

### SearchTrendingItem
```dart
class SearchTrendingItem {
  String? keyword;           // 关键词
  String? showName;          // 显示名称
  String? icon;              // 图标URL
  bool? showLiveIcon;        // 是否显示LIVE标签
  String? recommendReason;   // 推荐理由
}
```

### HotSearchItem (扩展)
```dart
class HotSearchItem {
  String? keyword;
  String? showName;
  int? wordType;
  String? icon;
  bool? showLiveIcon;        // 新增

}
```

## 问题解决

### 问题1：数据加载但不显示
**原因**：HotSearchItem 模型缺少字段，RxList 类型不匹配
**解决**：
1. 扩展 HotSearchItem 模型添加缺失字段
2. 使用 .toList() 转换 RxList 为普通 List
3. 重新生成 Hive 代码

### 问题2：调试日志过多
**原因**：添加了大量调试日志用于排查问题
**解决**：使用 PowerShell 正则表达式批量删除所有调试日志

## 使用说明

### 访问完整榜单
1. 打开搜索页面
2. 点击"大家都在搜"旁的"完整榜单"按钮
3. 查看完整的热搜排行榜
4. 点击任意热搜词直接搜索

### 查看搜索发现
1. 打开搜索页面
2. 向下滚动到"搜索发现"区域
3. 查看推荐的搜索关键词
4. 点击刷新按钮获取新推荐
