## 修复的问题

### 1. 主页Tab - 视频卡片布局问题
**问题**：
- 封面图不显示（灰色占位符）
- 布局不符合 PiliPlus 标准
- childAspectRatio 设置不正确

**解决方案**：
- 修改 `childAspectRatio` 从 `0.75` 改为 `0.65`，使卡片更高，适合显示标题
- 使用 `Card` 组件包裹，添加 `clipBehavior: Clip.hardEdge`
- 修复封面图 URL：使用 `item.pic ?? ''` 而不是 `item.pic`
- 使用 `AspectRatio` 固定封面比例为 `0.75`
- 标题使用 `Expanded` 包裹，确保正确显示

### 2. 主页Tab - 查看更多按钮无反应
**问题**：
- 点击"查看更多"按钮没有任何反应
- TODO 注释但没有实现

**当前状态**：

### 3. 追番Tab - 请求错误
**问题**：
- 追番 API 返回 -400 错误
- 缺少必要的签名参数

**解决方案**：
在 `lib/http/bangumi.dart` 的 `bangumiFollow()` 方法中添加：
1. 获取 `access_key`
2. 添加 `ts` 时间戳
3. 调用 `AppSign.appSign()` 进行签名

## 关键技术点

### 1. 视频卡片布局
```dart
Card(
  clipBehavior: Clip.hardEdge,
  child: InkWell(
    onTap: () { /* 跳转逻辑 */ },
    child: Column(
      children: [
        AspectRatio(
          aspectRatio: 0.75,  // 封面比例
          child: Stack(
            children: [
              NetworkImgLayer(src: item.pic ?? ''),
              // 时长标签
            ],
          ),
        ),
        Expanded(
          child: Padding(
            child: Text(/* 标题 */),
          ),
        ),
      ],
    ),
  ),
)
```

### 2. Grid 布局参数
```dart
SliverGridDelegateWithFixedCrossAxisCount(
  crossAxisCount: isVertical ? 2 : 4,  // 竖屏2列，横屏4列
  mainAxisSpacing: 8,
  crossAxisSpacing: 8,
  childAspectRatio: 0.65,  // 宽高比，0.65 使卡片更高
)
```

### 3. App API 签名流程
```dart
// 1. 准备参数
final params = <String, dynamic>{
  'vmid': mid,
  'type': 1,
  'ts': (DateTime.now().millisecondsSinceEpoch ~/ 1000).toString(),
};

// 2. 添加 access_key（如果已登录）
if (accessKey != null && accessKey.isNotEmpty) {
  params['access_key'] = accessKey;
}

// 3. 签名
AppSign.appSign(params);  // 会添加 appkey 和 sign

// 4. 发送请求
var res = await Request().get(Api.xxx, data: params);
```
