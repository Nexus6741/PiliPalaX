## 🔑 核心类

### SpaceData - 空间数据模型

```dart
class SpaceData {
  int? relation;              // 关系状态
  String? defaultTab;         // 默认Tab
  SpaceCard? card;            // 用户卡片信息
  SpaceImages? images;        // 背景图
  SpaceLive? live;            // 直播状态
  SpaceArchive? archive;      // 投稿视频
  SpaceFavourite2? favourite2;// 收藏夹
  SpaceCoinArchive? coinArchive;  // 投币视频
  SpaceLikeArchive? likeArchive;  // 点赞视频
  List<SpaceTab2>? tab2;      // Tab配置
  int? relSpecial;            // 特别关注
  int? silence;               // 封禁状态
}
```

### MemberController - 用户空间控制器

```dart
class MemberController extends GetxController {
  // 核心数据
  Rx<SpaceData?> spaceData;
  RxInt relation;             // 关系状态
  RxString relationText;      // 关系文本
  
  // 核心方法
  Future<void> loadSpaceData();        // 加载空间数据
  Future actionRelationMod(context);   // 关注/取关
  Future blockUser(context);           // 拉黑
  Future removeFan();                  // 移除粉丝
  void shareUser();                    // 分享
  Future<void> refresh();              // 刷新
}
```

class UserInfoCard extends StatelessWidget {

### 动态Tab配置

```dart
// Controller中自动配置
void configureTabs() {
  final supportedTabs = tab2!.where((tab) {
    return ['home', 'dynamic', 'contribute', 'bangumi', 'favorite']
        .contains(tab.param);
  }).toList();
  
  tabController = TabController(
    length: supportedTabs.length,
    vsync: this,
    initialIndex: initialIndex,
  );
}
```

## 📝 注意事项

1. **heroTag** - 每个用户空间实例需要唯一的heroTag
2. **状态保持** - 主页Tab使用AutomaticKeepAliveClientMixin
3. **响应式** - 所有布局支持横屏/竖屏
4. **空安全** - 所有数据访问都有空检查
5. **错误处理** - 完整的加载、错误、空数据处理

## 🐛 常见问题

### Q: 如何添加新的Tab？

A: 在 `_buildTabContent` 方法中添加新的case：

```dart
case 'new_tab':
  return NewTabPage(heroTag: heroTag);
```

### Q: 如何修改关系状态文本？

A: 在 `MemberController.updateRelationText()` 方法中修改。

### Q: 如何自定义主页Tab显示的内容数量？

A: 在 `MemberHomePage._buildBody()` 中修改 `min()` 的参数。
