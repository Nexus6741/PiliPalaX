# 视频卡片毛玻璃（亚克力）效果完成

## 实现内容

为视频卡片的信息区域（标题、播放量、UP主等）添加了毛玻璃效果，让界面更有质感和层次感。

## 实现方案

### 1. 创建毛玻璃组件

新建文件：`lib/common/widgets/frosted_glass_container.dart`

提供了三个毛玻璃效果组件：

#### VideoCardFrostedGlass（视频卡片专用）
- **视觉效果**：
  - 使用 `BackdropFilter` + `ImageFilter.blur` 实现毛玻璃效果
  - 模糊强度：sigmaX/Y = 12.0
  - 渐变背景：从半透明到更不透明，增强层次感
  - 顶部细边框：增加精致感
  
- **自适应主题**：
  - 深色模式：黑色半透明渐变（0.4 → 0.6 opacity）
  - 浅色模式：白色半透明渐变（0.5 → 0.7 opacity）

#### FrostedGlassContainer（通用容器）
- 可自定义模糊强度、颜色、圆角等
- 适用于各种需要毛玻璃效果的场景

#### LightFrostedGlass（轻量级）
- 更轻盈、更透明的毛玻璃效果
- 适合需要更多透明度的场景

### 2. 应用到垂直视频卡片

修改文件：`lib/common/widgets/video_card_v.dart`

- 导入毛玻璃组件
- 用 `VideoCardFrostedGlass` 包裹 `VideoContent`
- 调整布局结构，确保效果正确显示

## 技术细节

### BackdropFilter 原理

```dart
BackdropFilter(
  filter: ImageFilter.blur(sigmaX: 12.0, sigmaY: 12.0),
  child: Container(
    decoration: BoxDecoration(
      gradient: LinearGradient(...),
    ),
    child: child,
  ),
)
```

1. **BackdropFilter**：对背后的内容应用滤镜效果
2. **ImageFilter.blur**：高斯模糊滤镜
3. **渐变背景**：增强视觉层次，确保文字可读性

### 性能优化

- 使用 `ClipRRect` 限制模糊区域，提升性能
- 模糊强度适中（12.0），平衡效果和性能
- 避免过度嵌套，减少渲染开销

## 视觉效果

### 优化前
- 信息区域纯色背景（黑色或白色）
- 与封面图片分离明显
- 缺乏层次感

### 优化后
- 信息区域毛玻璃效果
- 可以透过看到背景渐变
- 增强视觉层次和质感
- 更现代、更精致的设计

## 应用范围

### 已应用
- ✅ 垂直视频卡片（`VideoCardV`）
  - 推荐页
  - 热门页
  - 分区页
  - 搜索结果（视频类型）

### 未应用（不适合）

  - 不适合毛玻璃效果

## 自定义配置

### 调整模糊强度

修改 `frosted_glass_container.dart` 中的 `VideoCardFrostedGlass`：

```dart
// 更强的模糊效果
filter: ImageFilter.blur(sigmaX: 16.0, sigmaY: 16.0)

// 更弱的模糊效果
filter: ImageFilter.blur(sigmaX: 8.0, sigmaY: 8.0)
```

### 调整透明度

```dart
// 深色模式 - 更透明
colors: [
  Colors.black.withOpacity(0.3),
  Colors.black.withOpacity(0.5),
]

// 深色模式 - 更不透明
colors: [
  Colors.black.withOpacity(0.5),
  Colors.black.withOpacity(0.7),
]
```

### 禁用效果

如果需要临时禁用效果：

```dart
VideoCardFrostedGlass(
  enabled: false,  // 禁用毛玻璃效果
  child: VideoContent(videoItem: videoItem),
)
```

## 注意事项

### 性能考虑

1. **避免过度使用**：
   - BackdropFilter 有一定性能开销
   - 不要在列表中大量使用
   - 当前实现已优化，每个卡片只有一个毛玻璃区域

2. **模糊强度**：
   - 过高的模糊值会影响性能
   - 建议范围：8.0 - 16.0

3. **嵌套限制**：
   - 避免多层 BackdropFilter 嵌套
   - 会导致性能问题和视觉异常

### 兼容性

- ✅ iOS：完美支持
- ✅ Android：完美支持
- ✅ Web：支持，但性能可能较差
- ✅ Desktop：完美支持

### 视觉效果

- 确保背景有内容可模糊（图片、渐变等）
- 纯色背景上的毛玻璃效果不明显
- 建议配合渐变背景使用

## 关于 flutter_acrylic

`flutter_acrylic` 包主要用于桌面应用的窗口效果（Windows、macOS、Linux），不适合移动端的卡片内容。

- **桌面窗口效果**：窗口透明、毛玻璃窗口等
- **移动端不适用**：无法应用到卡片内容
- **当前方案更优**：使用 `BackdropFilter` 是移动端的标准做法

如果未来需要桌面端的窗口毛玻璃效果，可以考虑添加 `flutter_acrylic`。
