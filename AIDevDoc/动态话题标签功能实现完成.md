## 实现内容

### 1. 自定义图标更新

更新 `lib/common/widgets/custom_icon.dart`：
- 从 PiliPlus 复制完整的自定义图标定义
- 添加 `topic_tag` 图标（小电视话题图标）
- 添加其他常用图标（点赞、收藏、分享等）
- 使用 `_CustomIconData` 类关联 `custom_icon` 字体文件

复制图标字体文件：
- 从 `PiliPlus/assets/fonts/custom_icon.ttf` 复制到 `assets/fonts/custom_icon.ttf`
- 在 `pubspec.yaml` 中添加字体配置：
  ```yaml
  fonts:
    - family: custom_icon
      fonts:
        - asset: assets/fonts/custom_icon.ttf
  ```

### 2. 动态内容面板更新

更新 `lib/pages/dynamics/widgets/content_panel.dart`：

#### 导入自定义图标
```dart
import 'package:PiliPalaX/common/widgets/custom_icon.dart';
```

#### 话题标签显示优化
- 在话题名称前添加小电视图标（`CustomIcons.topic_tag`）
- 使用 `Text.rich` 和 `TextSpan` 组合显示图标和文本
- 图标大小：18
- 图标颜色：主题色（`authorStyle.color`）
- 图标右侧留白：4px

#### 点击跳转功能
- 点击话题标签跳转到话题页面（`/dynamicsTopic`）
- 传递参数：
  - `id`：话题 ID
  - `name`：话题名称

### 3. 富文本节点处理更新

更新 `lib/pages/dynamics/widgets/rich_node_panel.dart`：

#### 导入自定义图标
```dart
import 'package:PiliPalaX/common/widgets/custom_icon.dart';
```

#### 话题类型节点处理
处理 `RICH_TEXT_NODE_TYPE_TOPIC` 类型的节点：

1. **判断是否为真正的话题**
   - 检查是否有 `rid`（话题 ID）
   - 有 `rid`：真正的话题，显示小电视图标
   - 无 `rid`：普通标签，保持显示 `#`

2. **添加小电视图标（仅真正的话题）**
   - 使用 `WidgetSpan` 包装图标
   - 图标大小：18
   - 图标颜色：主题色
   - 图标右侧留白：2px

3. **提取话题名称**
   - 真正的话题：从 `origText` 中提取（去掉前后的 `#`）
   - 普通标签：保持原始文本（包含 `#`）
   - 示例：
     - 真正的话题：`#年末总结#` → 🔖 年末总结
     - 普通标签：`#年末总结#` → #年末总结#

4. **智能跳转逻辑**
   - 如果有 `rid`（话题 ID）：跳转到话题页面
     ```dart
     Get.toNamed('/dynamicsTopic', parameters: {
       'id': i.rid!,
       'name': topicName,
     });
     ```
   - 如果没有 `rid`：跳转到搜索页面
     ```dart
     Get.toNamed('/searchResult', parameters: {
       'keyword': topicName,
     });
     ```

5. **显示文本**
   - 真正的话题：显示去掉 `#` 的话题名称
   - 普通标签：显示包含 `#` 的原始文本
   - 使用主题色显示
   - 可点击

## 功能特性

- ✅ 自动识别动态内容中的话题标签

## 技术细节

### 图标字体

使用 `custom_icon.ttf` 字体文件：
- 位置：`assets/fonts/custom_icon.ttf`
- 字体族：`custom_icon`
- 话题图标码点：`0xe817`

### 布局实现

使用 Flutter 的富文本组件：
- `Text.rich`：支持混合文本和组件
- `TextSpan`：文本片段
- `WidgetSpan`：组件片段
- `PlaceholderAlignment.middle`：垂直居中对齐

### 颜色方案

- 图标颜色：`Theme.of(context).colorScheme.primary`
- 文本颜色：`authorStyle.color`（与 @ 用户等保持一致）

## 对比 PiliPlus

### 相同点

- ✅ 使用相同的小电视图标
- ✅ 相同的颜色方案
- ✅ 相同的布局和间距
- ✅ 相同的点击跳转逻辑

### 差异点

- PiliPlus 在富文本中的话题标签跳转到搜索页
- 我们的实现优先跳转到话题页（如果有 ID）
- 这样可以提供更好的用户体验
