## 白屏的可能原因

### 1. 视频加载失败
视频控制器初始化后会请求视频播放URL，如果请求失败会导致白屏。

### 2. 播放器初始化失败
播放器组件可能因为某些原因无法正常初始化。

### 3. 视频详情获取失败
虽然有封面，但视频详情（标题、UP主等）可能获取失败。

## 已完成的修复

### 1. 路由跳转方式 ✅
```dart
// 使用查询字符串格式
Get.toNamed('/video?bvid=$bvid&cid=$cid', arguments: {...});
```

### 2. 参数传递 ✅
```dart
arguments: {
  'videoItem': videoItem,  // BgmRecommend对象
  'pic': videoItem.cover,  // 封面图片
  'heroTag': 'music_video_${videoItem.bvid}',
}
```

### 3. 视频控制器兼容性 ✅
添加了对BgmRecommend对象的支持：
- 自动从`cover`字段获取封面（如果`pic`不存在）
- 从`arguments.pic`获取封面作为备用
- 添加了详细的错误处理和日志

## 测试步骤

3. 查看是否能正常跳转到视频页面

### 2. 检查日志
如果仍然白屏，查看日志中是否有：
- 视频URL请求失败
- 播放器初始化错误

### 3. 对比测试
从其他地方（如首页推荐）点击视频，看是否能正常播放。如果能，说明问题不在跳转逻辑，而在视频本身或网络。

## 下一步调试

如果仍然白屏，需要检查：

### 1. 视频是否可播放
某些视频可能有地区限制、版权限制或已被删除。

### 2. 网络连接
检查网络是否正常，API请求是否成功。

### 3. 播放器日志
查看播放器相关的错误日志。

### 4. 视频详情API
检查视频详情API是否返回正确数据：
```
GET /x/web-interface/view?bvid=BV1kkmgBnEir
```
