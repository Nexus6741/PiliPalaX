# 离线番剧播放页面修复完成

## 问题描述
离线缓存打开的番剧/影视播放页和在线播放的不同。在线播放番剧时会显示番剧特有的界面（选集列表、番剧信息等），但离线播放时显示的是普通视频界面。

## 问题分析

### 在线播放番剧的跳转方式
查看 `lib/pages/bangumi/widgets/bangumi_card_v.dart` 中的跳转代码：

```dart
Get.toNamed(
  '/video?bvid=$bvid&cid=$cid&seasonId=$seasonId&epId=$epId',
  arguments: {
    'pic': pic,
    'heroTag': heroTag,
    'videoType': SearchType.media_bangumi,  // 关键：标记为番剧类型
    'bangumiItem': res['data'],
  },
);
```

关键参数：
1. URL参数：`bvid`, `cid`, `seasonId`, `epId`
2. arguments：`videoType: SearchType.media_bangumi`（标记为番剧类型）
3. arguments：`bangumiItem`（番剧详情数据）

### 离线播放的问题
原来的离线播放跳转代码：

```dart
Get.toNamed(
  '/video',
  parameters: {
    'bvid': entry.bvid,
    'cid': entry.cid.toString(),
  },
  arguments: {
    'sourceType': 'file',
    'entry': entry,
    'dirPath': entry.entryDirPath,
    'heroTag': heroTag,
    'pic': entry.cover,
  },
);
```

缺少的关键信息：
- 没有传递 `seasonId` 和 `epId`
- 没有传递 `videoType: SearchType.media_bangumi`
- 导致视频控制器无法识别这是番剧，使用了普通视频的界面

## 修复方案

### 1. 修改 `_playVideo` 方法
在 `lib/pages/download/view.dart` 中，修改 `_playVideo` 方法，根据 `entry` 的类型判断是否为番剧：

```dart
void _playVideo(DownloadEntryInfo entry) {
  final heroTag =
      '${entry.bvid}_${entry.cid}_${DateTime.now().millisecondsSinceEpoch}';

  // 判断是否为番剧/影视
  final isBangumi = entry.seasonId != null && entry.ep != null;

  if (isBangumi) {
    // 番剧/影视：使用与在线播放相同的跳转方式
    Get.toNamed(
      '/video?bvid=${entry.bvid}&cid=${entry.cid}&seasonId=${entry.seasonId}&epId=${entry.ep!.episodeId}',
      arguments: {
        'sourceType': 'file',
        'entry': entry,
        'dirPath': entry.entryDirPath,
        'pic': entry.cover,
        'heroTag': heroTag,
        'videoType': SearchType.media_bangumi,  // 标记为番剧类型
      },
    );
  } else {
    // 普通视频
    Get.toNamed(
      '/video',
      parameters: {
        'bvid': entry.bvid,
        'cid': entry.cid.toString(),
      },
      arguments: {
        'sourceType': 'file',
        'entry': entry,
        'dirPath': entry.entryDirPath,
        'heroTag': heroTag,
        'pic': entry.cover,
      },
    );
  }
}
```

### 2. 统一使用 `_playVideo` 方法
将所有播放视频的地方统一使用 `_playVideo` 方法：

1. `_buildSingleEntryItem` 的 onTap
2. `_buildExpandedEntryItem` 的 onTap
3. `_buildQualityItem` 的 onTap
4. `_buildEpisodeItem` 的 onTap（单画质时）

### 3. 添加必要的导入
在文件顶部添加 `SearchType` 的导入：

```dart
import 'package:PiliPalaX/models/common/search_type.dart';
```

## 数据支持

`DownloadEntryInfo` 模型已经包含了番剧所需的字段：
- `seasonId`: 番剧季度ID
- `ep`: 剧集信息（包含 `episodeId`）

这些字段在下载番剧时已经正确保存，所以可以直接使用。

## 修复效果

### 修复前
- 离线播放番剧时显示普通视频界面
- 无法看到选集列表
- 无法看到番剧信息

### 修复后
- 离线播放番剧时显示番剧专用界面
- 可以看到选集列表（虽然只能播放已下载的集）
- 可以看到番剧信息、评分等
- 与在线播放番剧的体验一致
