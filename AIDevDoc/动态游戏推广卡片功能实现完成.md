### 2. UI 实现

更新 `lib/pages/dynamics/widgets/additional_panel.dart`：

#### 游戏推广卡片布局

**整体结构**：
```
┌─────────────────────────────────────┐
│ [图标] 标题                  [按钮] │
│        描述1                        │
│        描述2                        │
└─────────────────────────────────────┘
```

**组件层次**：
- Material（背景色 + 圆角）
  - InkWell（点击效果）
    - Padding（内边距 12x8）
      - Row（横向布局）
        - 封面图（45x45，圆角 6）
        - 间距（10）
        - Expanded（文本区域）
          - Column（纵向布局）
            - 标题（1 行，省略）
            - 描述1（1 行，省略，灰色，13px）
            - 描述2（1 行，省略，灰色，13px）
        - 间距（10）
        - FilledButton.tonal（按钮）

#### 样式细节

**背景色**：
- floor == 1：`dividerColor.withValues(alpha: 0.08)`
- floor != 1：`colorScheme.surface`

**圆角**：
- floor == 1：无圆角
- floor != 1：6px 圆角

**封面图**：
- 尺寸：45x45
- 圆角：6px
- 右侧间距：10px

**文本样式**：
- 标题：默认样式，1 行省略
- 描述：灰色（`colorScheme.outline`），13px，1 行省略

**按钮样式**：
- 类型：FilledButton.tonal
- 圆角：6px
- 内边距：横向 10px
- 紧凑布局：`visualDensity: VisualDensity(horizontal: -2, vertical: -3)`
- 文本：优先使用 `jumpStyle.text`，其次 `text`，默认"进入"

### 3. 交互功能

#### 卡片点击
- 点击整个卡片区域跳转到游戏详情页
- 使用 webview 打开 `jumpUrl`
- 传递标题作为页面标题

#### 按钮点击
- 点击按钮跳转到游戏详情页
- 使用 webview 打开 `button.jumpUrl`
- 优先级高于卡片点击

#### 跳转参数
```dart
Get.toNamed(
  '/webview',
  parameters: {
    'url': jumpUrl,
    'type': 'url',
    'pageTitle': title ?? ''
  },
);
```

## 对比 PiliPlus

### 相同点

- ✅ 相同的布局结构
- ✅ 相同的尺寸和间距
- ✅ 相同的圆角和背景色
- ✅ 相同的按钮样式
- ✅ 相同的点击行为

### 差异点

- PiliPlus 使用 `PiliScheme.routePushFromUrl` 处理跳转
- 我们使用 `Get.toNamed('/webview')` 跳转
- 功能效果相同，实现方式略有不同

## 技术细节

### 条件渲染

使用 Dart 的条件表达式和展开运算符：
```dart
if (content.cover != null && content.cover!.isNotEmpty) ...[
  // 显示封面图
],
```

### 文本省略

使用 `maxLines` 和 `overflow`：
```dart
Text(
  content.title!,
  maxLines: 1,
  overflow: TextOverflow.ellipsis,
)
```

### 按钮优先级

按钮文本优先级：
1. `button.jumpStyle.text`
2. `button.text`
3. 默认值"进入"

```dart
Text(
  content.button!.jumpStyle?.text ??
  content.button!.text ??
  '进入',
)
```

### 布局适配

根据 `floor` 参数调整样式：
- `floor == 1`：动态详情页，无圆角
- `floor != 1`：转发动态，有圆角
