# 用户空间功能完善 - 分步实施指南

## 项目背景
当前项目的用户空间功能较为简陋，需要参考 PiliPlus 项目进行完善，包括UI布局、功能细节等方面。

## 核心差异对比

### 当前状态
- 3个Tab：动态、投稿、合集/列表
- 简单的用户信息展示
- 基础的关注/分享功能

### 目标状态（PiliPlus）
- 多个Tab：主页、动态、投稿（含子Tab）、追番、收藏、课程、商品
- 完善的用户信息卡片（背景图、挂件、认证、共同关注等）
- 丰富的菜单功能（登录设备、记录查询、空间设置等）

## 分步实施方案

### 阶段一：核心UI重构（优先级最高）

#### 1.1 用户信息卡片完善
**目标：** 实现与 PiliPlus 一致的用户信息展示

**需要添加的元素：**
- 顶部背景图（支持日间/夜间）
- 头像挂件显示
- 直播状态标识
- VIP标签独立样式
- 勋章展示
- 认证信息带图标
- 共同关注展示
- 空间标签
- 封禁状态提示
- 推广信息
- 私信按钮
- 多状态关注按钮

**实施步骤：**
1. 创建 `lib/pages/member/widgets/user_info_card.dart`
2. 参考 PiliPlus 实现完整的卡片布局
3. 支持横屏/竖屏两种布局
4. 添加必要的数据模型支持

#### 1.2 主页Tab实现
**目标：** 添加"主页"Tab，展示用户内容概览

**展示内容：**
- 视频投稿（4-8个）
- 收藏夹（第一个）
- 最近投币视频（2-4个）
- 最近点赞视频（2-4个）
- 图文（第一个）
- 音频（1-3个）
- 漫画（1-3个）
- 追番（3-6个）

**实施步骤：**
1. 创建 `lib/pages/member_home/` 目录
2. 实现 `view.dart` 和 `controller.dart`
3. 创建各类内容的卡片组件
4. 实现"查看更多"跳转逻辑

#### 1.3 菜单功能完善
**目标：** 添加更多菜单选项

**自己的空间新增：**
- 充电排行榜
- 大会员经验
- 登录设备
- 登录记录
- 硬币记录
- 经验记录
- 空间设置

**他人空间新增：**
- 移除粉丝
- 充电排行榜
- 举报

**实施步骤：**
1. 更新 `lib/pages/member/view.dart` 的菜单项
2. 创建简单的记录查看页面
3. 实现基础的跳转逻辑
