# 三级展开下载列表实现完成

## 功能概述
实现了三级展开的下载列表结构，支持按视频/番剧 → 选集/分P → 画质的层级展示，优化了多集视频和番剧的下载管理体验。

## 三级结构

### 一级：视频/番剧（按 pageId 分组）
- 显示视频/番剧的总标题
- 显示封面
- 显示集数或画质数量
- 番剧显示类型标签（番剧/电影/纪录片等）

### 二级：选集/分P（按 cid 分组）
- 番剧：显示"第X集"
- 普通视频：显示"PX 标题"
- 显示该集的画质数量
- 只有一个画质时直接播放，多个画质时可展开

### 三级：画质（按 quality 分组）
- 显示画质标签（360P、720P、1080P等）
- 显示文件大小
- 点击直接播放

## 实现细节

### 1. 新增模型
**文件**: `lib/models/download/download_episode_info.dart`

```dart
class DownloadEpisodeInfo {
  final int cid;
  final String title;
  final String cover;
  final int sortKey;
  final List<DownloadEntryInfo> entries;
  bool isExpanded;
  
  // 获取选集标题（显示集数信息）
  String get episodeTitle;
  
  // 获取画质数量文本
  String get qualityCountText;
}
```

### 2. 修改模型
**文件**: `lib/models/download/download_page_info.dart`

添加了：
- `episodes`: 选集分组列表
- `hasMultipleEpisodes`: 是否有多个选集
- `episodeCountText`: 选集数量文本

### 3. 控制器逻辑
**文件**: `lib/pages/download/controller.dart`

#### 添加方法
```dart
// 构建选集分组（按cid分组）
List<DownloadEpisodeInfo> _buildEpisodes(List<DownloadEntryInfo> entries)

// 切换选集展开状态
void toggleEpisodeExpanded(DownloadEpisodeInfo episodeInfo)
```

#### 分组逻辑
1. 按 `pageId` 分组（视频/番剧）
2. 对每个页面，按 `cid` 分组（选集）
3. 对每个选集，按 `quality` 排序（画质）

### 4. UI实现
**文件**: `lib/pages/download/view.dart`

#### 新增方法

## UI展示逻辑

### 单集单画质
```
视频标题
  └─ 直接显示画质标签
```

### 单集多画质
```
视频标题 (X个画质)
  ├─ 展开 ▼
  ├─ 1080P 60帧 (500MB) ▶️
  ├─ 1080P (400MB) ▶️
  └─ 720P (200MB) ▶️
```

### 多集单画质
```
番剧标题 (12集)
  ├─ 展开 ▼
  ├─ 第1集 (1080P) ▶️
  ├─ 第2集 (1080P) ▶️
  └─ 第3集 (1080P) ▶️
```

### 多集多画质（完整三级）
```
番剧标题 (12集)
  ├─ 展开 ▼
  ├─ 第1集 (3个画质)
  │   ├─ 展开 ▼
  │   ├─ 1080P 60帧 (500MB) ▶️
  │   ├─ 1080P (400MB) ▶️
  │   └─ 720P (200MB) ▶️
  ├─ 第2集 (3个画质)
  │   └─ 收起 ▶
  └─ 第3集 (3个画质)
      └─ 收起 ▶
```

## 交互逻辑

### 一级卡片（视频/番剧）
- **点击**：展开/收起选集列表
- **长按**：显示操作菜单（删除整个视频/番剧）
- **多选模式**：选择该视频/番剧

### 二级卡片（选集）
- **单画质**：
  - 点击：直接播放
  - 长按：显示操作菜单（删除该集）
- **多画质**：
  - 点击：展开/收起画质列表
  - 长按：显示操作菜单（删除该集所有画质）

### 三级卡片（画质）
- **点击**：播放该画质
- **长按**：显示操作菜单（删除该画质）

## 视觉标识

### 封面角标
- **右下角**：显示集数或画质数量
  - "12集"：多集视频
  - "3个画质"：单集多画质
  - "1080P"：单集单画质
- **左上角**：番剧类型标签
  - "番剧"、"电影"、"纪录片"等

### 展开图标
- **▼**：已展开
- **▶**：已收起
- **▶️**：播放图标（可直接播放）

### 选集标题
- **番剧**：第1集、第2集...
- **普通视频**：P1 标题、P2 标题...

## 数据流

```
下载服务加载
    ↓
按 pageId 分组
    ↓
为每个 page 构建 episodes
    ↓
按 cid 分组
    ↓
按 quality 排序
    ↓
构建三级UI结构
```

## 优化点

### 1. 智能展开
- 单集单画质：不显示展开按钮，直接播放
- 单集多画质：展开显示画质列表
- 多集：展开显示选集列表

### 2. 排序逻辑
- 选集：按 `sortKey` 排序（集数顺序）
- 画质：按 `preferedVideoQuality` 降序（高画质在前）

### 3. 视觉层次
- 一级：8px padding
- 二级：左侧 16px 缩进
- 三级：左侧 32px 缩进（16+16）

### 4. 操作便捷性
- 单画质直接点击播放
- 多画质展开选择
- 长按显示更多操作
