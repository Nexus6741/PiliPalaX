## 调试步骤

### 第一步：检查设置是否启用
1. 打开应用，进入设置页面
2. 找到"空降助手"相关设置
3. 确认以下设置：
   - `enableSponsorBlock`: 是否启用 SponsorBlock
   - `enablePgcSkip`: 是否启用番剧片头片尾跳过
   - `blockSettings`: 各类型片段的跳过方式

**预期结果**：至少有一个功能启用（`enableSponsorBlock` 或 `enablePgcSkip`）

### 第二步：播放视频并查看日志
1. 选择一个普通视频（非番剧）播放
2. 查看控制台日志输出
3. 检查以下关键点：

#### 2.1 初始化检查
```
🔍 [playerInit] 检查是否查询 SponsorBlock
🔍 enableBlock: true, autoplay: true  <-- 应该都是 true
```

**如果 enableBlock 为 false**：
- 检查设置中是否启用了 SponsorBlock 或番剧跳过
- 路径：`lib/pages/video/controller.dart` 第 120-124 行

**如果 autoplay 为 false**：
- 检查是否设置了自动播放
- 路径：设置 -> 播放器 -> 自动播放

#### 2.2 查询检查
```
🔍 [querySponsorBlock] 开始查询
🔍 enableBlock: true (enableSponsorBlock: true, enablePgcSkip: true)
🔍 普通视频，查询 SponsorBlock
```

**如果没有看到这些日志**：
- 说明 `querySponsorBlock()` 没有被调用
- 检查 `playerInit()` 中的条件判断

#### 2.3 API 请求检查
```
🔍 [_querySponsorBlockSegments] 开始请求 API
🔍 bvid: BV1..., cid: 123456
🔍 API 返回结果类型: Success<List<SegmentItemModel>>
✅ 成功获取片段，数量: 3
```

**如果返回 404 错误**：
- 说明该视频没有 SponsorBlock 数据
- 尝试播放其他热门视频

**如果返回其他错误**：
- 检查网络连接
- 检查 SponsorBlock 服务器地址设置

#### 2.4 片段处理检查
```
🔍 查询完成，segmentList.length: 3
```

**如果 segmentList 为空**：
- 检查 `_handleSegmentData()` 是否正确处理数据
- 检查片段是否被过滤掉（太短、类型被禁用等）

### 第三步：检查按钮显示
1. 进入全屏模式
2. 查看控制栏是否显示按钮
3. 查看日志：

```
🔍 [submitSegmentButton] enableSponsorBlock: true
🔍 [segmentInfoButton] segmentList.length: 3
```

**如果按钮不显示**：
- 提交按钮：检查 `enableSponsorBlock` 是否为 true
- 信息按钮：检查 `segmentList` 是否为空
- 确认是否在全屏模式（按钮只在全屏时显示）

### 第四步：检查自动跳过
1. 播放到广告片段位置
2. 查看是否自动跳过
3. 查看日志：

```
🔍 [_initSkipListener] 初始化监听
🔍 检测到片段: sponsor, 1000ms - 5000ms
✅ 已跳过sponsor
```

**如果没有自动跳过**：
- 检查 `_initSkipListener()` 是否被调用
- 检查片段的 `skipType` 设置（应该是 `alwaysSkip` 或 `skipOnce`）
- 检查播放位置监听是否正常工作

## 常见问题

### Q1: 按钮只在全屏时显示吗？
A: 是的，根据代码 `header_control.dart` 第 1820 行，按钮只在全屏模式下显示。

### Q2: 如何测试功能？
A: 
1. 找一个有广告的热门视频（如 BV1xx411c7mD）
2. 启用 SponsorBlock 功能
3. 播放视频并进入全屏
4. 查看是否自动跳过广告

### Q3: 为什么有些视频没有数据？
A: SponsorBlock 是众包数据，不是所有视频都有标记。建议测试热门视频。

### Q4: 如何手动提交片段？
A: 点击提交按钮（盾牌图标），但目前该功能还在开发中。
