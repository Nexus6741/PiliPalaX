# 弹幕即时预览调试指南

## 问题描述
发送弹幕后，弹幕没有立即显示在播放器中进行预览。

## 调试步骤

### 1. 检查弹幕控制器初始化
运行应用并播放视频，查看日志中是否有：
```
🎯 弹幕控制器已初始化
🎯 弹幕是否开启: true
🎯 控制器地址: [数字]
```

**如果没有看到这些日志：**
- 检查 `PlDanmaku` 组件是否正确传递给 `PLVideoPlayer`
- 检查弹幕是否被禁用（`isOpenDanmu` 为 false）

### 2. 检查发送弹幕流程
发送一条弹幕，查看日志输出顺序：

**预期日志顺序：**
```
🎯 弹幕发送成功，准备添加到播放器
🎯 弹幕内容: [你的弹幕内容]
🎯 弹幕类型: DanmakuItemType.scroll
🎯 selfSend: true
🎯 已调用 onSendSuccess
🎯 PLVideoPlayer 收到弹幕: [你的弹幕内容]
🎯 弹幕控制器是否为null: false
🎯 弹幕是否开启: true
🎯 播放器状态: PlayerStatus.playing
🎯 已调用 danmakuController.addDanmaku
🎯 弹幕内容: [你的弹幕内容]
🎯 弹幕类型: DanmakuItemType.scroll
🎯 selfSend: true
```

### 3. 常见问题排查

#### 问题1: 弹幕控制器为null
**日志特征：**
```
❌ 弹幕控制器为null，无法添加弹幕
```

**可能原因：**
- `DanmakuScreen` 的 `createdController` 回调未被调用
- 弹幕功能被禁用，导致 `PlDanmaku` 组件未渲染

**解决方案：**
- 确保 `isOpenDanmu.value == true`
- 检查 `PlDanmaku` 组件是否在视图树中

#### 问题2: 弹幕已添加但不显示
**日志特征：**
```
🎯 已调用 danmakuController.addDanmaku
```
但屏幕上看不到弹幕

**可能原因：**
1. 弹幕透明度设置为0
2. 弹幕被屏蔽类型过滤
3. 弹幕显示区域设置问题
4. canvas_danmaku 包的 `addDanmaku` 方法需要特定参数

**解决方案：**
- 检查弹幕设置：透明度、显示区域、屏蔽类型
- 对比 PiliPlus 的实现，确认 `DanmakuContentItem` 参数是否正确
- 检查 `addDanmaku` 是否需要在特定时机调用（如播放器正在播放时）

#### 问题3: 回调链断裂
**日志特征：**
只看到 `🎯 弹幕发送成功，准备添加到播放器`，但没有后续日志

**可能原因：**
- `onSendSuccess` 回调未正确传递
- 回调函数中抛出异常

**解决方案：**
- 检查 `DanmakuInputBar` → `PLVideoPlayer` 的回调传递链
- 在回调中添加 try-catch 捕获异常

#### 问题4: 播放器状态问题
**日志特征：**
```
🎯 播放器状态: PlayerStatus.paused
```

**可能原因：**
- 发送弹幕时播放器被暂停
- `addDanmaku` 可能需要播放器处于播放状态

**解决方案：**
- 检查发送弹幕时是否自动暂停了播放器
- 尝试在添加弹幕前确保播放器处于播放状态

### 4. 对比 PiliPlus 实现

#### PiliPlus 的关键代码
```dart
// PiliPlus/lib/pages/video/controller.dart
callback: (danmakuModel) {
  savedDanmaku = null;
  plPlayerController.danmakuController?.addDanmaku(danmakuModel);
},
```

#### 我们的实现
```dart
// lib/plugin/pl_player/view.dart
onSendSuccess: (danmakuItem) {
  _.danmakuController?.addDanmaku(danmakuItem);
},
```

**关键差异：**
- PiliPlus 直接在 controller 中调用
- 我们通过回调链传递

**验证点：**
- 确认 `DanmakuContentItem` 的参数是否一致
- 确认调用时机是否相同

### 5. 手动测试步骤

1. **启动应用并播放视频**
   - 确认弹幕功能已开启（右上角弹幕开关）
   - 确认能看到其他弹幕正常显示

2. **发送测试弹幕**
   - 点击底部弹幕输入框
   - 输入测试内容（如 "测试123"）
   - 点击发送

3. **观察现象**
   - 是否立即看到弹幕飞过？
   - 查看日志输出
   - 记录任何错误信息

4. **测试不同场景**
   - 播放中发送
   - 暂停时发送
   - 不同弹幕类型（滚动、顶部、底部）
   - 不同颜色

### 6. 深度调试

如果以上步骤都正常，但弹幕仍不显示，需要：

1. **检查 canvas_danmaku 包**
   - 查看 `addDanmaku` 方法的实现
   - 确认是否有返回值或异步操作
   - 查看是否有内部过滤逻辑

2. **添加更多日志**
   在 `lib/pages/danmaku/view.dart` 的 `videoPositionListen` 方法中添加：
   ```dart
   debugPrint('🎯 当前位置: $currentPosition ms');
   debugPrint('🎯 弹幕列表长度: ${currentDanmakuList?.length ?? 0}');
   ```

3. **对比正常弹幕和即时弹幕**
   - 正常弹幕（从服务器加载）能否显示？
   - 即时弹幕和正常弹幕的参数有何不同？

### 7. 可能的解决方案

#### 方案1: 延迟添加
```dart
onSendSuccess: (danmakuItem) {
  Future.delayed(Duration(milliseconds: 100), () {
    _.danmakuController?.addDanmaku(danmakuItem);
  });
},
```

#### 方案2: 确保播放状态
```dart
onSendSuccess: (danmakuItem) {
  if (_.playerStatus.status.value != PlayerStatus.playing) {
    _.play();
  }
  _.danmakuController?.addDanmaku(danmakuItem);
},
```

#### 方案3: 手动触发渲染
```dart
onSendSuccess: (danmakuItem) {
  _.danmakuController?.addDanmaku(danmakuItem);
  // 可能需要调用某个刷新方法
},
```
