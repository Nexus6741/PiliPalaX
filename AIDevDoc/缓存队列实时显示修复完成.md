# 缓存队列实时显示修复完成

## 问题描述

用户反馈离线缓存功能存在以下严重问题：

1. **队列不显示**：点击视频离线缓存后，打开离线缓存页面看不到正在缓存的视频
2. **需要重启才能看到**：只有重新启动应用才能看到缓存队列中的视频
3. **进度不更新**：即使看到了视频，也一直显示"等待中"，进度条不动

## 根本原因分析

### 1. 队列管理逻辑错误

**原有逻辑**：
```dart
Future<void> startDownload() {
  // 从队列中移除第一个视频
  final entry = waitDownloadQueue.removeAt(0);
  _curCid = entry.cid;
  curDownload.value = entry;
  // 开始下载...
}
```

**问题**：
- 开始下载时就把视频从 `waitDownloadQueue` 中移除了
- UI 监听的是 `waitDownloadQueue`，所以看不到正在下载的视频
- 正在下载的视频只保存在 `curDownload` 中，但 UI 没有直接显示这个变量

### 2. 进度更新无法传递

**问题链**：
1. 正在下载的视频被从队列中移除
2. UI 只监听 `waitDownloadQueue` 的变化
3. 进度更新发生在 `curDownload.value` 上
4. UI 看不到 `curDownload` 的进度变化

### 3. 重启后才能看到的原因

**初始化逻辑**：
```dart
Future<void> _readDownloadList() async {
  // 读取未完成的下载
  if (entry.isCompleted) {
    result.add(entry);
  } else {
    entry.status.value = DownloadStatus.wait;
    waitDownloadQueue.add(entry);  // 重新加入队列
  }
}
```

重启应用时，`_readDownloadList()` 会读取所有未完成的下载并重新加入队列，所以能看到。

## 解决方案

### 核心思路：保持正在下载的视频在队列中

不要在开始下载时从队列中移除视频，而是：
1. 保持视频在队列中
2. 用 `_curCid` 标记当前正在下载的视频
3. 只在下载完成或失败时才从队列中移除

### 主要修改

#### 1. 修改 `startDownload()` - 不移除队列项

```dart
Future<void> startDownload() {
  return _lock.synchronized(() async {
    if (waitDownloadQueue.isEmpty) {
      return;
    }
    if (curDownload.value != null) {
      return;
    }

    // 不要从队列中移除，只是标记为当前下载
    final entry = waitDownloadQueue.first;
    _curCid = entry.cid;
    curDownload.value = entry;

    try {
      await _startDownload(entry);
    } catch (e) {
      entry.status.value = DownloadStatus.failPlayUrl;
      _curCid = null;
      curDownload.value = null;
      // 从队列中移除失败的项
      waitDownloadQueue.remove(entry);
      // 启动下一个下载
      startDownload();
    }
  });
}
```

**改进**：
- 使用 `waitDownloadQueue.first` 而不是 `removeAt(0)`
- 视频保持在队列中，UI 可以实时看到
- 只在失败时才移除

#### 2. 修改 `_completeDownload()` - 完成时移除

```dart
Future<void> _completeDownload() async {
  final entry = curDownload.value;
  if (entry == null) return;

  entry.downloadedBytes.value = entry.totalBytes.value;
  entry.isCompleted = true;
  await _updateBiliDownloadEntryJson(entry);

  // 从等待队列中移除已完成的项
  waitDownloadQueue.remove(entry);
  // 添加到已完成列表
  downloadList.insert(0, entry);
  flagNotifier.refresh();

  _curCid = null;
  curDownload.value = null;
  videoManager = null;
  audioManager = null;

  // 启动下一个下载
  startDownload();
}
```

**改进**：
- 下载完成后才从队列中移除
- 移动到已完成列表

#### 3. 修改 `cancelDownload()` - 暂停保留，删除移除

```dart
Future<void> cancelDownload({
  required bool isDelete,
  bool downloadNext = true,
}) async {
  // ... 取消下载逻辑 ...

  final entry = curDownload.value;
  if (entry != null) {
    if (!isDelete) {
      await _updateBiliDownloadEntryJson(entry);
      entry.status.value = DownloadStatus.pause;
      // 暂停时保持在队列中，不需要重新插入
    } else {
      // 删除操作：从队列中移除并删除本地文件
      waitDownloadQueue.remove(entry);
      await _deleteDownloadFiles(entry);
    }
  }
  // ...
}
```

**改进**：
- 暂停时保持在队列中
- 删除时才从队列中移除

#### 4. 修改 `_onDone()` - 失败时移除

```dart
void _onDone([Object? error]) {
  final entry = curDownload.value;
  if (entry == null) return;

  if (error != null) {
    entry.status.value = videoManager?.status ?? DownloadStatus.pause;
    // 如果是暂停，保留在队列中；如果是失败，从队列中移除
    if (entry.status.value != DownloadStatus.pause) {
      waitDownloadQueue.remove(entry);
    }
    return;
  }

  final status = audioManager?.status == DownloadStatus.downloading
      ? DownloadStatus.audioDownloading
      : audioManager?.status == DownloadStatus.failDownload
          ? DownloadStatus.failDownloadAudio
          : videoManager?.status ?? DownloadStatus.pause;
  entry.status.value = status;

  entry.downloadedBytes.value = entry.totalBytes.value;
  if (status == DownloadStatus.completed) {
    _completeDownload();
  } else {
    _updateBiliDownloadEntryJson(entry);
    // 如果失败，从队列中移除
    if (status == DownloadStatus.failDownload || 
        status == DownloadStatus.failDownloadAudio) {
      waitDownloadQueue.remove(entry);
    }
  }
}
```

**改进**：
- 区分暂停和失败
- 失败时从队列中移除

#### 5. 修改 `removeFromWaitingQueue()` - 处理当前下载

```dart
Future<void> removeFromWaitingQueue(DownloadEntryInfo entry) async {
  // 如果是当前正在下载的，需要先取消
  if (curDownload.value?.cid == entry.cid) {
    await cancelDownload(isDelete: true, downloadNext: true);
  } else {
    waitDownloadQueue.remove(entry);
    await _deleteDownloadFiles(entry);
    flagNotifier.refresh();
  }
}
```

**改进**：
- 正确处理正在下载的视频的取消

#### 6. 修改 `clearWaitingQueue()` - 先取消当前下载

```dart
Future<void> clearWaitingQueue() async {
  // 先取消当前下载
  if (curDownload.value != null) {
    await cancelDownload(isDelete: true, downloadNext: false);
  }
  
  final entries = List<DownloadEntryInfo>.from(waitDownloadQueue);
  waitDownloadQueue.clear();

  // 删除所有等待中的下载文件
  for (final entry in entries) {
    await _deleteDownloadFiles(entry);
  }

  flagNotifier.refresh();
}
```

**改进**：
- 清空队列前先取消当前下载

## 数据流程图

### 修复前（错误）
```
添加下载 → 加入队列 → 开始下载（从队列移除）→ UI看不到
                                    ↓
                              curDownload（UI不监听）
```

### 修复后（正确）
```
添加下载 → 加入队列 → 开始下载（保留在队列）→ UI实时显示
                          ↓
                    标记 _curCid
                          ↓
                    进度更新（队列中的entry）
                          ↓
                    完成/失败（从队列移除）
```

## 总结

此次修复彻底解决了缓存队列显示和进度更新的问题。核心改进是：

1. **保持队列完整性**：正在下载的视频保留在队列中
2. **状态标记清晰**：用 `_curCid` 标记当前下载，而不是从队列中移除
3. **生命周期管理**：只在完成、失败或删除时才从队列中移除
4. **UI 响应实时**：UI 监听的队列始终包含所有活跃的下载任务

用户现在可以：
- ✅ 立即看到新添加的缓存任务
- ✅ 实时查看下载进度
- ✅ 清楚了解队列状态
- ✅ 正确管理缓存任务

这是一个关键的用户体验改进！
