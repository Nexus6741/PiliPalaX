# 缓存暂停继续功能完善

## 问题描述

用户反馈缓存功能还存在问题：

1. **跳过不生效**：点击跳过后，当前视频暂停一下又立马继续缓存
2. **暂停后缺少继续按钮**：暂停后应该显示继续/播放图标，点击后恢复下载

## 根本原因分析

### 1. 跳过功能问题

**问题代码 - `skipCurrentDownload()`**:
```dart
Future<void> skipCurrentDownload() async {
  // ... 暂停当前下载
  entry.status.value = DownloadStatus.pause;
  
  // ❌ 直接调用 startDownload()
  startDownload();
}
```

**问题代码 - `startDownload()`**:
```dart
Future<void> startDownload() {
  // ❌ 总是选择队列第一个
  final entry = waitDownloadQueue.first;
  _curCid = entry.cid;
  curDownload.value = entry;
  // ...
}
```

**问题链**：
1. 跳过当前下载，标记为暂停
2. 调用 `startDownload()`
3. `startDownload()` 选择队列第一个（就是刚暂停的）
4. 又开始下载刚暂停的视频

### 2. 缺少继续功能

**问题**：
- 暂停后按钮仍然显示"暂停"图标
- 没有"继续"按钮
- 用户无法恢复暂停的下载

## 解决方案

### 1. 修复跳过逻辑

#### 修改 `skipCurrentDownload()` - 使用锁

```dart
/// 跳过当前下载，继续下一个
Future<void> skipCurrentDownload() async {
  return _lock.synchronized(() async {  // ✅ 使用锁
    final entry = curDownload.value;
    if (entry == null) return;

    // 取消当前下载
    await videoManager?.cancel(isDelete: false);
    await audioManager?.cancel(isDelete: false);

    // 标记为暂停状态
    entry.status.value = DownloadStatus.pause;
    await _updateBiliDownloadEntryJson(entry);

    // 清理状态
    _curCid = null;
    curDownload.value = null;
    videoManager = null;
    audioManager = null;

    // ✅ 启动下一个下载（跳过暂停的）
    _startNextDownload();
  });
}
```

#### 新增 `_startNextDownload()` 方法

```dart
/// 启动下一个未暂停的下载
void _startNextDownload() {
  // ✅ 查找第一个未暂停的视频
  final nextEntry = waitDownloadQueue.firstWhereOrNull(
    (e) => e.status.value != DownloadStatus.pause,
  );
  
  if (nextEntry != null) {
    startDownload();
  }
}
```

#### 修改 `startDownload()` - 跳过暂停的视频

```dart
Future<void> startDownload() {
  return _lock.synchronized(() async {
    if (waitDownloadQueue.isEmpty) {
      return;
    }
    if (curDownload.value != null) {
      return;
    }

    // ✅ 查找第一个未暂停的视频
    final entry = waitDownloadQueue.firstWhereOrNull(
      (e) => e.status.value != DownloadStatus.pause,
    );
    
    if (entry == null) {
      // 队列中都是暂停的视频
      return;
    }

    _curCid = entry.cid;
    curDownload.value = entry;

    await _startDownload(entry);
  });
}
```

**改进**：
- 跳过时使用锁，避免竞态条件
- `startDownload()` 自动跳过暂停的视频
- 只下载未暂停的视频

### 2. 添加继续功能

#### 新增 `resumeDownload()` 方法

```dart
/// 继续下载（恢复暂停的下载）
Future<void> resumeDownload(DownloadEntryInfo entry) async {
  if (entry.status.value != DownloadStatus.pause) return;
  
  // ✅ 重置状态为等待
  entry.status.value = DownloadStatus.wait;
  await _updateBiliDownloadEntryJson(entry);
  
  // ✅ 如果当前没有下载，立即开始
  if (curDownload.value == null) {
    startDownload();
  }
}
```

**功能**：
- 将暂停状态改为等待状态
- 如果当前没有下载，立即开始
- 如果有其他下载，等待轮到它

#### 修改UI - 根据状态显示不同按钮

```dart
// 操作按钮
Row(
  mainAxisSize: MainAxisSize.min,
  children: [
    if (isCurrentDownloading) ...[
      // ✅ 根据状态显示暂停或继续按钮
      if (status == DownloadStatus.pause)
        // 继续按钮
        IconButton(
          icon: const Icon(Icons.play_arrow),  // ▶️ 播放图标
          onPressed: () {
            _downloadService.resumeDownload(entry);
            SmartDialog.showToast('继续下载');
          },
          tooltip: '继续下载',
        )
      else
        // 暂停按钮
        IconButton(
          icon: const Icon(Icons.pause),  // ⏸️ 暂停图标
          onPressed: () {
            _downloadService.cancelDownload(
              isDelete: false,
              downloadNext: false,
            );
            SmartDialog.showToast('已暂停下载');
          },
          tooltip: '暂停下载',
        ),
      // 跳过按钮
      IconButton(...),
      // 删除按钮
      IconButton(...),
    ] else
      // 等待中的视频：取消按钮
      IconButton(...),
  ],
),
```

**改进**：
- 暂停状态显示播放图标（▶️）
- 下载中显示暂停图标（⏸️）
- 点击播放图标恢复下载

## 用户操作指南

### 场景 1：跳过卡住的视频

1. 发现第一个视频下载很慢或卡住
2. 点击"跳过"按钮（⏭️）
3. **结果**：
   - 第一个视频暂停，显示"暂停中"
   - 自动开始下载第二个视频
   - 第一个视频保留在队列中

### 场景 2：暂停后继续

1. 点击"暂停"按钮（⏸️）
2. **结果**：
   - 下载暂停
   - 按钮变为播放图标（▶️）
   - 状态显示"暂停中"
3. 点击"播放"按钮（▶️）
4. **结果**：
   - 下载继续
   - 按钮变回暂停图标（⏸️）
   - 进度继续更新

### 场景 3：多个视频暂停

1. 暂停第一个视频
2. 第二个视频自动开始下载
3. 暂停第二个视频
4. 第三个视频自动开始下载
5. 点击第一个视频的播放按钮
6. **结果**：
   - 第一个视频状态变为"等待中"
   - 等待第三个下载完成后开始
