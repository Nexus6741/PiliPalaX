# 下载崩溃修复完成

## 问题描述

用户反馈：缓存的视频在缓存完成的时候还有手动暂停，都会导致应用闪退。

## 问题分析

经过分析发现崩溃主要出现在以下几个场景：

1. **下载完成时崩溃**：`_onDone` 和 `_onAudioDone` 方法中的异步操作没有异常处理
2. **手动暂停时崩溃**：`cancelSpecificDownload` 方法中的文件操作可能抛出异常
3. **UI更新崩溃**：`_completeDownload` 方法中的UI刷新操作没有异常保护
4. **文件操作崩溃**：各种文件读写操作缺乏异常处理

## 修复内容

### 1. 完善异常处理机制

#### _onReceive 方法
- **修复前**：没有异常处理，任何错误都会导致崩溃
- **修复后**：添加 try-catch 包装，安全处理进度更新
```dart
void _onReceive(int cid, int progress, int total) {
  try {
    final task = _activeDownloads[cid];
    if (task != null) {
      final entry = task.entry;
      // ... 处理逻辑
    }
  } catch (e) {
    if (kDebugMode) {
      debugPrint('Error in _onReceive: $e');
    }
  }
}
```

#### _onDone 方法
- **修复前**：直接调用异步方法，没有错误处理
- **修复后**：使用 `catchError` 处理异步操作异常
```dart
void _onDone(int cid, [Object? error]) {
  try {
    // ... 主要逻辑
    if (status == DownloadStatus.completed) {
      _completeDownload(cid).catchError((e) {
        if (kDebugMode) {
          debugPrint('Error completing download: $e');
        }
      });
    }
  } catch (e) {
    if (kDebugMode) {
      debugPrint('Error in _onDone: $e');
    }
  }
}
```

#### _onAudioDone 方法

### 3. 暂停操作安全处理

#### cancelSpecificDownload 方法
- **修复前**：暂停操作可能因为文件写入失败而崩溃
- **修复后**：分步骤异常处理，确保操作稳定
```dart
Future<void> cancelSpecificDownload(int cid, {required bool isDelete}) async {
  try {
    final task = _activeDownloads[cid];
    
    if (task != null) {
      try {
        await task.cancel(isDelete: isDelete);
      } catch (e) {
        if (kDebugMode) {
          debugPrint('Error canceling task: $e');
        }
      }
      
      if (!isDelete) {
        try {
          await _updateBiliDownloadEntryJson(task.entry);
          task.entry.status.value = DownloadStatus.pause;
          // ... 其他操作
        } catch (e) {
          if (kDebugMode) {
            debugPrint('Error updating paused task: $e');
          }
        }
      }
    }
  } catch (e) {
    if (kDebugMode) {
      debugPrint('Error in cancelSpecificDownload: $e');
    }
  }
}
```

### 4. 下载启动安全处理

#### startDownload 方法
- **修复前**：下载启动失败时没有清理状态
- **修复后**：失败时正确清理状态并启动下一个下载
```dart
Future<void> startDownload(DownloadEntryInfo entry) {
  return _lock.synchronized(() async {
    try {
      // ... 主要逻辑
      try {
        await _startDownload(entry, task);
      } catch (e) {
        if (kDebugMode) {
          debugPrint('Error starting download: $e');
        }
        // 下载失败，从活动列表中移除
        _activeDownloads.remove(entry.cid);
        // 设置失败状态
        entry.status.value = DownloadStatus.failPlayUrl;
        // 启动下一个下载
        _startNextDownload();
      }
    } catch (e) {
      if (kDebugMode) {
        debugPrint('Error in startDownload: $e');
      }
    }
  });
}
```

## 修复策略

### 1. 分层异常处理
- **外层保护**：每个主要方法都有 try-catch 包装
- **内层保护**：关键操作（文件IO、UI更新）单独处理异常
- **异步保护**：使用 `catchError` 处理异步操作异常

### 2. 状态一致性保证
- **失败恢复**：操作失败时正确清理状态
- **队列管理**：确保下载队列在异常情况下仍能正常工作
- **UI同步**：防止UI更新异常影响下载逻辑

### 3. 调试信息完善
- **错误日志**：所有异常都有详细的调试信息
- **条件输出**：只在调试模式下输出错误信息
- **上下文信息**：错误信息包含方法名和操作类型
