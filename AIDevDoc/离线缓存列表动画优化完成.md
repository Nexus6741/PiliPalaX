# 离线缓存列表动画优化完成

## 功能描述
为离线缓存页面的列表添加丝滑自然流畅的动画效果，提升用户体验。

## 实现方案

### 1. 使用的动画库
- **flutter_staggered_animations**: 用于主列表的交错动画效果
- **AnimatedSize**: 用于展开/收起的高度动画
- **SlideAnimation**: 滑入动画
- **FadeInAnimation**: 淡入动画

### 2. 动画层级

#### 一级列表（主视频列表）
使用 `flutter_staggered_animations` 实现交错动画：

```dart
AnimationConfiguration.staggeredList(
  position: index,
  duration: const Duration(milliseconds: 375),
  child: SlideAnimation(
    verticalOffset: 50.0,
    child: FadeInAnimation(
      child: // 视频卡片
    ),
  ),
)
```

**动画效果**：
- 从下往上滑入（verticalOffset: 50.0）
- 同时淡入（FadeInAnimation）
- 交错延迟（staggeredList）
- 持续时间：375ms

#### 二级列表（选集/分P列表）
使用 `AnimatedSize` + `AnimationConfiguration.staggeredList`：

```dart
AnimatedSize(
  duration: const Duration(milliseconds: 300),
  curve: Curves.easeInOut,
  child: pageInfo.isExpanded
      ? Column(
          children: episodes.map((episode) =>
            AnimationConfiguration.staggeredList(
              position: index,
              duration: const Duration(milliseconds: 300),
              child: SlideAnimation(
                verticalOffset: 30.0,
                child: FadeInAnimation(
                  child: // 选集项
                ),
              ),
            )
          ).toList(),
        )
      : const SizedBox.shrink(),
)
```

**动画效果**：
- 容器高度平滑变化（AnimatedSize）
- 子项从下往上滑入（verticalOffset: 30.0）
- 子项淡入
- 子项交错出现
- 持续时间：300ms

#### 三级列表（画质列表）
使用 `AnimatedSize` + `AnimationConfiguration.staggeredList`：

```dart
AnimatedSize(
  duration: const Duration(milliseconds: 250),
  curve: Curves.easeInOut,
  child: episode.isExpanded
      ? Column(
          children: qualities.map((quality) =>
            AnimationConfiguration.staggeredList(
              position: index,
              duration: const Duration(milliseconds: 250),
              child: SlideAnimation(
                horizontalOffset: 30.0,  // 横向滑入
                child: FadeInAnimation(
                  child: // 画质项
                ),
              ),
            )
          ).toList(),
        )
      : const SizedBox.shrink(),
)
```

**动画效果**：
- 容器高度平滑变化（AnimatedSize）
- 子项从左往右滑入（horizontalOffset: 30.0）
- 子项淡入
- 子项交错出现
- 持续时间：250ms

## 动画参数设计

### 持续时间
- **一级列表**: 375ms（较慢，给用户足够时间感知）
- **二级列表**: 300ms（中等速度）
- **三级列表**: 250ms（较快，避免等待感）

### 偏移量
- **一级列表**: 垂直 50px（明显的滑入效果）
- **二级列表**: 垂直 30px（适中的滑入效果）
- **三级列表**: 横向 30px（与二级区分，增加层次感）

### 缓动曲线
- **AnimatedSize**: `Curves.easeInOut`（平滑的加速和减速）
- **Staggered**: 默认曲线（适合交错动画）

## 技术细节

### 1. 交错动画索引
使用 `.asMap().entries` 获取索引：

```dart
pageInfo.episodes!
    .asMap()
    .entries
    .map((entry) => AnimationConfiguration.staggeredList(
          position: entry.key,  // 索引
          child: // entry.value 是实际数据
        ))
```

### 2. 条件渲染
使用三元运算符配合 `SizedBox.shrink()`：

```dart
child: isExpanded
    ? Padding(...)  // 展开时显示内容
    : const SizedBox.shrink(),  // 收起时不占空间
```

### 3. 动画组合
- `AnimatedSize`: 负责容器高度的平滑变化
- `AnimationConfiguration.staggeredList`: 负责子项的交错延迟
- `SlideAnimation`: 负责滑入效果
- `FadeInAnimation`: 负责淡入效果

### 4. 性能优化
- 使用 `const` 构造函数（如 `const SizedBox.shrink()`）
- 动画持续时间适中，避免过长导致卡顿感
- 交错延迟自动计算，无需手动管理

## 用户体验提升

### 视觉反馈
- **加载感知**: 交错动画让用户感知到内容正在加载
- **层次感**: 不同层级使用不同的动画方向（垂直/横向）
- **流畅性**: 所有动画都使用平滑的缓动曲线

### 操作反馈
- **展开/收起**: 高度平滑变化，不突兀
- **内容出现**: 子项逐个出现，不是一次性全部显示
- **视觉引导**: 动画方向引导用户视线

### 性能表现
- **轻量级**: 使用原生 Flutter 动画，性能优秀
- **流畅度**: 60fps 的动画效果
- **响应性**: 动画不阻塞用户交互
