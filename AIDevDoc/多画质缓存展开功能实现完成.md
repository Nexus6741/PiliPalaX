# 多画质缓存展开功能实现完成

## 需求描述

用户反馈：点击包含多个画质的缓存视频会提示"合集详情页开发中"，希望点击这个缓存视频卡片后，卡片下方能展开一个二级列表，展示各个画质的选项，用户可以点击选择具体画质进行观看。

## 功能设计

### 交互逻辑
1. **主卡片显示**：显示视频标题、封面、包含的画质标签
2. **点击展开**：点击主卡片展开/收起画质列表
3. **画质选择**：在展开的列表中点击具体画质进行播放
4. **视觉反馈**：展开/收起图标提示当前状态

### UI设计
- **主卡片**：保持原有样式，增加展开/收起图标
- **子项列表**：缩进显示，突出画质标签
- **播放图标**：每个画质项右侧显示播放按钮

```dart
class DownloadPageController extends GetxController {
```

#### 展开列表实现
```dart
Widget _buildMultiEntryItem(...) {
  return Column(
    mainAxisSize: MainAxisSize.min,
    children: [
      // 主卡片
      Material(...),
      
      // 展开的子项列表
      if (pageInfo.isExpanded && !enableMultiSelect)
        Padding(
          padding: const EdgeInsets.only(left: 16, top: 4),
          child: Column(
            children: pageInfo.entries.map((entry) {
              return _buildExpandedEntryItem(entry, theme);
            }).toList(),
          ),
        ),
    ],
  );
}
```

#### 子项卡片设计

```dart
Widget _buildExpandedEntryItem(DownloadEntryInfo entry, ThemeData theme) {
  return Card(
    margin: const EdgeInsets.only(bottom: 4),
    child: InkWell(
      onTap: () {
        // 跳转到视频播放页 - 离线播放
        Get.toNamed('/video', parameters: {...}, arguments: {...});
      },
      child: Padding(
        padding: const EdgeInsets.all(8),
        child: Row(
          children: [
            // 画质标签（突出显示）
            Container(
              padding: const EdgeInsets.symmetric(horizontal: 8, vertical: 4),
              decoration: BoxDecoration(
                color: theme.colorScheme.primaryContainer,
                borderRadius: BorderRadius.circular(4),
              ),
              child: Text(
                entry.qualityPithyDescription,
                style: TextStyle(
                  fontSize: 12,
                  fontWeight: FontWeight.bold,
                  color: theme.colorScheme.onPrimaryContainer,
                ),
              ),
            ),
            const SizedBox(width: 12),
            // 视频信息
            Expanded(
              child: Column(
                crossAxisAlignment: CrossAxisAlignment.start,
                children: [
                  Text(entry.showTitle, maxLines: 1, overflow: TextOverflow.ellipsis),
                  if (entry.ownerName != null)
                    Text(entry.ownerName!, style: TextStyle(fontSize: 11, color: theme.colorScheme.outline)),
                ],
              ),
            ),
            // 播放图标
            Icon(Icons.play_circle_outline, color: theme.colorScheme.primary, size: 24),
          ],
        ),
      ),
    ),
  );
}
```

### 4. 布局系统优化

#### 从固定网格改为动态列表
```dart
// 修改前：SliverGrid（固定高度）
sliver: SliverGrid(
  gridDelegate: const SliverGridDelegateWithFixedCrossAxisCount(
    crossAxisCount: 1,
    mainAxisSpacing: 8,
    crossAxisSpacing: 8,
    mainAxisExtent: 100, // 固定高度
  ),
  // ...
),

// 修改后：SliverList（动态高度）
sliver: SliverList(
  delegate: SliverChildBuilderDelegate(
    (context, index) {
      final item = _controller.pages[index];
      if (item.entries.length == 1) {
        // 单画质：保持固定高度
        return Padding(
          padding: const EdgeInsets.only(bottom: 8),
          child: SizedBox(
            height: 100,
            child: _buildSingleEntryItem(...),
          ),
        );
      }
      // 多画质：动态高度（支持展开）
      return Padding(
        padding: const EdgeInsets.only(bottom: 8),
        child: _buildMultiEntryItem(...),
      );
    },
    childCount: _controller.pages.length,
  ),
),
```

## 使用指南

### 查看多画质视频
1. 在下载页面找到包含多个画质的视频卡片
2. 卡片右下角显示"X个画质"标识
3. 卡片右侧有展开/收起图标

### 展开画质列表
1. 点击多画质视频卡片
2. 卡片下方展开显示所有画质选项
3. 每个画质项显示：画质标签 + 视频标题 + 播放图标

### 选择画质播放
1. 在展开的列表中找到想要的画质
2. 点击对应的画质项
3. 自动跳转到视频播放页面，播放对应画质

### 收起画质列表
1. 再次点击主卡片
2. 展开的画质列表自动收起
3. 展开图标变为收起图标

## 技术要点

### 1. 状态管理
- 使用 `isExpanded` 属性记录展开状态
- 通过 `pages.refresh()` 触发UI更新
- 展开状态独立于多选状态

### 2. 布局适配
- SliverList 支持动态高度
- 单画质保持固定高度（100px）
- 多画质支持展开后的动态高度

### 3. 用户体验
- 展开/收起有清晰的视觉反馈
- 画质标签使用主题色突出显示
- 播放图标提示交互性

### 4. 兼容性
- 多选模式下禁用展开功能
- 长按菜单功能保持不变
- 单画质视频显示不受影响
