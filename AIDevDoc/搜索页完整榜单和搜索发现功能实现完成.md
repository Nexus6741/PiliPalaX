# 搜索页完整榜单和搜索发现功能实现完成

## 实现概述

参照 PiliPlus 的搜索页面设计，为项目添加了"完整榜单"入口和"搜索发现"功能，提升搜索体验。

## 功能特性

### 1. 完整榜单页面
- **入口位置**：搜索页"大家都在搜"标题旁边
- **页面特点**：
  - 渐变色顶部横幅（带火焰图标）
  - 滚动时动态透明度的 AppBar
  - 置顶热搜（红色图标标识）
  - 前三名彩色序号（金、蓝、棕）
  - 支持下拉刷新
  - 点击直接跳转搜索结果

### 2. 搜索发现功能
- **位置**：在"大家都在搜"下方
- **特点**：
  - 显示推荐搜索关键词
  - 支持显示推荐理由
  - 支持刷新获取新内容
  - 双列布局展示

### 3. UI 优化
- 热搜关键词支持显示图标
- 支持显示 LIVE 标签
- 搜索发现支持显示推荐理由
- 统一的视觉风格

## API 接口

### 1. 热搜榜单
```dart
GET /x/v2/search/trending/ranking
参数：
  - limit: 数量限制（默认30）

返回：
  - list: 热搜列表
  - top_list: 置顶热搜列表
```

### 2. 搜索发现
```dart
GET /x/v2/search/recommend
参数：
  - build: 8430300
  - mobi_app: android
  - platform: android
  - from: 2

返回：
  - list: 推荐搜索列表
```

## 数据模型

### SearchTrendingItem
```dart
class SearchTrendingItem {
  String? keyword;           // 关键词
  String? showName;          // 显示名称
  String? icon;              // 图标URL
  bool? showLiveIcon;        // 是否显示LIVE标签
  String? recommendReason;   // 推荐理由
}
```

### SearchTrendingModel
```dart
class SearchTrendingModel {
  List<SearchTrendingItem>? list;      // 热搜列表
  List<SearchTrendingItem>? topList;   // 置顶列表
}
```

### SearchRecommendModel
```dart
class SearchRecommendModel {
  List<SearchTrendingItem>? list;      // 推荐列表
}
```

## 使用说明

### 1. 访问完整榜单
1. 打开搜索页面
2. 在"大家都在搜"标题旁点击"完整榜单"按钮
3. 查看完整的热搜排行榜
4. 点击任意热搜词直接搜索

### 2. 查看搜索发现
1. 打开搜索页面
2. 向下滚动到"搜索发现"区域
3. 查看推荐的搜索关键词
4. 点击刷新按钮获取新推荐

### 3. 配置选项
```dart
// 在 storage.dart 中配置
enableSearchRcmd = 'enableSearchRcmd'  // 是否启用搜索发现
```
