## 1. 过多的 Obx 监听器 ⚠️ 高优先级

**问题**: 
- 当前有 **40+ 个 Obx** 监听器
- 每个 Obx 都是独立的监听器，会频繁触发重建
- 某些 Obx 监听的是同一个变量

**影响**:
- 内存占用增加
- Widget 重建频率过高
- 可能导致掉帧

**优化方案**:

### 方案 A: 合并相邻的 Obx
```dart
// ❌ 当前：多个独立的 Obx
Obx(() => Widget1(value: controller.value1)),
Obx(() => Widget2(value: controller.value2)),
Obx(() => Widget3(value: controller.value1)), // 重复监听

// ✅ 优化：合并为一个 Obx
Obx(() => Column(
  children: [
    Widget1(value: controller.value1),
    Widget2(value: controller.value2),
    Widget3(value: controller.value1),
  ],
))
```

### 方案 B: 使用 GetBuilder 替代不需要细粒度更新的 Obx
```dart
// ❌ 当前：使用 Obx
Obx(() => VideoIntroPanel(heroTag: heroTag))

// ✅ 优化：使用 GetBuilder（如果不需要实时更新）
GetBuilder<VideoIntroController>(
  tag: heroTag,
  builder: (controller) => VideoIntroPanel(heroTag: heroTag),
)
```

### 方案 C: 提取静态部分
```dart
// ❌ 当前：整个 Stack 都在 Obx 中
Obx(() => Stack(
  children: [
    StaticWidget1(),  // 不需要响应式
    StaticWidget2(),  // 不需要响应式
    DynamicWidget(value: controller.value),  // 需要响应式
  ],
))

// ✅ 优化：只包裹需要响应式的部分
Stack(
  children: [
    StaticWidget1(),
    StaticWidget2(),
    Obx(() => DynamicWidget(value: controller.value)),
  ],
)
```

**预期效果**: 减少 50-60% 的 Obx 数量，提升响应速度

## 2. AnimatedContainer 优化 ⚠️ 中优先级

**问题**:
- 10 个 AnimatedContainer，每次动画都重建子树
- 动画时长 350ms 可以进一步优化

**影响**:
- 动画期间的 CPU 开销
- 可能与其他动画冲突

**优化方案**:

### 方案 A: 使用 AnimatedSize 替代
```dart
// ❌ 当前：AnimatedContainer 会重建子树
AnimatedContainer(
  duration: const Duration(milliseconds: 350),
  width: isFullScreen ? fullWidth : normalWidth,
  child: ExpensiveWidget(),
)

// ✅ 优化：AnimatedSize 只动画尺寸
AnimatedSize(
  duration: const Duration(milliseconds: 250),
  child: Container(
    width: isFullScreen ? fullWidth : normalWidth,
    child: ExpensiveWidget(),
  ),
)
```

### 方案 B: 添加 clipBehavior
```dart
AnimatedContainer(
  duration: const Duration(milliseconds: 250),  // 减少到 250ms
  curve: Curves.fastOutSlowIn,
  clipBehavior: Clip.none,  // 避免裁剪开销
  child: child,
)
```

**预期效果**: 减少 20-30% 的动画开销

## 3. 简介和评论的并行初始化 ⚠️ 低优先级

**问题**:
```dart
// 当前：串行初始化
Future.delayed(400ms)  // 播放器
  .then(() => Future.delayed(50ms))  // 简介
  .then(() => Future.delayed(50ms))  // 评论
// 总计: 500ms
```

**优化方案**:
```dart
// 优化：并行初始化
Future.delayed(const Duration(milliseconds: 400), () {
  if (mounted) {
    videoSourceInit();
    setState(() {
      _playerInitFinished = true;
      _playerOpacity = 1.0;
    });
    
    // 🔥 优化：并行初始化简介和评论
    Future.wait([
      Future.delayed(const Duration(milliseconds: 50), () {
        if (mounted) {
          setState(() {
            _introInitFinished = true;
          });
        }
      }),
      Future.delayed(const Duration(milliseconds: 50), () {
        if (mounted) {
          setState(() {
            _replyInitFinished = true;
          });
        }
      }),
    ]);
  }
});
// 总计: 450ms（节省 50ms）
```

**预期效果**: 节省 50ms 初始化时间

## 4. 封面图片复用优化 ⚠️ 中优先级

**问题**:
- 每个布局模式都创建独立的封面 Widget
- VideoHero 中的封面
- 封面淡出层中的封面
- 手动播放模式的封面

**优化方案**:

### 方案 A: 提取封面为独立 Widget
```dart
class _CoverImage extends StatelessWidget {
  final String imageUrl;
  final double width;
  final double height;
  
  const _CoverImage({
    required this.imageUrl,
    required this.width,
    required this.height,
  });
  
  @override
  Widget build(BuildContext context) {
    return RepaintBoundary(
      child: NetworkImgLayer(
        key: ValueKey(imageUrl),
        src: imageUrl,
        width: width,
        height: height,
      ),
    );
  }
}
```

### 方案 B: 使用 RepaintBoundary 隔离
```dart
RepaintBoundary(
  child: VideoHero(
    tag: heroTag,
    child: _CoverImage(
      imageUrl: videoDetailController.videoItem['pic'],
      width: videoWidth,
      height: videoHeight,
    ),
  ),
)
```

**预期效果**: 减少图片解码次数，节省内存

**问题**:

**优化方案**:
- 只在必要时调用 setState
- 合并多个状态更新

## 6. 使用 const 构造函数 ⚠️ 低优先级

**问题**:
- 很多 Widget 可以使用 const 构造函数
- 减少 Widget 重建

**优化方案**:
```dart
// ❌ 当前
SizedBox(width: 10, height: 10)

// ✅ 优化
const SizedBox(width: 10, height: 10)
```
