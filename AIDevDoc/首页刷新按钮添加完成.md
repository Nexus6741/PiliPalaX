# 首页刷新按钮添加完成

## 功能概述
在首页Tab栏右侧添加了刷新按钮，支持刷新所有Tab的内容。

## 实现位置
- 文件：`lib/pages/home/view.dart`

## 实现细节

### 1. 刷新按钮位置
刷新按钮放置在Tab栏的右侧，与"直播"、"推荐"、"热门"等Tab在同一行：
- 普通TabBar样式：在TabBar右侧添加IconButton
- 渐变背景样式（CustomTabs）：在CustomTabs的ListView右侧添加IconButton

### 2. 支持的Tab类型
刷新按钮支持以下所有Tab类型的内容刷新：

1. **推荐Tab (RcmdController)**
   - 调用：`controller.onRefresh()`

2. **直播Tab (LiveController)**
   - 调用：`controller.onRefresh()`

3. **热门Tab (HotController)**
   - 调用：`controller.onRefresh()`

4. **排行Tab (RankController)**
   - 调用：`controller.onRefresh()`

5. **番剧Tab (BangumiController)**
   - 调用：`controller.queryBangumiListFeed(type: 'init')` 和 `controller.queryBangumiFollow()`
   - 注意：BangumiController没有onRefresh方法，需要单独调用这两个方法

6. **影视Tab (PgcController)**
   - 调用：`controller.onRefresh()`

### 3. 刷新逻辑
```dart
void _refreshCurrentTab() {
  int currentIndex = _homeController.initialIndex.value;
  if (currentIndex < _homeController.tabsCtrList.length) {
    var controller = _homeController.tabsCtrList[currentIndex]();

    // 根据不同的控制器类型调用对应的刷新方法
    if (controller is RcmdController) {
      controller.onRefresh();
    } else if (controller is LiveController) {
      controller.onRefresh();
    } else if (controller is HotController) {
      controller.onRefresh();
    } else if (controller is RankController) {
      controller.onRefresh();
    } else if (controller is BangumiController) {
      controller.queryBangumiListFeed(type: 'init');
      controller.queryBangumiFollow();
    } else if (controller is PgcController) {
      controller.onRefresh();
    }
  }
}
```

### 4. UI实现

#### 普通TabBar样式
```dart
Row(
  children: [
    Expanded(
      child: Align(
        alignment: Alignment.center,
        child: TabBar(...),
      ),
    ),
    // 刷新按钮
    IconButton(
      tooltip: '刷新',
      onPressed: _refreshCurrentTab,
      icon: const Icon(Icons.refresh),
    ),
    const SizedBox(width: 8),
  ],
)
```

#### 渐变背景样式（CustomTabs）
```dart
Row(
  children: [
    Expanded(
      child: ListView(...), // Tab列表
    ),
    // 刷新按钮
    IconButton(
      tooltip: '刷新',
      onPressed: widget.onRefresh,
      icon: const Icon(Icons.refresh),
    ),
    const SizedBox(width: 8),
  ],
)
```

## 测试方法
1. 打开应用首页
2. 切换到不同的Tab（推荐、直播、热门、排行、番剧、影视）
3. 点击Tab栏右侧的刷新按钮
4. 验证当前Tab的内容是否正确刷新

## 注意事项
- 刷新按钮只刷新当前激活的Tab，不会影响其他Tab
- BangumiController的刷新逻辑与其他Controller不同，需要调用两个方法
- 刷新按钮在两种Tab样式下都能正常工作
- 刷新按钮固定在右侧，不会随Tab滚动
