## 功能特性

### 1. 智能剧集识别
- 自动识别当前播放的剧集
- 如果无法识别，默认选择第一集
- 支持多集番剧

### 2. 画质选择
- 获取视频真实可用的画质列表
- 显示画质选择对话框
- 支持所有B站画质（360P - 4K）

### 3. 下载信息
番剧下载包含以下信息：
- **cid**: 剧集ID
- **bvid**: 视频ID
- **aid**: AV号
- **part**: 剧集标题（长标题）
- **title**: 番剧总标题
- **cover**: 剧集封面或番剧封面
- **duration**: 时长
- **danmakuCount**: 弹幕数量

### 4. UI布局
操作按钮顺序（共6个）：
1. 👍 点赞
2. 🪙 投币
3. ⭐ 收藏
4. 💬 评论
5. 📥 缓存（新增）
6. 🔗 分享

## 使用流程

### 用户操作
1. 打开番剧视频页面
2. 点击底部的"缓存"按钮
3. 等待获取画质信息
4. 选择想要的画质
5. 视频添加到下载队列

### 系统流程
```
点击缓存按钮
    ↓
获取当前剧集信息
    ↓
请求可用画质列表
    ↓
显示画质选择对话框
    ↓
用户选择画质
    ↓
调用 downloadService.downloadVideo()
    ↓
添加到下载队列
    ↓
显示成功提示
```

## 技术细节

### 1. 剧集数据结构
使用 `EpisodeItem` 类：
```dart
class EpisodeItem {
  int? cid;
  String? bvid;
  int? aid;
  String? longTitle;  // 剧集标题
  String? cover;      // 剧集封面
  int? duration;      // 时长
  // ...
}
```

### 2. 画质获取
```dart
final res = await VideoHttp.videoUrl(
  bvid: currentEpisode.bvid!,
  cid: currentEpisode.cid!,
);
final PlayUrlModel playUrlData = res['data'];
final List<FormatItem>? supportFormats = playUrlData.supportFormats;
```

### 3. 下载调用
```dart
downloadService.downloadVideo(
  cid: currentEpisode.cid!,
  page: 1,
  bvid: currentEpisode.bvid!,
  aid: currentEpisode.aid!,
  part: currentEpisode.longTitle,
  title: bangumiDetail.value.title ?? '',
  cover: currentEpisode.cover ?? bangumiDetail.value.cover ?? '',
  duration: currentEpisode.duration ?? 0,
  danmakuCount: bangumiDetail.value.stat?['danmaku'],
  ownerId: null,
  ownerName: null,
  videoQuality: quality,
);
```

## 与普通视频的区别

| 特性   | 普通视频                  | 番剧视频             |
| ------ | ------------------------- | -------------------- |
| 数据源 | `Part` (分P)              | `EpisodeItem` (剧集) |
| 标题   | `pagePart`                | `longTitle`          |
| UP主   | 有 `ownerId`, `ownerName` | 无（设为 null）      |
| 封面   | 视频封面                  | 剧集封面或番剧封面   |
| 页码   | 实际分P页码               | 固定为 1             |

## 注意事项

1. **剧集识别**：基于 `lastPlayCid` 识别当前剧集
2. **封面优先级**：优先使用剧集封面，其次使用番剧封面
3. **UP主信息**：番剧没有UP主，设为 null
4. **页码固定**：番剧的 page 参数固定为 1
