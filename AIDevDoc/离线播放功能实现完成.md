## 功能概述

## 实现内容

### 1. 创建视频来源类型枚举

**文件**: `lib/models/common/source_type.dart` (新建)

定义了视频来源类型：
- `online`: 在线播放
- `file`: 本地文件播放

### 2. 修改下载页面 - 添加点击播放

**文件**: `lib/pages/download/view.dart`

在已完成的下载项上添加点击事件，跳转到视频播放页面并传递离线播放参数：

```dart
onTap: () {
  if (enableMultiSelect) {
    _controller.onSelect(pageInfo);
    return;
  }
  // 跳转到视频播放页 - 离线播放
  Get.toNamed(
    '/video',
    parameters: {
      'bvid': entry.bvid,
      'cid': entry.cid.toString(),
    },
    arguments: {
      'sourceType': 'file',
      'entry': entry,
      'dirPath': entry.entryDirPath,
    },
  );
},
```

#### 修改 queryVideoUrl 方法
在方法开头添加离线播放检测：

```dart
Future queryVideoUrl() async {
  var result;

  // 检查是否是离线播放
  if (Get.arguments != null && Get.arguments['sourceType'] == 'file') {
    return await _loadOfflineVideo();
  }

  // 原有的在线播放逻辑...
}
```

#### 新增 _loadOfflineVideo 方法
实现完整的离线视频加载逻辑：

1. **读取下载信息**: 从 arguments 获取 entry 和 dirPath
2. **检查文件存在**: 验证视频目录和媒体信息文件
3. **解析媒体信息**: 读取 index.json 并根据类型解析
4. **支持两种格式**:
   - **Type1 (FLV)**: 单文件格式
   - **Type2 (DASH)**: 视频+音频分离格式
5. **构建播放数据**: 创建 VideoItem 和 AudioItem
6. **初始化播放器**: 调用 playerInit() 开始播放

## 技术实现细节

### 文件路径结构

```
应用文档目录/downloads/
├── {avid}/
│   └── c_{cid}/
│       ├── entry.json        # 下载条目信息
│       ├── danmaku.pb        # 弹幕文件
│       ├── cover.jpg         # 封面图片
│       └── {quality}/        # 画质目录 (如 "120")
│           ├── index.json    # 媒体信息
│           ├── video.flv     # FLV格式视频
│           ├── video.m4s     # DASH格式视频
│           └── audio.m4s     # DASH格式音频
```

### 媒体格式判断

通过 JSON 结构判断媒体类型：
- 包含 `segment_list` 字段 → Type1 (FLV)
- 包含 `video` 和 `audio` 字段 → Type2 (DASH)

### 播放器支持

media_kit 播放器原生支持本地文件路径：
- 直接传入文件绝对路径即可
- 支持 FLV 和 M4S 格式
- 支持音视频分离播放

## 使用流程

1. **下载视频**:
   - 打开任意视频详情页
   - 点击下载按钮
   - 选择画质
   - 等待下载完成

2. **离线播放**:
   - 进入媒体库 → 离线缓存
   - 点击已完成的下载项
   - 自动跳转到视频播放页面
   - 开始离线播放
