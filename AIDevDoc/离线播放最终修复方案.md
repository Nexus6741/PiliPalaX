# 离线播放最终修复方案

## 问题总结
反复出现 `NoSuchMethodError: Class '_Map<String, dynamic>' has no instance getter 'pic'` 错误。

## 根本原因
**混淆了 Map 和对象的访问方式**

- 正常视频跳转：传递的 `videoItem` 是一个**对象**，使用 `args.pic` 访问
- 离线播放跳转：错误地传递了 `videoItem` 作为 **Map**：`{'pic': entry.cover}`
- 代码尝试用 `args.pic` 访问 Map，导致错误

## 最终解决方案

### 核心原则
**不要传递 Map 格式的 `videoItem`，直接传递 `pic` 参数**

### 修改内容

#### 1. 下载页面 (`lib/pages/download/view.dart`)

**修改前**：
```dart
arguments: {
  'sourceType': 'file',
  'entry': entry,
  'dirPath': entry.entryDirPath,
  'heroTag': heroTag,
  'pic': entry.cover,
  'videoItem': {           // ❌ 错误：传递 Map
    'pic': entry.cover,
  },
},
```

**修改后**：
```dart
arguments: {
  'sourceType': 'file',
  'entry': entry,
  'dirPath': entry.entryDirPath,
  'heroTag': heroTag,
  'pic': entry.cover,      // ✅ 正确：直接传递 pic
  // 不传递 videoItem
},
```

#### 2. 视频控制器 (`lib/pages/video/controller.dart`)

**恢复原来的简单逻辑**，不需要处理 Map 类型的 `videoItem`：

```dart
var keys = argMap.keys.toList();
if (keys.isNotEmpty) {
  if (keys.contains('videoItem')) {
    var args = argMap['videoItem'];
    // 直接使用 args.pic，因为 args 是对象
    if (args.pic != null && args.pic != '') {
      videoItem['pic'] = args.pic;
    }
    // ...
  }
  if (keys.contains('pic')) {
    // 离线播放时，直接从 argMap 获取 pic
    if (argMap['pic'] != null && argMap['pic'] != '') {
      videoItem['pic'] = argMap['pic'];
    }
  }
}
```

#### 3. 详情控制器 (`lib/pages/video/introduction/detail/controller.dart`)

**同样恢复原来的简单逻辑**：

```dart
if (Get.arguments.containsKey('videoItem')) {
  preRender = true;
  var args = Get.arguments['videoItem'];
  // 直接使用 args.pic，因为 args 是对象
  videoItem!['pic'] = args.pic;
  // ...
}
```

## 为什么这样修复有效？

### 1. 保持一致性
- **正常视频跳转**：传递对象类型的 `videoItem`，使用 `args.pic` 访问
- **离线播放跳转**：不传递 `videoItem`，直接传递 `pic` 参数
- 两种方式互不干扰，各自独立

### 2. 参考 PiliPlus 和番剧跳转
- PiliPlus 离线播放：通过 `extraArguments` 传递参数，不传递 `videoItem`
- 番剧跳转：也是直接传递 `pic` 参数，不传递 `videoItem`

### 3. 代码路径清晰
```dart
// 离线播放路径
if (keys.contains('pic')) {
  videoItem['pic'] = argMap['pic'];  // 从 argMap 直接获取
}

// 正常视频路径
if (keys.contains('videoItem')) {
  var args = argMap['videoItem'];
  videoItem['pic'] = args.pic;       // 从 videoItem 对象获取
}
```

## 经验教训

### 1. 不要混用 Map 和对象
- 如果传递对象，就用 `.` 访问
- 如果传递 Map，就用 `[]` 访问
- **不要在同一个参数名下混用两种类型**

### 2. 参考现有实现
- 查看项目中其他类似功能的实现方式
- 参考 PiliPlus 等成熟项目的实现
- 保持代码风格和模式的一致性

### 3. 简单即是美
- 不要过度设计，添加不必要的类型检查
- 保持代码简单清晰
- 遵循"单一职责"原则
