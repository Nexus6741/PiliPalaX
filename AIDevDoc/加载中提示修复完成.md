# 加载中提示修复完成

## 问题描述
打开视频进行缓冲时，"加载中..."提示和 logo 只出现一会儿就消失了，还没加载完毕就看不到了。

## 问题原因
"加载中"提示在播放器内部（`plPlayer`），但是有一个封面淡出动画层覆盖在播放器上面。

**原来的层级结构**:
```
Stack [
  VideoHero (封面)
  plPlayer (播放器，内部有"加载中"提示)
  AnimatedOpacity (封面淡出层) ← 这一层遮挡了"加载中"提示
]
```

当视频还在加载时：
- 封面淡出层的 opacity = 1.0（完全显示）
- 播放器内部的"加载中"提示被封面遮挡
- 用户看不到加载进度

## 解决方案
将"加载中"提示移到封面淡出层内部，显示在封面图片之上。

**修复后的层级结构**:
```
Stack [
  VideoHero (封面)
  plPlayer (播放器)
  AnimatedOpacity (封面淡出层) [
    Stack [
      NetworkImgLayer (封面图片)
      "加载中"提示 ← 现在显示在封面之上
    ]
  ]
]
```

## 修改内容

### 文件: `lib/pages/video/view.dart`

在所有自动播放模式的封面淡出动画中，将封面图片和"加载中"提示组合在一个 Stack 中：

```dart
// 🔥 优化：自动播放模式下的封面淡出动画
if (videoDetailController.autoPlay.value && _playerOpacity > 0)
  Obx(
    () => Positioned.fill(
      child: IgnorePointer(
        ignoring: plPlayerController?.isVideoLoaded.value ?? false,
        child: AnimatedOpacity(
          opacity: (plPlayerController?.isVideoLoaded.value ?? false)
              ? 0.0
              : 1.0,
          duration: const Duration(milliseconds: 300),
          curve: Curves.easeOut,
          child: Stack(
            children: [
              // 封面图片
              NetworkImgLayer(
                key: ValueKey(videoDetailController.videoItem['pic']),
                src: videoDetailController.videoItem['pic'],
                width: videoWidth,
                height: videoHeight,
              ),
              // 🔥 修复：加载中提示显示在封面之上
              if (plPlayerController == null ||
                  plPlayerController!.videoController == null ||
                  !(plPlayerController!.isVideoLoaded.value))
                Center(
                  child: Container(
                    padding: const EdgeInsets.all(30),
                    decoration: const BoxDecoration(
                      shape: BoxShape.circle,
                      gradient: RadialGradient(
                        colors: [Colors.black26, Colors.transparent],
                      ),
                    ),
                    child: Column(
                      mainAxisSize: MainAxisSize.min,
                      children: [
                        Image.asset(
                          'assets/images/loading.gif',
                          height: 25,
                          semanticLabel: "加载中",
                        ),
                        const Text(
                          '加载中...',
                          style: TextStyle(
                              color: Colors.white, fontSize: 12),
                          semanticsLabel: '',
                        ),
                      ],
                    ),
                  ),
                ),
            ],
          ),
        ),
      ),
    ),
  ),
```

## 修改位置
共修改了 4 处相同的封面淡出动画逻辑：
1. 横屏模式 - 标准布局
2. 竖屏模式 - 垂直扩展布局
3. 横屏模式 - 侧边栏布局
4. 其他布局模式

## 效果
- ✅ "加载中"提示始终可见，直到视频加载完成
- ✅ 提示显示在封面图片之上，不会被遮挡
- ✅ 当 `isVideoLoaded.value == true` 时，封面和提示一起淡出
- ✅ 用户体验更好，知道视频正在加载
