# 用户空间图文跳转修复完成

## 实现时间
2025-12-22

## 问题描述
用户空间图文Tab中的图文卡片点击后报错：
```
LateInitializationError: Field '_dynamicDetailController@364189647' has not been initialized.
```

## 问题原因
1. 图文卡片直接使用 `Get.toNamed('/dynamicDetail', parameters: {'id': item.opusId!})` 跳转
2. 动态详情页需要完整的 `item` 对象和 `floor` 参数，而不是简单的 `id` 参数
3. 动态详情页的初始化逻辑依赖于 `Get.arguments` 中的 `item` 和 `floor` 数据

## 解决方案
参考 PiliPlus 的实现，修改图文卡片的跳转逻辑：

1. **先调用 API 获取完整数据**
   - 使用 `DynamicsHttp.dynamicDetail(id: item.opusId!)` 获取完整的动态数据

2. **根据评论类型决定跳转目标**
   - 如果 `commentType == 12`（图文类型），跳转到 HTML 渲染页面 `/htmlRender`
   - 否则跳转到动态详情页 `/dynamicDetail`，并传递完整的 `item` 数据

3. **添加加载提示**
   - 显示加载提示，提升用户体验
   - 处理错误情况，显示错误提示

## 实现细节

### 修改文件
**文件**: `lib/pages/member_opus/widgets/space_opus_card.dart`

### 关键代码
```dart
Future<void> _onTap(BuildContext context) async {
  if (item.opusId == null) return;

  // 显示加载提示
  SmartDialog.showLoading(msg: '加载中...');

  try {
    // 先调用 API 获取完整的动态数据
    var res = await DynamicsHttp.dynamicDetail(id: item.opusId!);

    SmartDialog.dismiss();

    if (res['status']) {
      final data = res['data'];
      // 获取评论类型
      final commentType = data.basic?['comment_type'] ?? 11;

      if (commentType == 12) {
        // 图文类型，跳转到 HTML 渲染页面
        Get.toNamed('/htmlRender', parameters: {
          'url': 'www.bilibili.com/opus/${item.opusId}',
          'title': '',
          'id': item.opusId!,
          'dynamicType': 'opus',
        });
      } else {
        // 其他类型，跳转到动态详情页
        Get.toNamed('/dynamicDetail', arguments: {
          'item': data,
          'floor': 1,
        });
      }
    } else {
      SmartDialog.showToast(res['msg'] ?? '加载失败');
    }
  } catch (e) {
    SmartDialog.dismiss();
    SmartDialog.showToast('加载失败: $e');
  }
}
```
