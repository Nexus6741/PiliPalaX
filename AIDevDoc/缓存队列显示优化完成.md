# 缓存队列显示优化完成

## 问题描述
用户反馈缓存视频时存在以下问题：
1. 缓存队列只显示一个视频，其他排队的视频看不到
2. 没有取消缓存的按钮
3. 缓存进度不会实时更新，一直显示等待中

## 解决方案

### 1. 显示完整缓存队列
- **修改前**: 只显示队列中的第一个视频
- **修改后**: 显示所有等待队列中的视频，每个视频都有独立的卡片

### 2. 添加队列管理功能
- **队列序号**: 每个视频显示在队列中的位置（1、2、3...）
- **当前下载标识**: 正在下载的视频用下载图标标识
- **清空队列**: 当队列中有多个视频时，显示"清空队列"按钮
- **取消单个缓存**: 每个等待中的视频都有取消按钮

### 3. 优化进度显示
- **实时进度**: 正在下载的视频显示实时进度条和百分比
- **文件大小**: 显示已下载/总大小信息
- **状态提示**: 清晰显示每个视频的状态（等待中、正在下载等）

## 主要修改文件

### lib/pages/download/view.dart
1. **队列显示逻辑**:
   ```dart

   final entry = _downloadService.waitDownloadQueue.firstWhereOrNull(...) ?? 
                 _downloadService.waitDownloadQueue.firstOrNull;
   
   // 修改后：显示所有队列视频
   SliverList(
     delegate: SliverChildBuilderDelegate(
       (context, index) {
         final entry = _downloadService.waitDownloadQueue[index];
         final isCurrentDownloading = entry.cid == _downloadService.curCid;
         return _buildDownloadingItem(entry, theme, isCurrentDownloading, index);
       },
       childCount: _downloadService.waitDownloadQueue.length,
     ),
   )
   ```
