```dart
Future<void> _querySponsorBlockSegments() async {
  try {
    print('🔍 [_querySponsorBlockSegments] 开始请求 API');
    print('🔍 bvid: $bvid, cid: ${cid.value}');
    
    final result = await SponsorBlock.getSkipSegments(
      bvid: bvid,
      cid: cid.value,
    );

    print('🔍 API 返回结果类型: ${result.runtimeType}');
    
    if (result is Success<List<SegmentItemModel>>) {
      print('✅ 成功获取片段，数量: ${result.response.length}');
      for (var item in result.response) {
        print('  - ${item.category}: ${item.segment[0]}ms - ${item.segment[1]}ms');
      }
      await _handleSegmentData(result.response, isPgc: false);
    } else if (result is Error) {
      print('❌ API 返回错误: ${result.errMsg}');
    }
  } catch (e) {
    print('❌ 查询 SponsorBlock 失败: $e');
  }
}
```

## 日志说明

### 日志图标含义
- 🔍 **调试信息**：一般性调试输出
- ✅ **成功**：操作成功完成
- ⚠️ **警告**：非致命性问题
- ❌ **错误**：操作失败

### 日志级别
所有日志使用 `print()` 输出到控制台，便于用户查看。

### 日志内容
- **初始化信息**：视频类型、参数等
- **条件检查**：enableBlock、autoplay 状态
- **API 请求**：请求参数、返回结果
- **数据处理**：片段数量、类型、时间
- **UI 状态**：按钮显示条件

## 使用方法

### 1. 启用功能
```
设置 → 其他 → 空降助手 → 启用 SponsorBlock
```

### 2. 播放视频
选择一个视频播放，查看控制台输出。

### 3. 分析日志
根据日志输出判断问题：

#### 正常情况
```
🔍 VideoDetailController.onInit() - 开始初始化
🔍 [playerInit] 检查是否查询 SponsorBlock
🔍 enableBlock: true, autoplay: true
✅ 开始查询 SponsorBlock
🔍 [querySponsorBlock] 开始查询
✅ 成功获取片段，数量: 3
🔍 查询完成，segmentList.length: 3
```

#### 功能未启用
```
🔍 enableBlock: false, autoplay: true
⚠️ 不满足查询条件，跳过
```
**解决**：进入设置启用功能

#### 视频无数据
```
❌ API 返回错误: 404
```
**解决**：换一个视频测试

#### 片段被过滤
```
✅ 成功获取片段，数量: 3
🔍 查询完成，segmentList.length: 0
```
**解决**：检查跳过方式设置
