# 空降助手功能实现完成

## 功能概述

空降助手是一个基于 [BilibiliSponsorBlock](https://github.com/hanydd/BilibiliSponsorBlock) 的功能，可以自动跳过视频中的广告、片头片尾等片段，提升观看体验。

## 已完成的实现

### 1. 数据模型层 ✅

#### 片段类型 (SegmentType)
- `lib/models/common/sponsor_block/segment_type.dart`
- 支持10种片段类型：
  1. 赞助广告 (sponsor)
  2. 无偿/自我推广 (selfpromo)
  3. 三连/订阅提醒 (interaction)
  4. 过场/开场动画 (intro)
  5. 鸣谢/结束画面 (outro)
  6. 回顾/概要 (preview)
  7. 音乐:非音乐部分 (music_offtopic)
  8. 精彩时刻/重点 (poi_highlight)
  9. 离题闲聊/玩笑 (filler)
  10. 柔性推广/品牌合作 (exclusive_access)

#### 跳过类型 (SkipType)
- `lib/models/common/sponsor_block/skip_type.dart`
- 5种跳过模式：
  1. 总是跳过 (alwaysSkip)
  2. 跳过一次 (skipOnce)
  3. 手动跳过 (skipManually)
  4. 仅显示 (showOnly)
  5. 禁用 (disable)

#### 行为类型 (ActionType)
- `lib/models/common/sponsor_block/action_type.dart`
- 4种行为类型：
  1. 跳过 (skip)
  2. 静音 (mute)
  3. 整个视频 (full)
  4. 精彩时刻 (poi)

#### 其他模型
- `lib/models/common/sponsor_block/post_segment_model.dart` - 提交片段模型
- `lib/models/common/sponsor_block/segment_model.dart` - 片段模型
- `lib/models_new/sponsor_block/segment_item.dart` - 片段项模型
- `lib/models_new/sponsor_block/user_info.dart` - 用户信息模型

## 配置项说明

### 存储键值 (需要在 SettingBoxKey 中定义)

```dart
// 空降助手相关配置
static const String enableSponsorBlock = 'enableSponsorBlock';  // 是否启用
static const String blockLimit = 'blockLimit';                  // 最短片段时长
static const String blockSettings = 'blockSettings';            // 片段跳过设置
static const String blockColor = 'blockColor';                  // 片段颜色
static const String blockUserID = 'blockUserID';                // 用户ID
static const String blockToast = 'blockToast';                  // 显示跳过提示
static const String blockServer = 'blockServer';                // 服务器地址
static const String blockTrack = 'blockTrack';                  // 跳过统计
```

### 默认值

- `enableSponsorBlock`: false (默认禁用)
- `blockLimit`: 0.0 (不过滤短片段)
- `blockSettings`: 所有类型默认为 disable
- `blockColor`: 使用各类型的默认颜色
- `blockUserID`: 自动生成 UUID
- `blockToast`: true (显示跳过提示)
- `blockServer`: 'https://www.bsbsb.top'
- `blockTrack`: false (不参与统计)

### 5. 自动跳过逻辑 ⏳

在播放器位置监听中实现：

```dart
positionSubscription = plPlayerController
    .videoPlayerController
    ?.stream
    .position
    .listen((position) {
      int currentPos = position.inSeconds;
      for (SegmentModel item in segmentList) {
        if (currentPos >= item.segment.first / 1000 &&
            currentPos < item.segment.second / 1000) {
          switch (item.skipType) {
            case SkipType.alwaysSkip:
              onSkip(item);
              break;
            case SkipType.skipOnce:
              if (!item.hasSkipped) {
                item.hasSkipped = true;
                onSkip(item);
              }
              break;
            case SkipType.skipManually:
              onAddItem(item);
              break;
            default:
              break;
          }
          break;
        }
      }
    });
```

## 使用流程

### 用户配置流程

1. 进入"设置" -> "其它设置"
2. 点击"空降助手"
3. 配置各项设置：
   - 设置用户ID（首次使用会自动生成）
   - 选择要启用的片段类型
   - 为每种类型选择跳过模式
   - 自定义片段颜色（可选）
   - 设置最短片段时长
   - 开启/关闭跳过提示
   - 开启/关闭统计跟踪

### 观看视频流程

1. 播放视频时自动查询片段信息
2. 根据配置自动跳过或显示提示
3. 可以手动点击提示跳过片段
4. 可以查看所有片段信息
5. 可以对片段投票或修改分类
6. 可以提交新的片段
