# 动态话题标签测试指南

## 测试目标

验证动态卡片中话题标签的识别、显示和跳转功能是否正常工作。

## 测试环境

- 确保已编译最新代码
- 确保已登录账号（部分功能需要登录）
- 确保网络连接正常

## 测试步骤

### 1. 查看动态列表

**操作**：
1. 打开应用
2. 进入"动态"页面
3. 查看动态列表

**预期结果**：
- 带话题的动态卡片顶部显示话题标签
- 话题标签前有小电视图标（🔖）
- 话题名称使用主题色显示
- 图标和文本垂直居中对齐

### 2. 测试顶部话题标签

**操作**：
1. 找到一个带话题的动态
2. 点击动态顶部的话题标签

**预期结果**：
- 跳转到话题页面
- 话题页面显示正确的话题名称
- 话题页面显示话题详情和动态列表

### 3. 测试内容中的话题标签

#### 3.1 真正的话题（有话题 ID）
**操作**：
1. 找到一个内容中包含真正话题标签的动态
2. 确认话题标签显示为：🔖 话题名称（无 `#`）
3. 点击话题标签

**预期结果**：
- 显示小电视图标
- 话题名称不包含 `#`
- 跳转到话题页面
- 话题页面显示正确的内容

#### 3.2 普通标签（无话题 ID）
**操作**：
1. 找到一个内容中包含普通标签的动态
2. 确认标签显示为：#标签名#（保持原样）
3. 点击标签

**预期结果**：
- 不显示小电视图标
- 标签保持 `#` 符号
- 跳转到搜索页面
- 搜索关键词为标签名称

### 4. 测试话题页面功能

**操作**：
1. 从动态跳转到话题页面
2. 查看话题详情
3. 滚动查看动态列表
4. 尝试点赞、收藏话题
5. 点击"参与话题"按钮

**预期结果**：
- 话题详情正确显示
- 动态列表正确加载
- 点赞、收藏功能正常
- 参与话题功能正常

### 5. 测试不同类型的动态

**测试场景**：
- 纯文本动态
- 带图片的动态
- 带视频的动态
- 转发的动态
- 专栏动态

**预期结果**：
- 所有类型的动态都能正确显示话题标签
- 话题标签的样式和功能一致

### 6. 测试边界情况

#### 6.1 长话题名称
**操作**：找到一个话题名称很长的动态

**预期结果**：
- 话题名称不会溢出
- 布局保持正常

#### 6.2 特殊字符
**操作**：找到一个话题名称包含特殊字符的动态

**预期结果**：
- 特殊字符正确显示
- 点击跳转正常

#### 6.3 真正的话题 vs 普通标签
**操作**：
1. 找到包含真正话题的动态（有话题 ID）
2. 找到包含普通标签的动态（无话题 ID）
3. 对比显示效果

**预期结果**：
- 真正的话题：显示小电视图标 + 话题名称（无 `#`）
- 普通标签：显示 `#标签名#`（保持原样）
- 点击行为不同（话题页 vs 搜索页）

### 7. 测试不同主题

**操作**：

3. 切换到深色主题

**预期结果**：
- 两种主题下图标和文本颜色都正确
- 颜色与主题色一致
- 可读性良好

### 8. 测试不同屏幕尺寸

**操作**：
1. 在手机上测试
2. 在平板上测试（如果可用）
3. 旋转屏幕测试横屏模式

**预期结果**：
- 所有屏幕尺寸下布局正常
- 图标大小适中
- 文本可读

## 常见问题排查

### 问题 1：小电视图标不显示

**可能原因**：
- 图标字体文件未正确加载
- 图标码点错误

**排查步骤**：
1. 检查 `assets/fonts/custom_icon.ttf` 是否存在
2. 检查 `pubspec.yaml` 中是否正确配置字体
3. 重新编译应用

### 问题 2：点击话题标签无反应

**可能原因**：
- 路由配置错误
- 参数传递错误

**排查步骤**：
1. 检查 `lib/router/app_pages.dart` 中是否有 `/dynamicsTopic` 路由
2. 检查话题 ID 和名称是否正确传递
3. 查看控制台日志

### 问题 3：话题页面显示错误

**可能原因**：
- 话题 ID 无效
- 网络请求失败

**排查步骤**：
1. 检查传递的话题 ID 是否正确
2. 检查网络连接
3. 查看 API 请求日志

### 问题 4：图标和文本不对齐

**可能原因**：
- 对齐方式设置错误
- 图标大小不合适

**排查步骤**：
1. 检查 `PlaceholderAlignment.middle` 设置
2. 调整图标大小
3. 调整 padding
