# 批量下载选集功能实现完成

## 功能描述
为选集视频和番剧添加批量下载功能，用户可以在下载时选择多集进行批量下载，而不是一集一集地下载。

## 实现方案

### 1. 创建批量下载面板组件
**文件**: `lib/pages/video/widgets/batch_download_panel.dart`

#### 主要功能
- 显示所有可下载的选集列表
- 支持单选/全选选集
- 统一选择画质（所有选中的集使用相同画质）
- 显示已选择的集数
- 批量添加到下载队列

#### UI结构
```
┌─────────────────────────────────┐
│ 批量下载                         │
│ 视频标题                         │
├─────────────────────────────────┤
│ 选择画质                         │
│ [1080P] [720P] [480P] [360P]    │
├─────────────────────────────────┤
│ ☑ 全选 (共 12 集)    已选 5 集   │
├─────────────────────────────────┤
│ ☑ [1] 第1集 - 标题               │
│ ☐ [2] 第2集 - 标题               │
│ ☑ [3] 第3集 - 标题               │
│ ...                             │
├─────────────────────────────────┤
│ [取消]  [开始下载 (5)]           │
└─────────────────────────────────┘
```

#### 核心类

**BatchDownloadPanel**
- 批量下载面板的主组件
- 管理选集选择状态
- 管理画质选择
- 执行批量下载

**BatchDownloadItem**
- 表示一个可下载的选集项
- 包含视频信息（cid, bvid, aid等）
- 包含番剧特有信息（episodeId, longTitle等）
- 提供 `download()` 方法执行下载

### 2. 修改番剧下载逻辑
**文件**: `lib/pages/video/introduction/bangumi/controller.dart`

#### 修改内容
1. 修改 `actionDownloadVideo()` 方法
   - 检测是否有多集
   - 如果有多集，显示选择对话框（下载当前集 / 批量下载）
   - 如果只有一集，直接显示画质选择

2. 添加 `_showQualityDialog()` 方法
   - 从原来的 `actionDownloadVideo()` 中提取
   - 显示画质选择对话框
   - 下载单集

3. 添加 `_showBatchDownloadPanel()` 方法
   - 构建 `BatchDownloadItem` 列表
   - 显示批量下载面板

#### 下载选项对话框
```dart
AlertDialog(
  title: const Text('下载选项'),
  content: Column(
    children: [
      ListTile(
        leading: Icon(Icons.download),
        title: Text('下载当前集'),
        subtitle: Text('第1集 - 标题'),
        onTap: () => _showQualityDialog(...),
      ),
      ListTile(
        leading: Icon(Icons.download_for_offline),
        title: Text('批量下载'),

    ],
  ),
)
```

### 3. 修改普通视频下载逻辑
**文件**: `lib/pages/video/introduction/detail/controller.dart`

#### 修改内容
与番剧类似，添加批量下载支持：
1. 修改 `actionDownloadVideo()` 方法
2. 添加 `_showQualityDialog()` 方法
3. 添加 `_showBatchDownloadPanel()` 方法

#### 区别
- 普通视频使用 `pages` 列表（分P）
- 番剧使用 `episodes` 列表（剧集）
- 普通视频不需要 `seasonId` 和 `epInfo`

## 使用流程

### 番剧批量下载
1. 用户在番剧播放页点击"缓存"按钮
2. 如果有多集，显示下载选项对话框
3. 用户选择"批量下载"
4. 显示批量下载面板
5. 用户选择画质（必选）
6. 用户勾选要下载的集（可全选）
7. 点击"开始下载"
8. 所有选中的集按顺序添加到下载队列

### 普通视频批量下载
1. 用户在视频播放页点击"缓存"按钮
2. 如果有多个分P，显示下载选项对话框
3. 用户选择"批量下载"
4. 显示批量下载面板
5. 用户选择画质（必选）
6. 用户勾选要下载的分P（可全选）
7. 点击"开始下载"
8. 所有选中的分P按顺序添加到下载队列

## 技术细节

### 画质选择
- 使用 `ChoiceChip` 组件显示可选画质
- 所有选中的集使用相同画质
- 必须先选择画质才能开始下载

### 选集选择
- 使用 `CheckboxListTile` 显示每一集
- 支持单独勾选/取消勾选
- 支持全选/取消全选
- 实时显示已选择的集数

### 批量下载执行
```dart
for (var episode in selectedEpisodes) {
  await episode.download(
    downloadService,
    selectedQuality,
    videoTitle,
    videoCover,
    ownerId,
    ownerName,
    seasonId,
    seasonType,
  );
}
```

### 番剧特殊处理
- 构建 `EpInfo` 对象
- 传递 `seasonId`
- 传递 `seasonType`
- 使用 `episodeId` 作为排序键

### 普通视频特殊处理
- 使用 `Part` 信息
- 传递 `ownerId` 和 `ownerName`
- 使用 `page` 作为排序键

## 用户体验优化

### 默认状态
- 默认不选中任何集（避免误操作）
- 必须先选择画质（避免忘记选择）

### 视觉反馈
- 已选择的集数实时显示
- 全选状态自动更新
- 下载按钮显示选中数量

### 操作便捷性
- 支持点击整行勾选
- 全选按钮在顶部
- 取消和确认按钮在底部

### 错误提示
- 未选择画质时提示
- 未选择任何集时提示
- 下载完成后显示添加数量

## 测试场景

### 番剧批量下载
1. 打开一个多集番剧
2. 点击缓存按钮
3. 选择"批量下载"
4. 选择画质（如1080P）
5. 勾选多集（如第1、3、5集）
6. 点击"开始下载"
7. 检查下载队列是否正确添加了3集

### 普通视频批量下载
1. 打开一个多分P视频
2. 点击缓存按钮
3. 选择"批量下载"
4. 选择画质（如720P）
5. 点击"全选"
6. 点击"开始下载"
7. 检查下载队列是否正确添加了所有分P

### 单集/单P视频
1. 打开一个单集番剧或单P视频
2. 点击缓存按钮
3. 应该直接显示画质选择对话框
4. 不显示批量下载选项
