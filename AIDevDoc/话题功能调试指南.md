# 话题功能调试指南

## 问题：-111 错误（CSRF 验证失败）

### 根本原因

根据 PiliPlus 的实现，发现了以下关键点：

1. **API 端点**：应该使用相对路径，让 Dio 自动使用 baseUrl (api.bilibili.com)
2. **up_mid 参数**：应该使用当前登录用户的 mid，而不是话题创建者的 uid
3. **Content-Type**：PiliPlus 使用 `Headers.formUrlEncodedContentType`

### 修复内容

#### 1. API 端点 (`lib/http/api.dart`)

**修改前**：
```dart
static const String addFavTopic = '${HttpString.appBaseUrl}/x/topic/fav/sub/add';
static const String delFavTopic = '${HttpString.appBaseUrl}/x/topic/fav/sub/cancel';
static const String likeTopic = '${HttpString.appBaseUrl}/x/topic/like';
```

**修改后**：
```dart
static const String addFavTopic = '/x/topic/fav/sub/add';
static const String delFavTopic = '/x/topic/fav/sub/cancel';
static const String likeTopic = '/x/topic/like';
```

**原因**：使用相对路径，让 Dio 自动使用 baseUrl (https://api.bilibili.com)，这样 CSRF token 才能正确验证。

#### 2. 点赞方法 (`lib/http/user.dart`)

**修改前**：
```dart
static Future<dynamic> likeTopic(String topicId, bool isLike, int upMid) async {
  // ...
  'up_mid': upMid,  // 使用话题创建者的 uid
  // ...
}
```

**修改后**：
```dart
static Future<dynamic> likeTopic(String topicId, bool isLike) async {
  try {
    // 获取当前登录用户的 mid
    var userInfo = GStorage.userInfo.get('userInfoCache');
    int upMid = userInfo != null ? userInfo.mid : 0;
    
    var res = await Request().post(
      Api.likeTopic,
      data: {
        'csrf': await Request.getCsrf(),
        'action': isLike ? 'cancel_like' : 'like',
        'up_mid': upMid,  // 使用当前登录用户的 mid
        'topic_id': topicId,
        'business': 'topic',
      },
    );
    // ...
  }
}
```

**原因**：根据 PiliPlus 的实现，`up_mid` 应该是当前登录用户的 mid，而不是话题创建者的 uid。

#### 3. Controller 调用 (`lib/pages/dynamics_topic/controller.dart`)

**修改前**：
```dart
int upMid = topDetails.value?.topicCreator?.uid ?? 0;
var res = await UserHttp.likeTopic(topicId, currentIsLike, upMid);
```

**修改后**：
```dart
var res = await UserHttp.likeTopic(topicId, currentIsLike);
```

**原因**：不再需要传递 upMid 参数，方法内部会自动获取。

#### 4. 添加导入 (`lib/http/user.dart`)

```dart
import '../utils/storage.dart';
```

**原因**：需要使用 GStorage 获取用户信息。

### PiliPlus 参考实现

```dart
// PiliPlus/lib/http/fav.dart
static Future likeTopic(topicId, bool isLike) async {
  var res = await Request().post(
    Api.likeTopic,
    data: {
      'action': isLike ? 'cancel_like' : 'like',
      'up_mid': Accounts.main.mid,  // 当前登录用户的 mid
      'topic_id': topicId,
      'csrf': Accounts.main.csrf,
      'business': 'topic',
    },
    options: Options(contentType: Headers.formUrlEncodedContentType),
  );
  // ...
}
```

### 关键发现

1. **CSRF Token 域名**：
   - `getCsrf()` 从 `api.bilibili.com` 获取 cookie
   - 如果 API 使用 `app.bilibili.com`，CSRF token 会验证失败
   - 解决方案：使用相对路径，让 Dio 使用 baseUrl (api.bilibili.com)

2. **up_mid 参数**：
   - 不是话题创建者的 uid
   - 是当前登录用户的 mid
   - 用于标识是谁在点赞

3. **API 基础 URL**：
   - PiliPlus 使用 `HttpString.apiBaseUrl` (api.bilibili.com)
   - 不使用 `HttpString.appBaseUrl` (app.bilibili.com)

### 预期结果

- ✅ 点赞/取消点赞成功
- ✅ 收藏/取消收藏成功
- ✅ 点赞数和收藏数正确更新
- ✅ 按钮状态正确切换
- ✅ 不再出现 -111 错误

### 如果仍然失败

检查以下内容：

1. **登录状态**：确保已登录
2. **CSRF Token**：检查 cookie 中是否有 `bili_jct`
3. **网络请求**：使用抓包工具查看实际请求
4. **API 响应**：查看返回的错误信息
