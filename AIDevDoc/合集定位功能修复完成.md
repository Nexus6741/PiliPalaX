# 合集定位功能修复完成

## 问题描述
播放视频时，如果该视频属于合集：
- ✅ 没有子合集时：点击定位按钮可以正确定位到当前播放的集数
- ❌ 有子合集时：点击定位按钮失效，无法定位

## 问题原因
在 `lib/common/widgets/list_sheet.dart` 中：

1. **有子合集时**，`_buildTabBarView` 方法为每个 section 创建了独立的 `ItemScrollController`，但这些 controller 是局部变量
2. **定位方法** `_locateCurrentPlaying` 使用的是类成员变量 `itemScrollController`
3. **控制器不匹配**：定位方法试图控制一个不存在的 controller，而实际的列表使用的是各自独立的 controller

```dart
// 问题代码：每次都创建新的局部变量
Widget _buildTabBarView(ThemeData theme) {
  return TabBarView(
    children: allSections!.map((section) {
      final scrollController = ItemScrollController(); // ❌ 局部变量
      // ...
    }).toList(),
  );
}

// 定位方法无法访问到正确的 controller
void _locateCurrentPlaying() {
  itemScrollController.scrollTo(...); // ❌ 使用的是类成员变量
}
```

## 修复方案

### 1. 添加 Map 保存每个 section 的 controller
```dart
class _ListSheetContentState extends State<ListSheetContent> {
  // 为每个section保存独立的scrollController
  Map<int, ItemScrollController> sectionScrollControllers = {};
  // ...
}
```

### 2. 在构建 TabBarView 时使用持久化的 controller
```dart
Widget _buildTabBarView(ThemeData theme) {
  return TabBarView(
    controller: _tabController,
    children: allSections!.map((section) {
      final sectionIndex = allSections!.indexOf(section);
      
      // ✅ 从 map 中获取或创建 controller
      if (!sectionScrollControllers.containsKey(sectionIndex)) {
        sectionScrollControllers[sectionIndex] = ItemScrollController();
      }
      final scrollController = sectionScrollControllers[sectionIndex]!;
      // ...
    }).toList(),
  );
}
```

### 3. 修复定位方法使用正确的 controller
```dart
void _locateCurrentPlaying() {
  if (allSections != null) {
    for (int i = 0; i < allSections!.length; i++) {
      final section = allSections![i];
      final index = section.episodes!.indexWhere(...);
      if (index != -1) {
        // 切换到对应的 Tab
        if (i != currentSectionIndex) {
          _tabController?.animateTo(i);
          setState(() {
            currentSectionIndex = i;
            displayEpisodes = allSections![i].episodes!;
            currentIndex = index;
          });
        }
        
        // ✅ 使用对应 section 的 controller
        WidgetsBinding.instance.addPostFrameCallback((_) {
          final controller = sectionScrollControllers[i];
          if (controller != null && controller.isAttached) {
            controller.scrollTo(
              index: index,
              duration: const Duration(milliseconds: 300),
              curve: Curves.easeInOut,
            );
          }
        });
        SmartDialog.showToast('已定位到当前播放');
        return;
      }
    }
  }
}
```

## 修复效果
- ✅ 无子合集时：定位功能正常工作
- ✅ 有子合集时：定位功能正常工作，会自动切换到对应的 Tab 并滚动到正确位置
- ✅ 跨 section 定位：可以从一个子合集定位到另一个子合集中的视频
