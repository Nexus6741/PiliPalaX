# 暂停禁用防休眠功能修复完成

## 问题描述
用户点击暂停按钮时，虽然视频暂停了，但防休眠功能没有被禁用，导致屏幕不会自动息屏。

## 根本原因
- `play()` 和 `pause()` 方法中已经添加了防休眠控制代码
- 但是点击暂停按钮时，`pause()` 方法并没有被直接调用
- 播放器使用的是 `videoPlayerController.stream.playing` 事件流来监听播放状态变化

## 解决方案
在 `videoPlayerController.stream.playing.listen()` 监听器中添加防休眠控制逻辑：

### 修改位置
`lib/plugin/pl_player/controller.dart` - 第 866 行左右的播放状态监听器

### 修改内容
```dart
videoPlayerController!.stream.playing.listen((event) {
  if (event) {
    playerStatus.status.value = PlayerStatus.playing;
    if (!isBuffering.value) {
      isVideoLoaded.value = true;
    }
    // 播放时启用防休眠
    print('🟢 播放状态监听器：视频开始播放，启用防休眠');
    WakelockManager.instance.enable();
  } else {
    playerStatus.status.value = PlayerStatus.paused;
    // 暂停时禁用防休眠
    print('🔴 播放状态监听器：视频已暂停，禁用防休眠');
    WakelockManager.instance.disable();
  }
  // ... 其他代码
}),
```

## 技术细节

### 为什么在监听器中添加而不是在 pause() 方法中？
- 播放器的播放/暂停状态变化是通过事件流 `stream.playing` 通知的
- UI 控件（暂停按钮）直接调用底层播放器的暂停方法，不一定经过 `pause()` 方法
- 监听器能捕获所有播放状态变化，包括：
  - 用户点击暂停按钮
  - 播放完成自动暂停
  - 其他组件触发的暂停
  - 系统中断（来电等）

### 双重保护机制
现在有两层防休眠控制：
1. **播放状态监听器**（主要）- 捕获所有播放状态变化
2. **play()/pause() 方法**（备用）- 直接调用这些方法时也会控制防休眠

这样确保无论通过什么方式改变播放状态，防休眠功能都能正确响应。
