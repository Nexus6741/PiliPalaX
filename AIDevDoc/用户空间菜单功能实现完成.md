## 技术要点

### 1. 通用日志表格设计
- 使用抽象基类 `LogController<R, T>`
- 子类只需实现：
  - `title`：页面标题
  - `header`：表头数据
  - `getFlexAndText()`：列宽和文本提取
  - `customGetData()`：API 调用
  - `getDataList()`：数据解析
- 一个视图组件支持多种日志类型

### 2. 空间设置的反向逻辑
- 某些设置项使用反向逻辑（`isReverse: true`）
- 例如："公开我的关注列表"
  - API 字段：`disable_following`
  - 值为 0 表示公开（开关打开）
  - 值为 1 表示不公开（开关关闭）
- 通过 `boolVal` getter 自动处理转换

### 3. 空间设置的自动保存
- 使用 `hasMod` 标志跟踪是否有修改
- 在 `onClose()` 生命周期中自动保存
- 避免用户忘记保存设置

### 4. 状态管理
- 所有页面使用统一的 `LoadingState`
- 支持 loading、success、error 三种状态
- 统一的错误处理和重试机制
