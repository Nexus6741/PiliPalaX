# 追番时间表功能实现完成

## 功能概述
参考 PiliPlus 项目，为番剧 Tab 页面添加了追番时间表功能，完全按照 PiliPlus 的功能细节和 UI 布局实现。

## 实现内容

### 1. 数据模型 (lib/models/bangumi/timeline.dart)
创建了追番时间表的数据模型：
- `TimelineModel`: 时间表主模型
  - date: 日期字符串
  - dateTs: 时间戳
  - dayOfWeek: 星期几 (1-7)
  - episodes: 当天更新的番剧列表
  - isToday: 是否为今天 (1表示今天)
  - addAll(): 合并同一天的番剧和国创数据

- `TimelineEpisode`: 番剧剧集模型
  - cover: 封面图
  - episodeId: 剧集ID
  - seasonId: 番剧ID
  - title: 标题
  - pubIndex: 更新集数信息
  - pubTime: 更新时间
  - follow: 是否已追番 (1表示已追)
  - 等其他字段

### 2. HTTP API (lib/http/bangumi.dart)
添加了 `bangumiTimeline` 方法：
- 参数：
  - types: 类型 (1-番剧, 3-电影, 4-国创)
  - before: 前几天的数据
  - after: 后几天的数据
- 返回时间表数据列表

### 3. 时间表卡片组件 (lib/pages/bangumi/widgets/bangumi_card_timeline.dart)
创建了专门的时间表卡片组件：
- 0.75 宽高比的封面图
- 右上角显示"已追番"标记（如果已追番）
- 左下角显示更新时间
- 底部显示番剧标题和更新集数
- 点击跳转到番剧播放页面

### 4. Controller 更新 (lib/pages/bangumi/controller.dart)
添加了时间表相关功能：
- `timelineList`: 时间表数据列表
- `timelineLoading`: 加载状态
- `queryBangumiTimeline()`: 查询时间表方法
  - 同时获取番剧(types=1)和国创(types=4)的时间表
  - 合并同一天的数据
  - 前后各6天的数据
- 在 `onInit()` 中自动加载时间表

### 5. View 更新 (lib/pages/bangumi/view.dart)
在番剧页面顶部添加了时间表区域：
- 使用 `DefaultTabController` 实现日期切换
- Tab 栏显示日期和星期，今天标记为"今天"
- 自动定位到今天的 Tab
- 横向滚动展示当天更新的番剧
- 每个番剧使用 `BangumiCardTimeline` 卡片展示
- 下拉刷新时同时刷新时间表

## UI 布局特点

### 时间表区域布局
1. **标题栏**：
   - 左侧显示"追番时间表"标题
   - 右侧为可滚动的日期 Tab 栏

2. **日期 Tab**：
   - 圆角胶囊样式
   - 选中状态使用 secondaryContainer 颜色
   - 显示格式：MM-DD 周X / MM-DD 今天
   - 可横向滚动

3. **番剧卡片**：
   - 横向滚动列表
   - 卡片宽度为 Grid.maxRowWidth / 2
   - 0.75 宽高比封面
   - 已追番标记（右上角）
   - 更新时间标记（左下角）
   - 标题和更新集数（底部）

4. **整体高度**：
   - Grid.maxRowWidth / 2 / 0.75 + 96 (考虑文字缩放)

## 数据来源
- API: `/pgc/web/timeline/web_timeline`
- 同时获取番剧和国创数据并合并
- 前后各6天的数据（共13天）
