# 音乐视频跳转修复完成

## 问题描述
音乐推荐视频点击后出现白屏，第一次点击失败，第二次点击才能正常跳转。

## 根本原因

### 问题1：参数传递格式不正确
传递给视频播放页的参数格式不正确：
- 错误做法：传递 `videoItem` 对象（BgmRecommend类型）
- 正确做法：只传递必要的字段（cover, title, heroTag）

视频控制器期望从 arguments 中获取独立的字段，而不是一个完整的 videoItem 对象。

### 问题2：播放器冲突
当从视频播放页进入音乐tag页时，原来的视频播放器还在后台运行，点击音乐推荐列表中的视频时，新旧播放器发生冲突导致白屏。

## 解决方案

### 1. 修改 `lib/pages/music/widgets/music_video_card_h.dart`
```dart
// 不传videoItem，只传必要的字段（参考PiliPlus的toVideoPage方法）
Get.toNamed(
  '/video?bvid=$bvid&cid=$finalCid',
  arguments: {
    'heroTag': heroTag,
    'cover': videoItem.cover,
    'title': videoItem.title,
  },
);
```

### 2. 修改 `lib/pages/music/view.dart` 的 `_goToMV` 方法
```dart
void _goToMV(MusicDetail item) {
  final String bvid = item.mvBvid ?? '';
  final int cid = item.mvCid ?? 0;
  if (bvid.isEmpty || cid == 0) {
    return;
  }
  final String heroTag = Utils.makeHeroTag(cid);
  // 不传videoItem，只传必要的字段
  Get.toNamed(
    '/video?bvid=$bvid&cid=$cid',
    arguments: {
      'heroTag': heroTag,
      'cover': item.mvCover,
      'title': item.title,
    },
  );
}
```

### 3. 更新 `lib/pages/video/controller.dart`
简化了 onInit 方法，支持从 arguments 中直接获取 cover 和 title：
```dart
// 从arguments中获取cover和title（音乐推荐等场景）
if (keys.contains('cover')) {

if (keys.contains('title')) {
```

## 参考实现
参考了 PiliPlus 的 `toVideoPage` 方法：
```dart
// PiliPlus/lib/utils/page_utils.dart
static Future<void>? toVideoPage({
  int? aid,
  String? bvid,
  required int cid,
  String? cover,
  String? title,
  // ...
}) {
  final arguments = {
    'aid': aid ?? IdUtils.bv2av(bvid!),
    'bvid': bvid ?? IdUtils.av2bv(aid!),
    'cid': cid,
    'cover': ?cover,
    'title': ?title,
    'heroTag': Utils.makeHeroTag(cid),
    // ...
  };
  return Get.toNamed('/videoV', arguments: arguments);
}
```

### 4. 暂停播放器避免冲突

在音乐详情页和音乐推荐视频页的 `onInit` 中添加播放器暂停逻辑：

**lib/pages/music/controller.dart:**
```dart
@override
void onInit() {
  super.onInit();
  musicId = Get.parameters['musicId']!;
  
  // 暂停正在播放的视频，避免冲突
  PlPlayerController.pauseIfExists();
  
  getMusicDetail();
  // ...
}
```

**lib/pages/music/video/controller.dart:**
```dart
@override
void onInit() {
  super.onInit();
  final args = Get.arguments as Map<String, dynamic>;
  musicId = args['musicId'];
  musicDetail = args['musicDetail'];
  
  // 暂停正在播放的视频，避免冲突
  PlPlayerController.pauseIfExists();
  
  queryData();
}
```

### 5. 使用 offNamed 替换页面

为了确保旧的播放器实例被正确清理，使用 `Get.offNamed` 替换当前页面：

**lib/pages/music/widgets/music_video_card_h.dart:**
```dart
// 使用 offNamed 替换当前页面，确保旧播放器被正确清理
Get.offNamed(
  '/video?bvid=$bvid&cid=$finalCid',
  arguments: {
    'heroTag': heroTag,
    'cover': videoItem.cover,
    'title': videoItem.title,
  },
);
```

**lib/pages/music/view.dart (_goToMV方法):**

## 关键要点
1. **不要传递完整的 videoItem 对象**，只传递必要的字段
2. **heroTag 使用 cid 生成**，而不是 aid 或 bvid
3. **视频控制器会自动获取完整的视频信息**，只需要提供 bvid 和 cid
4. **参考 PiliPlus 的实现**，保持一致的参数传递方式
5. **进入音乐页面时必须暂停播放器**，使用 `PlPlayerController.pauseIfExists()` 避免冲突
