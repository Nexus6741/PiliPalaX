### 1. 文件大小显示功能

#### 数据模型扩展
```dart
class DownloadEntryInfo {
  // ... 原有属性

  /// 获取格式化的文件大小
  String get formattedFileSize {
    final bytes = totalBytes.value;
    if (bytes == 0) return '未知大小';
    
    const suffixes = ['B', 'KB', 'MB', 'GB', 'TB'];
    var i = 0;
    double size = bytes.toDouble();
    
    while (size >= 1024 && i < suffixes.length - 1) {
      size /= 1024;
      i++;
    }
    
    return '${size.toStringAsFixed(i == 0 ? 0 : 1)}${suffixes[i]}';
  }
}
```

#### UI显示位置
- **单画质视频**：在画质标签和UP主信息下方显示文件大小
- **多画质展开项**：在每个画质项的右侧显示对应画质的文件大小

### 2. 全选功能实现

#### 控制器扩展
```dart
class DownloadPageController extends GetxController {
  // ... 原有代码

  /// 检查是否全选
  bool get isAllSelected => pages.isNotEmpty && pages.every((e) => e.checked == true);

  /// 检查是否部分选择
  bool get isPartialSelected => pages.any((e) => e.checked == true) && !isAllSelected;

  /// 全选/取消全选
  void toggleSelectAll() {
    final shouldSelectAll = !isAllSelected;
    for (var page in pages) {
      page.checked = shouldSelectAll;
    }
    rxCount.value = shouldSelectAll ? pages.length : 0;
    pages.refresh();
  }
}
```

#### UI界面集成
```dart
// AppBar 中的全选按钮
IconButton(
  icon: Icon(
    _controller.isAllSelected
        ? Icons.check_box                    // 全选状态
        : _controller.isPartialSelected
            ? Icons.indeterminate_check_box  // 部分选择状态
            : Icons.check_box_outline_blank, // 未选择状态
  ),
  onPressed: _controller.toggleSelectAll,
  tooltip: _controller.isAllSelected ? '取消全选' : '全选',
),
```

#### 状态管理
- **全选状态**：所有项目都被选中
- **部分选择状态**：部分项目被选中
- **未选择状态**：没有项目被选中
- **智能切换**：根据当前状态自动切换到相反状态

## 使用指南

### 查看文件大小
1. **单画质视频**：在视频卡片底部查看文件大小
2. **多画质视频**：展开后在每个画质项右侧查看对应大小
3. **大小格式**：自动显示合适的单位（MB、GB等）

### 使用全选功能
1. 进入多选模式（点击多选按钮）
2. 点击AppBar中的全选按钮
3. **全选**：选择所有视频
4. **取消全选**：取消所有选择
5. **部分选择**：显示中间状态图标

### 精确删除画质
1. 展开包含多个画质的视频
2. 长按要删除的画质项
3. 选择"删除 XXX 画质"
4. 确认删除操作
5. 系统会删除该画质的所有文件

### 文件大小说明
- **B**：字节（小于1KB的文件）
- **KB**：千字节（1024B = 1KB）
- **MB**：兆字节（1024KB = 1MB）
- **GB**：吉字节（1024MB = 1GB）
- **TB**：太字节（1024GB = 1TB）
