# 投票创建功能修复说明

## 问题描述
创建投票后点击发布会提示"投票创建失败"。

## 问题原因

### 1. API 地址错误
**旧的（错误的）：**
```dart
static const String createVote = 
    'https://api.vc.bilibili.com/vote_svr/v1/vote_svr/create_vote';
```

**新的（正确的）：**
```dart
static const String createVote = '/x/vote/create';
```

### 2. API 请求格式错误
**旧的格式（表单格式）：**
```dart
Map<String, dynamic> formData = {
  'info[title]': voteInfo.title,
  'info[desc]': '',
  'info[type]': 0,
  'info[choice_cnt]': voteInfo.multiChoice ? voteInfo.options.length : 1,
  'info[duration]': voteInfo.getDurationInSeconds(),
  'csrf': await Request.getCsrf(),
};

// 添加选项
for (int i = 0; i < voteInfo.options.length; i++) {
  formData['info[options][$i][desc]'] = voteInfo.options[i].text;
}

var res = await Request().post(
  Api.createVote,
  data: formData,
);
```

**新的格式（JSON 格式）：**
```dart
var res = await Request().post(
  Api.createVote,
  queryParameters: {
    'csrf': await Request.getCsrf(),
  },
  data: {
    'vote_info': voteInfo.toJson(),
  },
);
```

### 3. VoteInfo 模型的 toJson 方法字段名错误

**修复前：**
```dart
Map<String, dynamic> toJson() {
  return {
    'vote_id': voteId,
    'title': title,
    'options': options.map((e) => e.toJson()).toList(),
    'end_time': endTime,
    'multi_choice': multiChoice,
    'choice_count': choiceCount,  // ❌ 错误的字段名
    'duration': duration,
  };
}
```

**修复后：**
```dart
Map<String, dynamic> toJson() {
  final int calculatedChoiceCnt = multiChoice ? options.length : 1;
  
  return {
    if (voteId != null) 'vote_id': voteId,
    'title': title,
    'desc': '', // 投票描述，可为空
    'type': 0, // 0: 文字投票, 1: 图片投票
    'choice_cnt': choiceCount ?? calculatedChoiceCnt,  // ✅ 正确的字段名
    'duration': getDurationInSeconds(),
    'options': options.map((e) => e.toJson()).toList(),
  };
}
```

### 4. VoteOption 模型的 toJson 方法字段名错误

**修复前：**
```dart
Map<String, dynamic> toJson() {
  return {
    'text': text,  // ❌ 错误的字段名
    'count': count,
    'selected': selected,
  };
}
```

**修复后：**
```dart
Map<String, dynamic> toJson() {
  return {
    'opt_desc': text,  // ✅ 正确的字段名
    if (count != null) 'cnt': count,
  };
}
```

### 2. 更新 createVote 方法 (`lib/http/dynamics.dart`)
```dart
static Future createVote(VoteInfo voteInfo) async {
  try {
    print('=== createVote 开始 ===');
    print('投票标题: ${voteInfo.title}');
    print('投票选项数: ${voteInfo.options.length}');
    print('是否多选: ${voteInfo.multiChoice}');
    print('持续时间(秒): ${voteInfo.getDurationInSeconds()}');

    // 使用新的 API 格式（JSON）
    final voteData = voteInfo.toJson();
    print('投票数据: $voteData');

    var res = await Request().post(
      Api.createVote,
      queryParameters: {
        'csrf': await Request.getCsrf(),
      },
      data: {
        'vote_info': voteData,
      },
    );

    print('=== createVote 响应 ===');
    print('code: ${res.data['code']}');
    print('message: ${res.data['message']}');
    print('data: ${res.data['data']}');

    if (res.data['code'] == 0) {
      return {
        'status': true,
        'data': res.data['data'],
      };
    } else {
      return {
        'status': false,
        'msg': res.data['msg'] ?? res.data['message'],
      };
    }
  } catch (err) {
    print('=== createVote 异常 ===');
    print('错误: $err');
    return {
      'status': false,
      'msg': err.toString(),
    };
  }
}
```

## API 字段对照表

### VoteInfo 字段
| 你的字段名 | API 需要的字段名 | 说明 |
|-----------|----------------|------|
| voteId | vote_id | 投票ID（可选） |
| title | title | 投票标题 |
| - | desc | 投票描述（可为空） |
| - | type | 投票类型（0: 文字, 1: 图片） |
| choiceCount | choice_cnt | 最多选几项 |
| duration | duration | 持续时间（秒） |
| options | options | 选项列表 |

### VoteOption 字段
| 你的字段名 | API 需要的字段名 | 说明 |
|-----------|----------------|------|
| text | opt_desc | 选项文字 |
| count | cnt | 投票数（可选） |

```

投票选项数: 2
是否多选: false

投票数据: {title: xxx, desc: , type: 0, choice_cnt: 1, duration: 604800, options: [{opt_desc: 选项1}, {opt_desc: 选项2}]}
=== createVote 响应 ===
code: 0
```

如果创建失败，会显示错误信息：
```
=== createVote 响应 ===
code: xxx
message: 错误信息
data: null
```

## 测试步骤

1. 打开动态发布页面
2. 点击投票按钮
3. 创建一个投票（至少2个选项）
4. 点击完成
5. 输入动态内容
6. 点击发布
7. 查看控制台日志，确认投票创建成功

## 注意事项

1. 新的 API 使用 JSON 格式，不再使用表单格式
2. 字段名必须严格匹配 API 要求（如 `choice_cnt` 而不是 `choice_count`）
3. 选项的字段名是 `opt_desc` 而不是 `text` 或 `desc`
4. CSRF token 需要放在 queryParameters 中
