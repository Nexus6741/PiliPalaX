# 话题页排序功能修复说明

## 问题描述
话题页的排序功能存在以下问题：
1. 点击排序按钮后，UI显示的选中状态不正确
2. 排序内容不匹配选中的排序方式
3. 用户选择的排序方式被服务器返回的默认排序覆盖

## 问题原因分析

### 1. 排序状态被覆盖
在 `queryData()` 方法中，每次请求后都会执行：
```dart
sortBy = data.topicSortByConf?.showSortBy ?? 0;
```
这导致用户选择的排序方式被服务器返回的默认排序覆盖。

### 2. 排序状态不是响应式的
`sortBy` 是普通的 `int` 类型，不是响应式的，导致UI无法自动更新。

## 修复方案

### 1. 修复排序状态覆盖问题
```dart
// 修改前：每次都覆盖排序
sortBy = data.topicSortByConf?.showSortBy ?? 0;

// 修改后：只在第一次加载时设置默认排序
if (topicSortByConf.value == null) {
  sortBy.value = data.topicSortByConf?.showSortBy ?? 0;
}
```

### 2. 将排序状态改为响应式
```dart
// 修改前：普通变量
int sortBy = 0;

// 修改后：响应式变量
RxInt sortBy = 0.obs;
```

### 3. 更新相关方法
- `queryData()`: 使用 `sortBy.value` 传递参数
- `onSort()`: 使用 `sortBy.value` 设置新值
- 视图中的 `isSelected`: 使用 `sortBy.value` 进行比较

## 修复的具体文件

### lib/pages/dynamics_topic/controller.dart
1. **排序变量改为响应式**：
   ```dart
   RxInt sortBy = 0.obs;
   ```

2. **修复排序覆盖逻辑**：
   ```dart
   // 只在第一次加载时设置默认排序
   if (topicSortByConf.value == null) {
     sortBy.value = data.topicSortByConf?.showSortBy ?? 0;
   }
   ```

3. **更新排序方法**：
   ```dart
   void onSort(int newSortBy) {
     sortBy.value = newSortBy;
     offset = '';
     isEnd.value = false;
     dynamicsList.clear();
     queryData();
   }
   ```

### lib/pages/dynamics_topic/view.dart
1. **修复排序按钮选中状态**：
   ```dart
   isSelected: allSortBy.map((e) {
     return e.sortBy == _controller.sortBy.value;
   }).toList(),
   ```

## 修复效果

### 修复前
- 点击排序按钮后，UI选中状态不变
- 内容可能刷新但排序方式不正确
- 用户选择被服务器默认值覆盖

### 修复后
- 点击排序按钮后，UI正确显示选中状态
- 内容按照选中的排序方式正确排序
- 用户选择的排序方式得到保持
- 响应式更新，UI与数据状态同步

## 技术要点

1. **响应式编程**：使用 `RxInt` 让排序状态变为响应式
2. **状态管理**：避免服务器数据覆盖用户选择
3. **UI同步**：通过响应式变量确保UI与数据状态同步
4. **条件判断**：只在初始化时设置默认排序，保护用户选择

2. 点击不同的排序选项，确认UI选中状态正确更新
3. 确认内容按照选中的排序方式正确显示
