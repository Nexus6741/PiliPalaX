# 话题点赞和收藏功能修复说明

## 问题描述
话题页的点赞和收藏功能返回 -111 错误码，操作失败。

## 问题原因
通过对比 PiliPlus 项目的实现，发现主要问题是：

1. **缺少正确的 Content-Type 请求头**：B站的话题相关API需要使用 `application/x-www-form-urlencoded` 格式
2. **请求格式不正确**：没有按照B站API的要求设置正确的请求头

## 修复方案

### 1. 添加必要的导入
在 `lib/http/user.dart` 文件顶部添加 dio 导入：
```dart
import 'package:dio/dio.dart';
```

### 2. 修复话题收藏相关方法
为 `addFavTopic` 和 `delFavTopic` 方法添加正确的请求头：
```dart
options: Options(contentType: Headers.formUrlEncodedContentType)
```

### 3. 修复话题点赞方法
为 `likeTopic` 方法添加正确的请求头：
```dart
options: Options(contentType: Headers.formUrlEncodedContentType)
```

## 修复的具体文件
- `lib/http/user.dart`
  - `addFavTopic` 方法
  - `delFavTopic` 方法  
  - `likeTopic` 方法

## 参考实现
修复方案参考了 PiliPlus 项目中 `lib/http/fav.dart` 的正确实现。

## 测试建议
1. 重新编译应用
2. 在话题页测试点赞功能
3. 在话题页测试收藏功能
4. 确认操作成功且UI状态正确更新

## 技术细节
B站的话题相关API（`/x/topic/like`、`/x/topic/fav/sub/add`、`/x/topic/fav/sub/cancel`）要求：
- Content-Type: `application/x-www-form-urlencoded`
- 必需参数：csrf、topic_id
- 点赞API额外需要：action、up_mid、business

修复后的请求将使用正确的格式，避免 -111 错误。
