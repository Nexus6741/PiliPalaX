## 功能说明

### 登录设备页面
- 显示当前账号所有登录设备列表
- 每个设备显示：
  - 设备名称
  - 最后登录时间
  - 来源
  - 当前设备标记（显示"(本机)"）
- 支持下拉刷新
- 支持加载状态、错误状态、空数据状态

### API 实现
- 接口：`/x/safecenter/user_login_devices`
- 方法：GET
- 参数：csrf
- 返回：设备列表

## UI 设计

### 登录设备页面
- 使用 ListTile 展示每个设备
- 标题：设备名称（14px）
- 副标题：最后登录时间 + 来源（13px，灰色）
- 尾部：当前设备标记"(本机)"（13px，灰色）
- 设备之间有分隔线
- 最大宽度限制为 650px（居中显示）

## 测试指南

1. 登录账号后，进入自己的用户空间
2. 点击右上角"..."菜单
3. 选择"登录设备"
4. 应该能看到当前账号的所有登录设备列表
5. 当前设备应该有"(本机)"标记
