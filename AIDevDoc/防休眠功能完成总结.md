## 🔧 技术实现

### 核心 API
```typescript
// 鸿蒙原生层
await windowClass.setWindowKeepScreenOn(true);   // 启用
await windowClass.setWindowKeepScreenOn(false);  // 禁用
```

### 调用流程
```
播放器状态变化
    ↓
stream.playing.listen()
    ↓
WakelockManager.instance.enable/disable()
    ↓
Platform.operatingSystem == 'ohos' ?
    ├─ Yes → WakelockOhos.enable/disable()
    │           ↓
    │       MethodChannel 调用
    │           ↓
    │       WakelockOhosPlugin.ets
    │           ↓
    │       window.setWindowKeepScreenOn()
    │
    └─ No → WakelockPlus.enable/disable()
```

## 📝 使用说明

### 基础用法
```dart
import 'package:PiliPalaX/utils/wakelock_manager.dart';

// 启用防休眠
await WakelockManager.instance.enable();

// 禁用防休眠
await WakelockManager.instance.disable();
```

### 播放器自动控制
播放器已自动集成，无需手动调用：
- 播放时自动启用防休眠
- 暂停时自动禁用防休眠
- 播放完成时自动禁用防休眠
