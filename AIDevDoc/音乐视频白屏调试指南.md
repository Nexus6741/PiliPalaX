# 音乐视频白屏调试指南

## 当前问题
从音乐推荐列表点击视频后：
- ✅ 有声音（说明视频在播放）
- ❌ 白屏（说明UI没有正确渲染）

## 可能的原因

### 1. 播放器实例状态问题
`PlPlayerController.getInstance()` 是单例模式，可能返回的是之前被暂停的播放器实例，导致：
- `videoController` 为 null
- 播放器状态异常
- UI无法正确渲染

### 2. 播放器 Key 冲突
播放器使用 `heroTag` 作为 key，如果 heroTag 相同可能导致 Flutter 不重新构建 widget。

### 3. 播放器未正确初始化
`setDataSource` 可能没有正确完成，导致 `videoController` 为 null。

## 调试步骤

### 步骤1：查看日志
运行应用，从音乐推荐列表点击视频，查看控制台输出：

```
🎵 VideoDetailController.onInit - 开始初始化
🎵 arguments: {...}
🎵 argument keys: [...]
🎵 从cover获取封面: ...
🎵 从title获取标题: ...
🎵 最终videoItem: {...}
🎵 autoPlay: true/false
🎵 获取播放器实例: true/false
🎵 播放器videoController: null/Instance of '...'
```

### 步骤2：检查关键信息
1. **autoPlay 是否为 true**
   - 如果为 false，播放器不会初始化
   
2. **播放器实例是否获取成功**
   - 应该为 true
   
3. **videoController 是否为 null**
   - 如果为 null，说明 `setDataSource` 还没完成或失败了

### 步骤3：检查播放器渲染条件
在 `lib/pages/video/view.dart` 中，播放器渲染需要满足：
```dart
(!videoDetailController.autoPlay.value && videoDetailController.isShowCover.value) ||
plPlayerController == null ||
plPlayerController!.videoController == null
```

如果任何一个条件为 true，播放器会显示为空（nil）。

## 可能的解决方案

### 方案1：重置播放器实例
在获取播放器实例前，先dispose旧实例：
```dart
if (autoPlay.value) {
  isShowCover.value = false;
  // 如果存在旧实例，先dispose
  PlPlayerController.disposeIfExists();
  plPlayerController = PlPlayerController.getInstance();
  plPlayerController!.controls = false;
  // ...
}
```

### 方案2：强制刷新播放器
在 `setDataSource` 完成后，强制刷新 UI：
```dart
await plPlayerController!.setDataSource(...);
isShowCover.value = false;
isShowCover.refresh();
```

### 方案3：使用不同的 heroTag
确保每个视频使用唯一的 heroTag：
```dart
final String heroTag = Utils.makeHeroTag(cid);
```

### 方案4：检查 isShowCover 状态
确保 `isShowCover` 为 false：
```dart
if (autoPlay.value) {
  isShowCover.value = false;
  print('🎵 isShowCover: ${isShowCover.value}');
  // ...
}
```
