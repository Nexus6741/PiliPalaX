- 🔍 `[搜索]` - 控制器层日志
- 🌐 `[API]` - HTTP请求层日志  
- 🎨 `[视图]` - UI视图层日志

## 常见问题排查

### 问题1：大家都在搜区域为空

**检查日志：**
1. 查看是否有 `🔍 [搜索] 开始获取热搜关键词...`
2. 查看 `🌐 [API] 热搜榜单响应码` 是否为 0
3. 查看 `🔍 [搜索] 热搜关键词数量` 是否大于 0
4. 查看 `🎨 [视图] 热搜列表长度` 是否大于 0

**可能原因：**
- API请求失败（响应码不为0）
- 数据解析失败（有异常日志）
- 数据为空（数量为0）
- 视图未正确渲染

### 问题2：搜索发现区域为空

**检查日志：**
1. 查看 `🔍 [搜索] 搜索发现开关` 是否为 true
2. 查看是否有 `🔍 [搜索] 准备加载搜索发现...`
3. 查看 `🌐 [API] 搜索发现响应码` 是否为 0
4. 查看 `🔍 [搜索] 搜索发现数量` 是否大于 0
5. 查看 `🎨 [视图] 搜索发现列表长度` 是否大于 0

**可能原因：**
- 搜索发现功能被禁用（开关为false）
- API请求失败
- 数据解析失败
- 数据为空

### 问题3：API请求失败

**检查日志：**
```
❌ [API] 热搜榜单请求失败: XXX
❌ [API] 热搜榜单异常: XXX
❌ [API] 堆栈: XXX
```

**可能原因：**
- 网络连接问题
- API端点错误
- 参数错误
- 服务器错误

### 问题4：数据解析失败

**检查日志：**
```
❌ [搜索] 热搜关键词异常: XXX
❌ [搜索] 堆栈: XXX
```

**可能原因：**
- 数据格式不匹配
- 模型定义错误
- 字段缺失

## 调试步骤

```dart

enableSearchRcmd = 'enableSearchRcmd' // 搜索发现开关
```

### 步骤2：检查API端点
```dart
// 在 lib/http/api.dart 中检查
static const String searchTrending = '/x/v2/search/trending/ranking';
static const String searchRecommend = '/x/v2/search/recommend';
```

### 步骤3：查看完整日志
运行应用并打开搜索页面，在控制台查看完整的日志输出。

## 清理日志

完成调试后，可以删除或注释掉日志代码：

1. 在 `lib/pages/search/controller.dart` 中删除 print 语句
2. 在 `lib/http/search.dart` 中删除 print 语句
3. 在 `lib/pages/search/view.dart` 中删除 print 语句

或者使用条件编译：
