# 鸿蒙视频播放防休眠功能修复完成

## 问题描述

在鸿蒙端播放视频时，即使不操作设备，屏幕仍会自动休眠，影响用户体验。原有的 `wakelock_plus` 插件在鸿蒙平台上不生效。

## 解决方案

创建了专门的 `wakelock_ohos` 插件，使用鸿蒙原生的 `@ohos.runningLock` API 来实现防休眠功能，并通过 `WakelockManager` 工具类统一管理所有平台的防休眠功能。

## 实现内容

### 1. 创建 wakelock_ohos 插件

**目录结构：**
```
packages/wakelock_ohos/
├── lib/
│   └── wakelock_ohos.dart          # Dart 接口层
├── ohos/
│   ├── src/main/
│   │   ├── ets/components/plugin/
│   │   │   └── WakelockOhosPlugin.ets  # 鸿蒙原生实现
│   │   └── module.json5            # 权限配置
│   ├── build-profile.json5
│   ├── index.ets
│   └── oh-package.json5
├── pubspec.yaml
└── README.md
```

**核心功能：**
- `enable(timeout)`: 启用防休眠锁
  - `timeout = -1`: 永久持锁，需要主动释放
  - `timeout = 0`: 默认 3 秒后超时释放
  - `timeout > 0`: 按指定时间（毫秒）超时释放
- `disable()`: 释放防休眠锁
- `isHolding()`: 查询锁是否处于持有状态
- `isSupported()`: 检查系统是否支持该功能

**技术细节：**
- 使用 `runningLock.RunningLockType.PROXIMITY_SCREEN_CONTROL` 类型
- 该类型会使能接近光传感器，根据距离控制亮灭屏
- 在视频播放场景下保持屏幕常亮

### 2. 创建 WakelockManager 工具类

创建了 `lib/utils/wakelock_manager.dart`，统一管理所有平台的防休眠功能：

```dart
class WakelockManager {
  static final WakelockManager _instance = WakelockManager._();
  static WakelockManager get instance => _instance;

  /// 启用防休眠
  Future<void> enable() async {
    if (UniversalPlatform.isOhos) {
      // 鸿蒙平台使用专用插件，永久持锁
      await WakelockOhos.enable(timeout: -1);
    } else {
      // 其他平台使用 wakelock_plus
      await WakelockPlus.enable();
    }
  }

  /// 禁用防休眠
  Future<void> disable() async {
    if (UniversalPlatform.isOhos) {
      await WakelockOhos.disable();
    } else {
      await WakelockPlus.disable();
    }
  }
}
```

### 3. 集成到播放器控制器

修改了 `lib/plugin/pl_player/controller.dart`，在播放器的关键生命周期中调用防休眠管理器：

**播放时启用：**
```dart
Future<void> play({bool repeat = false, bool hideControls = true}) async {
  // ... 其他代码
  await _videoPlayerController?.play();
  playerStatus.status.value = PlayerStatus.playing;
  
  // 启用防休眠
  WakelockManager.instance.enable();
}
```

**暂停时禁用：**
```dart
Future<void> pause({bool notify = true, bool isInterrupt = false}) async {
  await _videoPlayerController?.pause();
  playerStatus.status.value = PlayerStatus.paused;
  
  // 禁用防休眠
  WakelockManager.instance.disable();
}
```

**销毁时释放：**
```dart
Future<void> dispose() async {
  pause();
  
  // 释放防休眠锁
  WakelockManager.instance.disable();
  
  // ... 其他清理代码
}

Future<void> videoPlayerClosed() async {
  // ... 其他代码
  
  // 释放防休眠锁
  WakelockManager.instance.disable();
}
```

### 4. 权限配置

在 `ohos/entry/src/main/module.json5` 中添加了必要的权限：

```json5
requestPermissions: [
  { name: "ohos.permission.INTERNET" },
  { name: "ohos.permission.VIBRATE" },
  { name: "ohos.permission.RUNNING_LOCK" },  // 新增
]
```

## 使用方式

功能已自动集成到视频播放器中，无需手动调用：

- **播放视频时**：自动启用防休眠
- **暂停视频时**：自动禁用防休眠
- **退出播放器时**：自动释放防休眠锁

如需在其他场景手动控制，可以使用 `WakelockManager`：

```dart
import 'package:PiliPalaX/utils/wakelock_manager.dart';

// 启用防休眠
await WakelockManager.instance.enable();

// 禁用防休眠
await WakelockManager.instance.disable();

// 查询状态
bool isEnabled = await WakelockManager.instance.isEnabled();

// 检查系统支持
bool isSupported = await WakelockManager.instance.isSupported();
```

或直接使用底层插件（仅鸿蒙平台）：

```dart
import 'package:wakelock_ohos/wakelock_ohos.dart';

// 启用防休眠
await WakelockOhos.enable(timeout: -1);

// 禁用防休眠
await WakelockOhos.disable();
```

## 注意事项

1. **权限要求：** 必须在 module.json5 中声明 `ohos.permission.RUNNING_LOCK` 权限
2. **资源管理：** 插件会在 `onDetachedFromEngine` 时自动释放锁，避免资源泄漏
3. **错误处理：** 所有操作都有错误捕获，失败时会打印日志但不会影响应用运行
4. **平台兼容：** 只在鸿蒙平台生效，其他平台继续使用 `wakelock_plus`
