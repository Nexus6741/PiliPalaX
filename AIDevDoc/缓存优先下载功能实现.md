# 缓存优先下载功能实现

## 功能描述

实现了更直观的缓存管理方式：

1. **移除跳过按钮**：简化操作，避免混淆
2. **等待视频可立即开始**：点击播放按钮立即下载该视频
3. **自动暂停当前下载**：开始新视频时自动暂停当前下载

## 设计理念

### 旧设计的问题
- **跳过按钮不直观**：用户不清楚"跳过"的含义
- **操作复杂**：需要先跳过，再等待下一个
- **缺少主动权**：用户无法直接选择想下载的视频

### 新设计的优势
- **直接选择**：点击任意等待视频的播放按钮即可立即下载
- **自动管理**：系统自动暂停当前下载
- **操作简单**：一键切换，无需多步操作

## 实现方案

### 1. 新增优先下载方法

```dart
/// 优先下载指定视频（暂停当前，立即开始该视频）
Future<void> prioritizeDownload(DownloadEntryInfo entry) async {
  return _lock.synchronized(() async {
    // 如果该视频已经在下载，不做处理
    if (curDownload.value?.cid == entry.cid) {
      return;
    }

    // 如果有正在下载的视频，先暂停它
    if (curDownload.value != null) {
      final currentEntry = curDownload.value!;
      
      // 取消当前下载
      await videoManager?.cancel(isDelete: false);
      await audioManager?.cancel(isDelete: false);

      // 标记为暂停状态
      currentEntry.status.value = DownloadStatus.pause;
      await _updateBiliDownloadEntryJson(currentEntry);

      // 清理状态
      _curCid = null;
      curDownload.value = null;
      videoManager = null;
      audioManager = null;
    }

    // 将目标视频状态改为等待
    if (entry.status.value == DownloadStatus.pause) {
      entry.status.value = DownloadStatus.wait;
      await _updateBiliDownloadEntryJson(entry);
    }

    // 立即开始下载该视频
    _curCid = entry.cid;
    curDownload.value = entry;
    await _startDownload(entry);
  });
}
```

**功能**：
- 使用锁确保操作原子性
- 自动暂停当前下载
- 立即开始目标视频下载
- 处理暂停状态的视频

## 功能流程图

### 优先下载流程

```
队列状态：
  视频A（正在下载）
  视频B（等待中）
  视频C（等待中）

用户操作：点击视频C的"立即下载"按钮
    ↓
系统处理：
  1. 暂停视频A
  2. 视频A状态 → pause
  3. 视频C状态 → downloading
    ↓
新队列状态：
  视频A（暂停中）
  视频B（等待中）
  视频C（正在下载）← 当前
```

### 继续下载流程

```
队列状态：
  视频A（暂停中）
  视频B（等待中）
  视频C（正在下载）

用户操作：点击视频A的"继续"按钮
    ↓
系统处理：
  1. 暂停视频C
  2. 视频C状态 → pause
  3. 视频A状态 → downloading
    ↓
新队列状态：
  视频A（正在下载）← 当前
  视频B（等待中）
  视频C（暂停中）
```

## 使用场景

### 场景 1：优先下载重要视频

**情况**：队列中有5个视频，第1个正在下载，但用户想先下载第4个

**操作**：
1. 找到第4个视频
2. 点击"立即下载"按钮（▶️）
3. **结果**：
   - 第1个视频自动暂停
   - 第4个视频立即开始下载
   - 第1个视频保留在队列中

### 场景 2：切换下载视频

**情况**：正在下载视频A，但想改为下载视频B

**操作**：
1. 找到视频B
2. 点击"立即下载"按钮
3. **结果**：
   - 视频A自动暂停
   - 视频B立即开始下载
   - 可以随时点击视频A的"继续"按钮恢复

### 场景 3：管理多个下载

**情况**：有多个视频在队列中，想按自己的顺序下载

**操作**：
1. 点击想下载的视频的"立即下载"按钮
2. 下载完成后，点击下一个想下载的视频
3. **结果**：
   - 完全按照自己的意愿控制下载顺序
   - 不需要的视频可以一直等待
   - 随时可以切换

### 场景 4：暂停后继续

**情况**：暂停了某个视频，想继续下载

**操作**：
1. 找到暂停的视频（显示"暂停中"）
2. 点击"继续"按钮（▶️）
3. **结果**：
   - 如果有其他视频在下载，会先暂停它
   - 该视频立即开始下载
