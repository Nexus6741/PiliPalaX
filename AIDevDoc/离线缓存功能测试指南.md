# 离线缓存功能测试指南

## 前置条件

1. 确保已安装所有依赖包：
```bash
flutter pub get
```

2. 确保以下包已添加到 `pubspec.yaml`：
- `path_provider` - 文件路径管理
- `synchronized` - 同步锁
- `flutter_cache_manager` - 缓存管理

## 测试步骤

### 1. 基础功能测试

#### 1.1 下载视频
1. 打开应用
2. 进入任意视频详情页
3. 点击底部操作栏的"缓存"按钮
4. 选择画质（480P/720P/1080P/4K）
5. 观察是否提示"已添加到下载队列"

#### 1.2 查看下载列表
1. 导航到离线缓存页面（路由：`/download`）
2. 应该能看到：
   - 正在下载的视频（如果有）
   - 下载进度条
   - 下载状态提示
   - 已下载的视频列表

#### 1.3 下载进度
1. 观察正在下载的视频
2. 检查进度条是否正常更新
3. 检查百分比显示是否正确
4. 检查状态文字是否正确（正在下载/正在下载音频/获取弹幕等）

### 2. 下载管理测试

#### 2.1 暂停下载
1. 点击正在下载视频的暂停按钮
2. 观察下载是否暂停
3. 状态是否变为"暂停中"

#### 2.2 删除下载
1. 长按已下载的视频卡片
2. 选择"删除"
3. 确认删除
4. 观察视频是否从列表中移除

#### 2.3 更新弹幕
1. 长按已下载的视频卡片
2. 选择"更新弹幕"
3. 观察是否提示"更新成功"或"更新失败"

### 3. 批量操作测试

#### 3.1 多选模式
1. 点击右上角的多选按钮
2. 观察界面是否进入多选模式
3. 选择多个视频
4. 观察顶部是否显示已选择数量

#### 3.2 批量删除
1. 进入多选模式
2. 选择多个视频
3. 点击删除按钮
4. 确认删除
5. 观察所有选中的视频是否被删除

#### 3.3 批量更新弹幕
1. 进入多选模式
2. 选择多个视频
3. 点击"更新弹幕"按钮
4. 观察是否提示更新结果

### 4. 边界情况测试

#### 4.1 网络异常
1. 开始下载一个视频
2. 断开网络连接
3. 观察是否提示下载失败
4. 重新连接网络
5. 检查是否可以继续下载

#### 4.2 存储空间不足
1. 在存储空间接近满的设备上测试
2. 尝试下载大文件
3. 观察是否有适当的错误提示

#### 4.3 应用重启
1. 开始下载一个视频
2. 关闭应用
3. 重新打开应用
4. 进入下载页面
5. 检查下载状态是否正确恢复

### 5. UI 测试

#### 5.1 单视频显示
1. 下载一个单P视频
2. 检查卡片显示是否正确：
   - 封面图片
   - 标题
   - UP主名称
   - 更多按钮

#### 5.2 合集显示
1. 下载同一视频的多个分P
2. 检查是否显示为合集
3. 检查是否显示"X个视频"标签
4. 点击合集（当前会提示"合集详情页开发中"）

#### 5.3 响应式布局
1. 在不同屏幕尺寸下测试
2. 横屏/竖屏切换
3. 检查布局是否正常

### 6. 性能测试

#### 6.1 大文件下载
1. 下载 4K 视频
2. 观察内存使用情况
3. 观察下载速度
4. 检查是否有卡顿

#### 6.2 多个文件下载
1. 连续添加多个视频到下载队列
2. 观察队列管理是否正常
3. 检查是否按顺序下载

#### 6.3 长时间运行
1. 下载多个大文件
2. 让应用在后台运行
3. 检查下载是否能正常完成
4. 检查是否有内存泄漏
