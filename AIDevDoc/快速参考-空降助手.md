# 快速参考 - 空降助手

## 功能概述

空降助手可以自动跳过视频中的广告、片头片尾等片段，提升观看体验。

## 用户使用指南

### 1. 启用功能
1. 进入"设置" → "其它设置"
2. 点击"空降助手"
3. 配置各项设置

### 2. 配置片段类型
每种片段类型可以独立配置跳过模式：
- **总是跳过** - 每次都自动跳过
- **跳过一次** - 只跳过第一次
- **手动跳过** - 显示按钮，手动点击跳过
- **仅显示** - 只标记，不跳过
- **禁用** - 完全忽略

### 3. 观看视频
- 自动跳过：片段会自动跳过，显示提示
- 手动跳过：左下角显示跳过按钮，点击跳过
- 查看详情：全屏时点击"片段信息"按钮

### 4. 提交片段（开发中）
全屏时点击"提交片段"按钮，可以提交新的片段信息

### 数据结构

#### SegmentModel
```dart
class SegmentModel {
  final String UUID;              // 片段ID
  final SegmentType segmentType;  // 片段类型
  final int segmentStart;         // 开始时间（毫秒）
  final int segmentEnd;           // 结束时间（毫秒）
  SkipType skipType;              // 跳过类型
  bool hasSkipped;                // 是否已跳过
  bool hasShownButton;            // 是否已显示按钮
}
```

#### SegmentType（10种）
1. sponsor - 赞助广告
2. selfpromo - 自我推广
3. interaction - 订阅提醒
4. intro - 开场动画
5. outro - 结束画面
6. preview - 回顾/概要
7. music_offtopic - 非音乐部分
8. poi_highlight - 精彩时刻
9. filler - 离题闲聊
10. exclusive_access - 品牌合作

#### SkipType（5种）
1. alwaysSkip - 总是跳过
2. skipOnce - 跳过一次
3. skipManually - 手动跳过
4. showOnly - 仅显示
5. disable - 禁用

## 常见问题

### Q: 如何禁用某种类型的片段？
A: 在设置页面中，将该类型的跳过模式设置为"禁用"

### Q: 如何调整最短片段时长？
A: 在设置页面中，点击"最短片段时长"进行调整

### Q: 片段数据从哪里来？
A: 从 BilibiliSponsorBlock 社区服务器获取，由用户共同维护

### Q: 如何参与贡献？
A: 观看视频时点击"提交片段"按钮，提交新的片段信息

### Q: 是否支持番剧？
A: 支持，番剧使用官方 API 的片头片尾信息

### Q: 如何关闭跳过提示？
A: 在设置页面中，关闭"显示跳过Toast"开关

## 技术细节

### 性能优化
- 懒加载：只在需要时查询
- 防抖：避免重复跳过
- 异步处理：不阻塞主线程

### 兼容性
- 支持普通视频和番剧
- 支持横屏和竖屏
- 支持全屏和小窗模式

### 隐私保护
- 用户ID本地生成
- 统计追踪可选
- 不收集个人信息
